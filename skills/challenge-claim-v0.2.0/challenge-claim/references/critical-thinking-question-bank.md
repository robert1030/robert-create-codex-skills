# 批判論點挑戰題庫

本文件供 `challenge-claim` 在壓力測試主張、政策、研究結論、產品決策與方案建議時使用。目標不是替使用者判定「誰正確」，而是系統性揭露主張的證據缺口、隱含前提、替代解釋、反方理由與可驗證的修正方向。

---

## 1. 使用原則

### 1.1 先重述，再挑戰

開始提問前，先將原始主張整理成可檢驗格式：

> 在條件 `C` 下，採取行動 `A`，會透過機制 `M`，造成結果 `R`，且相較於基準 `B`，效果具有重要性 `I`。

若無法填滿上述欄位，先指出主張尚未具備可檢驗形式，不要直接進入反駁。

### 1.2 區分主張類型

同一句話可能同時包含多種類型的主張。應拆開處理：

| 主張類型 | 主要問題 |
|---|---|
| 事實主張 | 事情是否真的發生？資料是否可靠？ |
| 因果主張 | A 是否造成 B？是否存在第三因素？ |
| 預測主張 | 未來結果是否可能發生？不確定性多大？ |
| 比較主張 | A 是否優於 B？比較基準是否公平？ |
| 價值主張 | 為何這個結果值得追求？由誰承擔代價？ |
| 定義主張 | 關鍵詞的範圍與判準是什麼？ |
| 規範主張 | 應否採取某項行動？替代方案為何？ |
| 風險主張 | 風險機率、影響與可接受程度為何？ |
| 權威主張 | 專家、研究或機構的資格與適用範圍為何？ |
| 類比主張 | 兩個案例是否真的具有相關結構？ |

### 1.3 問題要推進分析

每個問題應至少具備一項功能：

- 要求定義關鍵概念。
- 要求提出證據或來源。
- 檢查證據是否支持該結論。
- 揭露必要前提。
- 提出替代假設。
- 測試反例與邊界條件。
- 分離事實、推論與價值判斷。
- 指出需要補充的資料或實驗。
- 協助修正為更精確、可辯護的主張。

避免連續提出只會重複「你確定嗎？」的問題。

## 2. 標準壓力測試流程

### 步驟一：抽取主張

**Input**

- 使用者提供的論點、段落、簡報、報告或決策建議。
- 可用的背景、資料、引用與限制。

**Output**

```text
主張：
條件：
行動或原因：
推測機制：
預期結果：
比較基準：
影響對象：
時間範圍：
不確定性：
```

**Validation**

- 主張至少包含可辨識的結論。
- 將描述性內容與規範性內容分開。
- 將「因為」「因此」「所以」「應該」「一定」等推論連接詞標記出來。
- 無法辨認的部分標記為「未明示」，不可自行補成事實。

### 步驟二：判定主張類型

**Input**

- 抽取後的主張。

**Output**

```text
主要類型：
次要類型：
需要優先檢查的風險：
```

**Validation**

- 至少選定一個主要類型。
- 若包含因果、預測或規範結論，優先檢查證據與前提。
- 若關鍵詞定義不清，先處理定義問題，再評估證據。

### 步驟三：建立前提與推理鏈

**Input**

- 主張結論與支持理由。

**Output**

```text
明示前提：
隱含前提：
證據：
從證據到前提的推論：
從前提到結論的推論：
可能缺失的中介步驟：
```

**Validation**

- 每個結論至少對應一條理由。
- 區分「資料顯示」與「因此推論」。
- 找出若不存在便會使結論失效的必要前提。
- 對涉及人群、政策或風險的主張檢查樣本、基準與外推範圍。

### 步驟四：提出反方與替代假設

**Input**

- 原主張、證據與前提清單。

**Output**

- 最強反方論點。
- 至少兩個替代假設。
- 能區分原主張與替代假設的觀察或測試。
- 原主張可能成立的條件。

**Validation**

- 反方不可只是原主張的否定。
- 替代假設要能解釋相同資料，或指出資料不足以區分不同解釋。
- 至少提出一個對原主張不利的案例。
- 同時保留可能支持原主張的證據，避免單向挑錯。

### 步驟五：整理分層問題（內部工作表，交付格式依 SKILL.md 的輸出契約）

**Input**

- 已完成的主張分析。

**Output**

依序產生：

1. 澄清問題。
2. 證據問題。
3. 前提問題。
4. 因果或推理問題。
5. 反方問題。
6. 邊界與反例問題。
7. 修正與驗證問題。

**Validation**

- 每個問題都對應一個可識別的分析缺口。
- 問題數量以能推進決策為準，避免無限制列舉。
- 高風險主張優先列出會改變決策的問題。
- 問題後附上「為何重要」與「理想回答應包含什麼」。

### 步驟六：形成暫定判定

**Input**

- 問題回答、現有資料或使用者補充資訊。

**Output**

```text
判定：
信心：
支持主張的證據：
削弱主張的證據：
尚未解決的關鍵缺口：
建議修正版主張：
下一個驗證行動：
```

**Validation**

- 判定不可超出證據支持範圍。
- 「證據不足」與「主張為假」分開表述。
- 對高不確定性主題使用條件式結論。
- 明確指出哪些部分是事實、哪些部分是推論、哪些部分是價值判斷。

## 3. 通用蘇格拉底式問題

### 3.1 澄清主張

- 你具體主張的是什麼？
- 這句話中的「有效」「安全」「公平」「大幅」「必要」如何定義？
- 這個結論適用於所有情況，還是只適用於特定條件？
- 你是在描述現況、預測未來，還是在主張應採取某個行動？
- 哪一部分是觀察到的資料，哪一部分是你的推論？
- 如果只能保留一句話，你會保留哪個可檢驗命題？
- 什麼結果會讓你承認這個主張需要修正？

### 3.2 目的與價值

- 這個主張要解決的具體問題是什麼？
- 成功由誰定義？
- 你優先追求的是效率、準確性、公平性、成本、速度，還是其他目標？
- 若不同目標互相衝突，採用什麼排序？
- 誰會從這個方案受益？誰可能承擔成本？
- 是否把「可量化」誤當成「重要」？
- 這個結論依賴哪些未說明的價值偏好？

### 3.3 證據

- 支持這個結論的最直接證據是什麼？
- 證據來自原始資料、二手摘要、專家意見，還是個案？
- 資料的時間、地點、人群與情境是否適用於目前問題？
- 是否存在未被納入的反面資料？
- 測量方式是否真的測到主張中的概念？
- 樣本如何取得？誰沒有被納入？
- 結果是否能被獨立重現？
- 證據支持的是「可能」「通常」「平均」還是「必然」？
- 來源是否具有直接利益衝突？
- 是否把相關性、同時發生或事後發生誤當成因果證據？

### 3.4 推理

- 從證據到結論，中間需要哪些推論？
- 哪一個前提一旦不成立，結論就會失效？
- 是否從少數案例推廣到整個群體？
- 是否將「沒有證據」當成「證明不存在」？
- 是否把複雜問題簡化成只有兩個選項？
- 是否把一個方案的缺點拿來與另一方案的理想狀態比較？
- 結論是否比證據允許的範圍更強？
- 是否忽略了基準率、時間延遲或選擇偏誤？
- 這個推理是否依賴循環論證？
- 有沒有把結果、原因與評價混在同一句話裡？

## 4. 依主張類型分類的問題庫

## 4.1 事實主張

### 檢查問題

- 這件事的觀察定義是什麼？
- 事件發生的時間與範圍為何？
- 你依據的是直接紀錄還是他人轉述？
- 是否有多個獨立來源交叉支持？
- 資料是否可能因報告制度、抽樣方式或媒體選擇而偏斜？
- 是否存在相反案例？
- 這個事實對結論的必要性有多高？

### 替代解釋

- 觀察到的變化可能是測量方式改變，而非現象本身改變。
- 報告數量增加可能代表通報意願提高，而非事件實際增加。
- 其中一個突出案例可能被過度報導，不能代表整體頻率。

### 反方提問

- 如果這個事實普遍成立，為何在其他相近情境中沒有出現？
- 有哪些可靠資料會與這個描述衝突？
- 你的來源是否只呈現支持結論的部分？

---

## 4.2 因果主張

### 檢查問題

- A 發生在 B 之前，是否就能說 A 造成 B？
- 是否存在同時影響 A 與 B 的第三因素？
- 是否可能是 B 反過來影響 A？
- 是否有對照組、自然實驗或其他因果識別設計？
- 作用機制是什麼？能否被獨立觀察？
- 這個效果在不同條件下是否仍存在？
- 若移除 A，B 是否會下降？
- 預期的時間延遲是否符合機制？

### 替代假設

1. 第三因素同時造成 A 與 B。
2. B 造成 A，方向與原主張相反。
3. A 與 B 都由選擇偏誤產生。
4. A 與 B 只是共同趨勢，沒有直接關係。
5. 介入真正影響的是中介變項，而非主張所說的結果。

### 反方提問

- 如果 A 是主要原因，未接受 A 的相似群體應呈現什麼不同結果？
- 哪一項觀察最能區分「A 造成 B」與「第三因素造成兩者」？
- 有沒有可能方案有效，但不是因為你提出的機制？

---

## 4.3 預測主張

### 檢查問題

- 預測的時間範圍是多久？
- 預測對哪些條件敏感？
- 參考基準是什麼？
- 過去預測的校準表現如何？
- 預測是點估計還是區間估計？
- 失敗成本是否與成功收益對稱？
- 哪些早期指標可以驗證預測是否正在成真？
- 有哪些事件會使預測失效？

### 替代假設

- 趨勢會因政策、競爭或資源限制而反轉。
- 目前觀察到的成長是短期波動。
- 受影響者會改變行為，使原先預測失準。
- 預測忽略了低機率但高影響事件。

### 反方提問

- 什麼條件改變時，你會撤回這項預測？
- 如果預測錯誤，最可能是哪個前提出錯？
- 這項預測與最簡單的基準模型相比，增加了多少資訊？

---

## 4.4 比較主張

### 檢查問題

- A 與 B 是以什麼指標比較？
- 指標是否與使用者真正關心的目標一致？
- 比較的時間、成本、規模與條件是否相同？
- 是否只挑選對 A 有利的指標？
- B 是否被設定成不公平的弱基準？
- 平均表現是否掩蓋不同族群的差異？
- 差異是否具統計意義與實務意義？
- 若考慮導入成本，結論是否仍成立？

### 替代假設

- A 在速度上較好，但在準確性或公平性上較差。
- A 的優勢只出現在特定族群。
- 表面差異來自不同資源投入，而非方案本身。
- A 與 B 的差異小於測量誤差。

### 反方提問

- 若更換比較指標，結論是否會反轉？
- 哪個基準最接近真實替代方案？
- 這項優勢是否足以抵銷其額外風險與成本？

---

## 4.5 價值與規範主張

### 檢查問題

- 「應該」是依據哪個價值或原則？
- 這個原則是否一致適用於相反案例？
- 誰有權決定這項價值排序？
- 是否把個人偏好包裝成客觀必要性？
- 方案是否侵犯他人的選擇、隱私或尊嚴？
- 是否考慮短期利益與長期後果？
- 是否存在能達成相同目標、但代價較小的方案？
- 對不能承擔風險的人，是否有保護措施？

### 替代假設

- 效率不是唯一目標，公平或自主性可能具有優先性。
- 個案中的最佳選擇不一定適合整體制度。
- 即使目標合理，手段也可能不具正當性。
- 方案的成本由無法發聲的群體承擔。

### 反方提問

- 如果受影響者不同意，你會如何回應？
- 你接受這個原則被套用到自己不利的案例嗎？
- 為了達成目標，哪些代價不可接受？理由是什麼？

---

## 4.6 風險主張

### 檢查問題

- 風險的事件定義是什麼？
- 機率、影響程度與暴露人數分別是多少？
- 風險是相對風險還是絕對風險？
- 是否把最壞情境當成最可能情境？
- 是否存在可降低風險的控制措施？
- 剩餘風險由誰承擔？
- 風險是否可逆？發生後能否補救？
- 是否納入連鎖效應與長期效應？

### 替代假設

- 風險機率低，但一旦發生便不可逆。
- 風險估計建立在不穩定或不完整資料上。
- 風險只被轉移，而非真正降低。
- 控制措施在壓力或大規模使用時會失效。

### 反方提問

- 哪個風險即使機率很低，也值得停止方案？
- 若風險發生，現有補救是否實際可行？
- 你是否把「尚未觀察到傷害」誤當成「沒有傷害」？

---

## 4.7 定義主張

### 檢查問題

- 關鍵詞是否有操作性定義？
- 不同人使用這個詞時是否指同一件事？
- 定義是否因立場而改變？
- 定義排除了哪些案例？
- 這個詞的邊界案例如何處理？
- 是否用同一個詞同時表示原因、結果與價值評價？

### 反方提問

- 若採用更窄或更寬的定義，結論是否改變？
- 哪些案例會讓你的定義感到不自然？
- 這個定義是為了描述現象，還是為了讓結論成立？

---

## 4.8 類比主張

### 檢查問題

- 兩個案例共享哪些結構特徵？
- 相關特徵是否真的與結論有關？
- 是否只比較表面相似性？
- 兩者在規模、時間、權力關係或風險上有何差異？
- 類比中哪些因素無法轉移？
- 是否存在同樣相似但導向相反結果的案例？

### 反方提問

- 如果這個類比成立，哪些其他預測也應該成立？
- 哪個差異足以使類比失效？
- 你是否選擇了最有利的類比，而忽略更接近的反例？

---

## 5. 缺失前提檢查清單

### 5.1 語意前提

- [ ] 關鍵詞有明確定義。
- [ ] 量詞範圍清楚，例如「所有」「多數」「通常」。
- [ ] 時間範圍明確。
- [ ] 適用對象與排除對象明確。
- [ ] 描述、因果與價值判斷已分開。

### 5.2 證據前提

- [ ] 證據直接涉及主張，而非只與主題相關。
- [ ] 來源時間符合問題需求。
- [ ] 樣本與目標群體相符。
- [ ] 資料沒有明顯選擇偏誤。
- [ ] 反面資料已被搜尋或說明。
- [ ] 測量指標能代表主張中的概念。
- [ ] 引用內容沒有超出原始來源支持範圍。

### 5.3 因果前提

- [ ] 原因發生於結果之前。
- [ ] 沒有未控制的主要第三因素。
- [ ] 因果機制可描述且可觀察。
- [ ] 存在適當對照或比較基準。
- [ ] 沒有把相關性當成因果性。
- [ ] 沒有忽略反向因果。
- [ ] 結果在合理條件下具可重現性。

### 5.4 決策前提

- [ ] 目標已排序。
- [ ] 替代方案已列出。
- [ ] 成本、效益與風險使用一致單位比較。
- [ ] 受益者與受害者都被納入。
- [ ] 失敗時有停止或補救條件。
- [ ] 決策者擁有足夠授權與資訊。
- [ ] 不確定性已反映在決策門檻中。

### 5.5 公平與影響前提

- [ ] 不同群體的影響已分開評估。
- [ ] 弱勢或無法發聲者沒有被平均值掩蓋。
- [ ] 個人自主、隱私與尊嚴受到考量。
- [ ] 責任歸屬清楚。
- [ ] 風險沒有只被轉嫁給他人。
- [ ] 方案具有可申訴或修正機制。

---

## 6. 替代假設產生法

針對每項主張，至少從下列角度產生替代假設。

### 6.1 第三因素

```text
原主張：A 造成 B。
替代假設：C 同時造成 A 與 B。
需要檢查：控制 C 後，A 與 B 的關係是否仍存在？
```

### 6.2 反向因果

```text
原主張：A 造成 B。
替代假設：B 促使 A 發生。
需要檢查：時間順序、滯後效果與先行指標。
```

### 6.3 選擇偏誤

```text
原主張：採用方案 A 的群體表現較好。
替代假設：原本能力較高的群體更願意採用 A。
需要檢查：採用前差異與未採用者資料。
```

### 6.4 測量偏誤

```text
原主張：方案 A 提升了成效。
替代假設：A 改變了測量方式或回報行為。
需要檢查：獨立指標、盲測與長期結果。
```

### 6.5 基準錯置

```text
原主張：A 比 B 好。
替代假設：B 不是實際可行的替代方案，真正基準是 C。
需要檢查：真實決策中會被採用的替代方案。
```

### 6.6 範圍外推

```text
原主張：在情境 X 有效，因此普遍有效。
替代假設：效果只在 X 的特殊條件下成立。
需要檢查：不同人群、環境、規模與時間的結果。
```

### 6.7 反應性與適應

```text
原主張：政策 A 將持續產生結果 B。
替代假設：受影響者會改變行為，使 B 逐漸減弱或反轉。
需要檢查：長期追蹤與策略性回應。
```

## 7. 反方提問設計

高品質反方提問應遵循「最強版本」原則，不攻擊稻草人。

### 7.1 反方問題格式

```text
反方觀點：
反方最強理由：
它挑戰的前提：
需要的證據：
原主張可如何回應：
```

### 7.2 範例

```text
主張：
導入 AI 助理能提升員工決策品質，因此應全面導入。

反方觀點：
AI 助理可能提高依賴與自動化偏誤，反而降低員工獨立判斷。

反方最強理由：
即使平均正確率提高，員工可能在高風險情況下過度相信錯誤建議。

它挑戰的前提：
「整體平均表現提升」等於「每個重要決策都更安全」。

需要的證據：
不同風險等級下的錯誤率、人工覆核率、錯誤建議被採納的比例。

原主張可如何回應：
將全面導入修正為分階段導入，並設定人工覆核與停止條件。
```

### 7.3 不同強度的反方問題

**溫和澄清**

- 哪些條件下這項主張可能不成立？
- 是否有合理的人會根據相同資料得出不同結論？

**實質挑戰**

- 哪個替代解釋同樣能說明目前證據？
- 這項方案造成的主要副作用是什麼？

**壓力測試**

- 若最重要的前提錯誤，現有方案會造成什麼損害？
- 哪一個反例足以讓你停止推行？
- 在最不利但合理的情境下，結論是否仍值得採用？

## 8. 證據強度與結論措辭

依證據強度調整結論，不讓語氣超出資料。

| 證據狀態 | 建議措辭 |
|---|---|
| 只有直覺或個案 | 「目前只能提出可能性」 |
| 多個相關觀察 | 「資料顯示存在關聯，但尚不足以確認因果」 |
| 有對照但有重大限制 | 「在特定條件下提供初步支持」 |
| 多來源且方法一致 | 「現有證據支持此結論，但仍受以下範圍限制」 |
| 證據相互衝突 | 「證據不一致，暫不宜作出單一結論」 |
| 關鍵前提缺失 | 「結論取決於尚未驗證的前提」 |
| 主張與證據矛盾 | 「目前證據削弱，或不支持該主張」 |

不要將以下句型混用：

- 「沒有證據支持」不等於「已證明錯誤」。
- 「可能造成」不等於「已造成」。
- 「平均改善」不等於「對所有人改善」。
- 「統計顯著」不等於「實務上重要」。
- 「專家說法」不等於「適用於本案例」。

## 11. 完整示例

### 原始主張

> 公司應取消遠端工作，因為辦公室工作能提高生產力與團隊合作。

### 主張重述

- 原始主張：取消遠端工作能提升生產力與團隊合作。
- 可檢驗版本：在本公司目前的職務組成與管理制度下，全面要求進辦公室，相較於現行混合制度，能提高可衡量的工作產出與合作品質。
- 主要類型：因果主張、比較主張、規範主張。
- 適用範圍：本公司員工、特定工作職能、指定期間。
- 初始信心：證據不足。

### 隱含前提

1. 生產力主要受工作地點影響。
2. 辦公室中的即時互動會轉化為更好的合作成果。
3. 所有職務都能從辦公室工作中獲得相同收益。
4. 通勤時間、員工流失與彈性降低的成本小於預期收益。
5. 現行遠端或混合制度沒有其他可修正的管理問題。
6. 團隊合作可以用可觀察且一致的指標衡量。

### 蘇格拉底式問題

#### 定義

1. 「生產力」是以完成件數、品質、營收、交付速度，還是其他指標衡量？
   - 為何重要：不同指標可能導向相反結論。
   - 理想回答：指定期間、指標、基準與計算方法。

2. 「團隊合作」具體指協作速度、知識分享、衝突解決，還是會議參與？
   - 為何重要：辦公室出席率不能直接代表合作品質。
   - 理想回答：列出可觀察行為與結果指標。

#### 證據

3. 是否有本公司比較辦公室、遠端與混合制度的資料？
   - 為何重要：外部研究不一定適用於本公司。
   - 理想回答：依職能、團隊與時間分層的資料。

4. 生產力差異是否可能由管理方式、任務類型或員工自我選擇造成？
   - 為何重要：工作地點可能只是表面相關因素。
   - 理想回答：控制職能、資歷、團隊與任務複雜度後的比較。

#### 因果

5. 若辦公室工作是主要原因，改善非同步流程、文件制度或主管訓練是否也能產生相同效果？
   - 為何重要：需要比較工作地點與其他可能機制。
   - 理想回答：提出不同介入方式的可測試預測。

6. 辦公室互動增加後，是否真的改善交付結果，而非只是增加會議與可見度？
   - 為何重要：活動增加不代表結果改善。
   - 理想回答：將互動量與品質、錯誤率、交付結果分開測量。

#### 反方

7. 取消遠端工作的最大成本是否包括通勤時間、人才流失、招募範圍縮小與員工滿意度下降？
   - 為何重要：只計算收益會造成不完整比較。
   - 理想回答：量化或明確描述各項成本與不確定性。

8. 是否存在混合制度或針對高協作任務安排固定聚會，比全面取消遠端更低成本？
   - 為何重要：全面政策可能不是必要手段。
   - 理想回答：比較至少兩個替代方案。

#### 邊界

9. 哪些職務需要現場設備或即時協作，哪些職務不需要？
   - 為何重要：全面政策可能忽略職務差異。
   - 理想回答：依工作需求建立分級政策。

10. 若部分團隊在混合制度下表現更好，全面辦公室政策是否仍然合理？
    - 為何重要：測試政策是否把平均結果過度外推。
    - 理想回答：定義例外條件與停止條件。

### 替代假設

| 假設 | 可解釋的觀察 | 區分測試 |
|---|---|---|
| 管理流程不佳造成合作問題 | 團隊互動多但交付仍慢 | 改善流程後比較結果 |
| 任務類型造成生產力差異 | 需要現場設備的職務較適合辦公室 | 依職能分層分析 |
| 員工自我選擇造成差異 | 主動進辦公室者原本表現較高 | 比較制度變更前後與相似群體 |
| 辦公室增加可見度但未增加產出 | 出席率高、實際交付不變 | 使用結果指標而非出席指標 |

### 暫定判定

全面取消遠端工作的因果與比較證據尚未充分。較可辯護的修正版是：

> 針對需要高頻現場協作或特定設備的職務，試行明確的辦公室安排；同時以交付品質、週期時間、員工流失與合作指標評估，並與現行混合制度及其他改善方案比較。

## 12. 常見推理錯誤檢查

- [ ] 把相關性當成因果性。
- [ ] 把單一案例當成普遍證據。
- [ ] 把權威身分當成結論證明。
- [ ] 把情緒強度當成證據強度。
- [ ] 把二分法當成完整選項。
- [ ] 把對手最弱版本當成反方。
- [ ] 把未被反駁當成已被證明。
- [ ] 把平均效果套用到每個個體。
- [ ] 把短期結果外推為長期結果。
- [ ] 把「應該有效」寫成「已經有效」。
- [ ] 把方案目標偷換成方案成效。
- [ ] 把重新定義問題當成解決問題。
- [ ] 忽略執行成本與轉換成本。
- [ ] 忽略錯誤後果的不對稱性。
- [ ] 只尋找支持資料，沒有主動測試反例。

## 13. 高風險主張的額外檢查

涉及醫療、法律、金融、公共政策、人身安全、隱私或重大資源配置時，增加以下問題：

1. 若判斷錯誤，最嚴重的合理後果是什麼？
2. 誰有資格作出最後決策？
3. 是否需要合格專業人士或正式程序覆核？
4. 資料是否包含敏感個人資訊？
5. 是否存在不可逆或難以補救的後果？
6. 有沒有更保守但仍能取得部分收益的方案？
7. 什麼條件下應暫停執行並重新評估？
8. 是否清楚標示不確定性，而非提供過度確定的結論？

高風險情境的輸出應優先提供：

- 風險分級。
- 關鍵未知事項。
- 保守行動。
- 專業覆核需求。
- 停止與升級條件。
