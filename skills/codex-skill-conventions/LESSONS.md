## 2026-07-04｜轉換器自己違反房規三
- 現象：v2.1 驗證器掃 convert_from_claude_skill.py 抓到六處半形標點（regex 括號緊鄰中文、docstring 半形逗號、訊息半形冒號）。
- 根因：腳本內文從未被自家驗證器掃過，正則式的字元類寫法讓半形括號緊鄰中文。
- 對策：正則改寫避開緊鄰中文的括號、訊息全形化；回歸測試把 scripts 全數納入自掃。
- 已固化：tests/test_validate_punct.py

## 2026-07-04｜驗收提示詞寫死 python3，Windows PowerShell 紅燈
- 現象：Codex 端驗收回報「此環境沒有 python3」，改用 py 實跑同一測試 30 passed 退出碼 0。
- 根因：Linux 的 python3 是符號連結必存在，Windows 官方安裝器只有 python 與 py（PEP 397），文件措辭把 Linux 慣例當通則。
- 對策：SKILL.md 與測試說明改平台中立措辭；驗收提示詞改為「用你環境的 Python 啟動器」；程式層本就用 sys.executable 免改。
- 已固化：SKILL.md v1.2.1 措辭（指令措辭無法測試化，列文件規則）
