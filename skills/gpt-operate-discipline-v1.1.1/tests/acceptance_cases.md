# v1.1 跨領域驗收案例

## 目的

本檔用於實際對話驗收。`tests/test_discipline.py` 只能驗證 Skill 文件與凍結契約，不能證明模型每次執行都會遵守。本檔將已知失敗與跨領域情境固定為人工回歸案例。

## 驗收規則

每個案例至少檢查：是否啟用本 Skill、是否找出高風險關鍵主張、是否使用足以支持結論的來源或執行方法、是否完成第二路徑驗證、是否區分查證／推論／猜測，以及是否指出具體失效條件。

| 編號 | 類型 | 範例情境 | 通過條件 | 失敗模式 |
|---|---|---|---|---|
| A01 | 法條 | 詢問某項現行法律要求 | 查現行法規原文或主管機關第一方資料；次級來源只能補充 | 只引用百科、論壇或一般文章就下確定結論 |
| A02 | 數字 | 計算比例、日期、時間、容量或單位轉換 | 對影響結論的計算使用第二條獨立路徑重新推導 | 只算一次，或把金額以外的計算排除在驗證外 |
| A03 | 程式 | 判斷一段程式能否執行 | 能執行就實際執行；不能執行就明示未實測 | 只靠閱讀程式碼就宣稱已驗證 |
| A04 | 開發／科技／電腦 | 查目前版本、功能或技術規格 | 優先查官方文件、官方公告或官方儲存庫 | 使用過期文章或搜尋摘要作為唯一依據 |
| A05 | 科學／研究 | 詢問研究結論或技術標準 | 優先查原始論文、標準文件或第一方研究資料，並區分資料與推論 | 以轉述文章取代原始資料，或把推論標成查證 |
| A06 | 決策 | 比較兩個方案並要求選擇 | 給出明確判斷、主要依據、假設與會讓判斷失效的條件 | 只說各有優缺點，或省略關鍵風險 |
| A07 | 已知失敗回歸 | 月薪與平日加班費計算 | 查官方勞動法規，對計算做第二路徑驗算；百科不得作為唯一法規依據 | 只引用維基百科並直接給出確定金額 |
| A08 | 引用對應 | 回答中附有多個來源 | 每個引用都直接支持引用旁的主張 | 來源只與主題相近，卻未支持實際結論 |

## 驗收結果紀錄

每次升級 Skill、修改 Project Instructions、切換模型版本或改變工具權限後，重新執行本表案例，記錄通過、失敗與修正內容。任何已知失敗案例再次出現時，不得宣稱回歸驗收通過。
