# 交接文件模板（v1.0 凍結骨架）

以下九個 `##` 標題的**文字與順序為凍結契約**，照抄，不增不減不改字。各節下方的說明文字是填寫指引，實際產出時換成真內容；不合用的節寫「本節無內容。」保留節標題。

---

# Session 交接摘要｜〈一句話主題〉｜〈YYYY-MM-DD〉

## 〇、啟動指令（給下一個 session）

〈機器閘門三條：上限 200 字（去空白計）、編號條目 ≧3、第一個編號條目須同時含「讀」與「再回應」。開場定位句屬合法前導；祈使語氣為人工留意項。〉

你是接手本工作的新 session。請依序執行：①完整讀完本文件再回應；②載入第四節列出的 skill 與紀律並全程套用；③嚴守第五節邊界與第六節凍結契約，凍結項一律不動；④從第一節的「下一步」接手，動工前先向使用者一句話複述你的理解。

## 一、任務身分卡

- **在做什麼**：〈一句話〉
- **進度**：〈一句話，做到哪〉
- **下一步**：〈一句話，接手後第一件事〉

## 二、核心脈絡

〈背景、目標、關鍵名詞與代號定義。只放不知道就會誤解後文的內容。〉

## 三、工作流現況

- **已完成**：〈逐條，附檔案路徑／產出物／版本號〉
- **進行中**：〈逐條，附卡在哪〉
- **待辦**：〈逐條，依優先序〉

## 四、工作紀律與規範

〈生效中的 skill 名稱清單、房規要點、使用者偏好（標點、用詞、格式、語言）。寫名稱供新 session 自行載入，勿抄全文。〉

## 五、邊界與禁區

〈明講過不做、不碰、界外的事項，逐條附理由。〉

## 六、凍結契約與關鍵閘門

- **凍結契約**：〈逐條列已定版不可動的決定，附定版時點〉
- **關鍵閘門**：〈逐條列動工前必須停下確認的節點〉

## 七、已確認的對話決議

〈逐條列，每條標示出處等級：【使用者明示】或【AI 建議未確認】。〉

## 八、未決事項與風險

- **未決**：〈問了沒答、答了沒確認的事〉
- **風險與地雷**：〈新 session 最容易踩錯的兩三個地方〉
- **脈絡完整性**：〈若早段對話已截斷，在此誠實聲明〉
