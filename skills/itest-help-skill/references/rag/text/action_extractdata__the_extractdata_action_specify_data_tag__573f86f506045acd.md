# The ‘extractData’ action: Specify data tag and value to extract > The ‘extractData’ action: Specify data tag and value to extract

For the extractData action, iTest allows you to set data tag/value pair in the associated Description field, which is extracted and reported.

The extractData action requires these two arguments.

- Tag: (Field substitution disabled) Define the data tag to extract.

- Value: (Field substitution enabled) Define the value of the tag to be extracted and stored.

See Example test case steps with action extractData..

At runtime, the specified value is stored and associated with the extracted data tag. The extracted data from the test case step appear in the Response view and test report under the section Extracted Data.

See example report in Example report when action extractData is defined., “Test Reports.”
