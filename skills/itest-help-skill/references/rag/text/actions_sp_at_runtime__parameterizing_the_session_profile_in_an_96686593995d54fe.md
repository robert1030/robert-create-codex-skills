# Determining the device or session profile (dynamically) at runtime > Determining the device or session profile (dynamically) at runtime > Parameterizing the session profile in an open step

1. Create a topology (File > New > Topology).

1. 2

1. On the Topology editor, add a Device, and then add a session profile. On the Test Case Editor Steps page, add an open step. Now that you have specified a Local topology, the device appears as a choice in the drop-down menu for the Description.

At this point, the test case has some flexibility. Whenever you specify a different topology, you can select the appropriate device in the open step.
