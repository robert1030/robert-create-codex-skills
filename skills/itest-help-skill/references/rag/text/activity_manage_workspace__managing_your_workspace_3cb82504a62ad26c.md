# Managing your workspace > Managing your workspace

To facilitate use of approved shared files, your organization might ask you to import one or more existing projects or to create a new project or create a reference session profile. You perform these activities only occasionally on an as-needed bases using the Manage workspace page. See Importing a project, Creating Reference Session, and Creating a project for details.
