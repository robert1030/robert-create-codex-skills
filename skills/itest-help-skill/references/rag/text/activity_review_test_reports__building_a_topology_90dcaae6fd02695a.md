# Activity View > Activity View > Building a topology

The Build a topology page provides quick access to the tools that help you to create and edit topologies (as described in Overview: iTest Topologies, “iTest Topology Editor”):

- Working on the topology in the Topology editor

- Adding a session configuration to a device in the topology

- Starting (launching) a session with a device in the topology
