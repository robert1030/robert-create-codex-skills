# Activity View > Activity View > Building a topology > Messages

The Messages table lists all issues with devices and sessions in the topology. Double-click a message to select the device that has the issue. You can then use the tools in the Topology editor to fix the issue.

1. 1

1. When you click Finish, the Build a Topology activity page opens.



To create a new topology or open an existing one

See Creating a new topology or opening an existing one.



To start (launch) a session with a device in the topology

1. 1

1. On the Build a topology activity page, click Start Session.

1. 2

1. The Start Session dialog box opens. In the tree, open the device, select the session configuration, and then click Start. The session starts in the editor area.

> **Tip:** Tip While locating the session, to limit the number of devices that appear in the tree, type filter text in the box. Only session configurations that include the filter text are displayed.



To add a session configuration for a device

See Adding a session configuration for a device.
