# Activity View > Activity View > Developing a test case > Reviewing test reports > Source of the test reports and connection status

This line displays the source of the test reports: the Internal (built-in) database in your current workspace (the default source) or an external database. For more information, see Configuring Velocity iTest to save test reports to an external database.

If there is an issue with the database connection, then the error message appears here.
