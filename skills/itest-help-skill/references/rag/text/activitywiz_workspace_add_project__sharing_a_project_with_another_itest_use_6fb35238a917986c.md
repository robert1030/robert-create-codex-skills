# Creating a project > Creating a project > Sharing a project with another iTest user or with Customer support

Step 1

First, Export the project to an archive:

1. 1

1. Right-click the project and select Export. The Export wizard starts.

1. 2

1. On the Select page, the General > Archive File option is selected. Click Next.

1. 3

1. Click Select All.

1. 4

1. In the To archive file text box, type and/or browse to the archive file name.

> **Note:** Note Do not name the project “my_project” or “project”.

1. 5

1. Click Finish.

Now, your coworker can import the archive

To import the archive as a project:

1. Start iTest and create a new workspace: Click File > Switch Workspace.

When creating a new workspace in the iTest GUI, the interpreter language will be as set in Preferences: Spirent > General > General preference settings. For example, iTest defaults the interpreter language to Python.

1. 2

1. In the Workspace Launcher, click Browse. Create a new directory and return to iTest.

1. 3

1. In the Project Explorer, click} to collapse all projects.

1. 4

1. Delete the default projects to avoid duplicate names: Select (Ctrl-click) both the my_project and resources projects. Right-click and select Delete. On the Confirm dialog box, select Also delete contents in the file system.

The Project Explorer will now be empty.

1. 5

1. Click File > Import.

1. 6

1. On the Select page, select General > Existing Projects into Workspace. Click Next.

1. 7

1. On the Import Projects page, select Select archive file and then browse to the archive file.

1. 8

1. Click Finish. The project is imported.
