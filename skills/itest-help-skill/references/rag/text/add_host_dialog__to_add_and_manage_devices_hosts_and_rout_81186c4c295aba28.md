# To add and manage devices (hosts and routers) > To add and manage devices (hosts and routers)

When you select All Devices or Devices in the Model Objects tree, the session window displays the list of hosts and routers.

To perform an action on a host, router, or device, click one of the buttons in the toolbar. Descriptions for the actions appear in Host commands, Device commands, and Router commands.

| Toolbar button | Captured iTest action |
| --- | --- |
|  | addHost addRouter |
|  | deleteDevice |
|  | configureDevice |
|  | showHosts showRouters |
