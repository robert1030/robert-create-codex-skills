# Analysis rules: Validating responses and setting Pass / Fail > Analysis rules: Validating responses and setting Pass / Fail > Adding an analysis rule

The easiest way to add an analysis rule to a test case step is:

1. Select the step in the Test Case editor

1. 2

1. In the Response view, right-click in the appropriate blue box (that is, the data to validate)

1. 3

1. Select Analysis Rule Wizard
