# Adding and working with Global analysis rules > Adding and working with Global analysis rules > Editing Global Analysis Rules

1. 1

1. To make changes to a Global analysis rule, first select it in the list.

1. 2

1. Select the field that you want to edit.

1. 3

1. Click the field to edit and either edit the text directly (for What to extract and Details) or make a new selection from the drop-down menu (for Extract using and Perform).

1. 4

1. To modify the property settings of the rule’s extractors and processors. Click More to open the Analysis Rule Properties section.
