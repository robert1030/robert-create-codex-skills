# Adding and working with analysis rules > Adding and working with analysis rules > Testing Analysis Rules

Verify that your analysis rules are performing properly by executing the test case and reviewing the results in the Execution view (pass/fail result as expected, messages output properly, and so on) or the Step Issues view. Notice that the analysis rule is cited as the reason for the execution message with a Severity of OK .
