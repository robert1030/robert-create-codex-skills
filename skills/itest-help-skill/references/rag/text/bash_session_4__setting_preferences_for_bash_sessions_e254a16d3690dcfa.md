# Setting preferences for Bash sessions > Setting preferences for Bash sessions

To view or edit preferences, click Window > Preferences. On the Preferences page, click Spirent > Session Types > Bash (in Ubuntu and RHEL environments).

Configure iTest to auto-select the General information on setting and sharing preference settings appears in “Configuring iTest Preferences”.
