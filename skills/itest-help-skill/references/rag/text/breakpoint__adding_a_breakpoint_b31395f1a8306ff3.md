# Adding a breakpoint > Adding a breakpoint

During execution, when iTest encounters a breakpoint, it switches to the iTest Debugging perspective to facilitate single-stepping and other debugging tasks.

> **Tip:** Tip While execution is paused, you can perform interactive actions in the session to view the results. If a step is useful, you might later add it to the test case.
