# Analysis Rules: Validating Responses > Analysis rules: Validating responses and setting Pass / Fail > Adding an analysis rule

The easiest way to add an analysis rule to a test case step is:

![*](bullet_blue.jpg) <!-- image_ref -->

1. Select the step in the Test Case editor

1. 2 In the Response view, right-click in the appropriate blue box (that is, the data to validate)

1. 3 Select Analysis Rule Wizard
