# Popups（來源文件無 TOC 對應，依資料夾結構歸類） > popups/slide.html > slide

Slides the specified slider to the specified value.

Target Required. Controls Sliders. Command Numeric value of the slider. Step Properties Step Properties Index of the thumb: The index of the slider thumb Default: 0 Slide source: The item that performs the slide. Default: thumb Trigger: Mouse or Keyboard Default: Mouse Keycode: The key used if the trigger property was set to keyboard Default: [blank] Step Properties > Target Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15

For details, see the online help: Flex action reference.
