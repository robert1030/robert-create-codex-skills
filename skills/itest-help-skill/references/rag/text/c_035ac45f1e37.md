Automation interface — These interfaces are not meant for human interaction. These interfaces do not return a prompt and might not even echo what the user types. Hybrid interface — These interfaces echo what the user types and return a prompt. The prompt can be a normal one like login: or mydut> or could be TL1 end of message: < or ;
