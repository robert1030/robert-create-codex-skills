# SNMP Sessions > Loading your proprietary MIB files into iTest > Specifying a shared folder for MIBs

1. 1 Place all of your MIB definition files (uncompiled text format) into a particular directory. You must copy the individual files because subdirectories are not supported.

![](images/snmp_3.2.jpg) <!-- image_ref -->

1. 2 Open the device's session profile and click to view the Session Properties section.

1. 3 In the tree, click SNMP MIB Browser > MIBs.

1. 4 In the MIBs folder text box, type or paste the URI of the directory. For example, myhost:///mymibs or filename:///c/mymibs. (Remember, subdirectories are not supported.)

1. 5 Click Save.

1. 6 Exit and restart iTest.

1. 7 The standard MIB definitions provided by Spirent appear in the Mibs directory. If you point to a new location and want to continue to use the Spirent default MIBs, then you must copy the default MIBs from Mibs to the new location.
