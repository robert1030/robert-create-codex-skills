- Slot and port numbering starts with 1 (1-based).

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- When iTest returns responses to commands or captures your commands, it can display port references either in slot:portID format (the full port name, for example 2:3) or in sequential portIndex format (just the port identifier, for example, 5). The port format that is displayed in responses is controlled by the Display slot:port format in responses property. The port format used in captured steps is controlled by the Use slot:port format in captured steps property. See Spirent TestCenter properties.
