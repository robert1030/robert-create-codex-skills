# Parameters > Global Parameters > Global parameter file

When a particular parameter file is the Global parameter file, then any executing test case uses the parameters defined in the file. In addition, if the file references other parameter files, then the parameter definitions in the referenced files are included.

Note The only parameter file that is automatically used by test cases is the Global parameter file. You cannot specify a particular parameter file for a test case in iTest. You can, however, use iTestRT to specify a particular parameter file (that is, not the Global parameter file) for use by a particular test case.

The Global parameter file applies to all test cases in a workspace.
