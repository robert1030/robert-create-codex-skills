# Session Profiles > Session Profiles: Quick instructions > 第2段

- **To:**：Do This:
- **Specify that a session profile is a reference session profile**：Configure the session profile in the normal way (as described in Defining a session profile (configuring the session settings)) and then specify one additional property setting: On the Start page, check This is a reference session profile.
- **Add a new session profile**：Container: Path to the new session profile file. Default: /my_project/session_profiles File name: Name of the session profile document that you are creating (.ffsp filename extension).
- **Base a new profile on an existing profile**：
- **Edit a session profile**：See Editing session profiles
- **Select Language used to create the session profile**：Select the language that will be used to create the session profile. Click the Settings tab. On the Settings page, use the default language displayed (as set in Preferences: Spirent > General > General preference settings, Chapter , “Configuring iTest Preferences”) or select a different language from the list. When you select Language as Python, you may export the entire iTest test case (FFTC) to a Python script.
- **Copy / Paste profile**：In the Project Explorer or Favorites view, right-click the session profile and select Copy. Paste into the appropriate folder.
- **Delete profile**：In the Project Explorer or Favorites view, right-click the session profile and select Delete.
- **Move profile**：In the Project Explorer, select the session profile and then drop it into the new folder. Alternatively: In the Project Explorer, right-click the session profile and select Move. In the Folder Selection page, specify the new folder.
- **Rename profile**：In the Project Explorer or Favorites view, right-click the session profile and select Rename.
