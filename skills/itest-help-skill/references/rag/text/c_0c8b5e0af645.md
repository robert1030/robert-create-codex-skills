# YAML Step Editor > YAML Step Editor Overview

iTest provides a list of commands for CRUD operations and Insert YAML Step wizard to add the commands. The YAML Step Editor easily formulates a YAML document and also helps manipulate the YAML response. That is:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Formulate a YAML document from the TestCase Editor (See also “Test Case Editor”). A Wizard provides an easy point-and-click way to perform CRUD operations on nodes in a YAML document.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Manipulate the YAML response. iTest provides a programmatic way of performing CRUD operations on block response of a procedure (see also “Procedures”, section Defining a procedure).
