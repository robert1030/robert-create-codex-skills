# Bash sessions > Session profile property settings for Bash sessions (Ubuntu and RHEL) > Limitations of the Record feature:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- For the Alt key, iTest captures only the last key pressed. For example, Alt+q is recorded as “q”.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Function keys are not recorded.
