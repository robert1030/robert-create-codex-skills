# Capturing Manual (Interactive) Sessions > Overview: Creating a test case by capturing interactive sessions > Saving captured sessions or captured items as a Capture report > Saving captured sessions as a Capture report

![*](bullet_blue.jpg) <!-- image_ref -->

1. In the Capture view, select one or more sessions (use Ctrl-click and Shift-click to select multiple items).

![](images/capture_tasks_2.4.jpg) <!-- image_ref -->

1. 2 Click Save As Capture Report (alternatively, right-click the selection and select Save As Capture Report).

1. 3 On the Save Capture Report dialog box, in the Container field, specify the path to the report that you are about to create.

1. 4 iTest suggests a filename. Specify the name of the file. Click Finish.

1. 5 iTest creates the document and then selects it in the Project Explorer.
