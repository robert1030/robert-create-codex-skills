# Using Git in iTest > Restore Deleted Files

This section describes how to recover a file that was deleted in iTest from Git.

![*](bullet_blue.jpg) <!-- image_ref -->

1. Go to iTest Development View, and delete a file you previously Staged.

1. 2 Right-click on the test_cases folder and then click Recover from Local History.

![](images/26-recover_from_local_history.png) <!-- image_ref -->

1. 3 The Recover from Restore from Local History dialog opens. Select file to recover and click Restore.

![](images/27-window_recover_from_local_history.png) <!-- image_ref -->

1. 4 The restore file is populated in the Project Explorer in Development view as illustrated below

![](images/28-restored_file.png) <!-- image_ref -->

You may delete the restored file from the Git Staging section, modify the restored file as required and commit again, if required.

1. 5 Right-click file in the Staged Changes section of the Git Staging page to delete files that are not required.

![](images/29-Staged_file_right_click.png) <!-- image_ref -->

You may also perform other tasks options available on the right-click menu in the Git Staging > Staged Changes section.
