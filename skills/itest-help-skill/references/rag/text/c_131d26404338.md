# The iTest Builder > Refactoring iTest resources (renaming, moving, or deleting files) > To rename, move, or delete a iTest resource

![*](bullet_blue.jpg) <!-- image_ref -->

1. Select the file (or multiple files using Ctrl-click or Shift-click).

1. 2 Right-click the selection and then select Rename, Move, or Delete.

1. 3 In the Rename Resource or Move Resource or Delete Resource dialog box, click Preview to see the structured list of all iTest resources that will be affected by the change. Individual references to the resource that will change (for example, a run step to a test case that is being renamed) are listed under each file.

By default, all affected resources are selected. You have the option to uncheck the resources that should not be updated with the new name or location of the changed resource.

> **Note：** Note All references to a deleted resource become validation warnings in the affected dependent file (because there is no way to update a reference to a deleted file).

1. 4 Click OK to apply the changes.
