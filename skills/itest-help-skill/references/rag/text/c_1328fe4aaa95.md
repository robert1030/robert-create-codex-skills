The name of each Spirent iTest action corresponds directly to the name of the Spirent TestCenter Tcl API function that it executes. See the Spirent TestCenter Tcl API Object Reference for details on operation and usage.

If the Spirent TestCenter Tcl command associated with the Spirent iTest step/action requires arguments, then you can view and set the argument values in the Step Properties section.

Each Spirent iTest action returns the same values as the corresponding Spirent TestCenter command.
