# Wireshark sessions > Session profile property settings for Wireshark sessions > Wireshark

Note Wireshark already uses the tshark –i, –c, –w and –f options to capture packets and save to a temporary capture file. Arguments that change the output may prevent capture from working.

- **Capture network interface name**：Optional. Specify an interface name to capture packets. Use the show interfaces command to see which interfaces can be selected. To select an interface, specify part or all of an interface name or description. Use wildcard “*” characters within the name to find an interface based on a more complex search pattern. Default: <blank>. Capture starts on the first non-loopback interface. Use the show interfaces command to see which interfaces can be selected.
- **Capture filter**：Optional. Specify a filter that determines which captured packets are to be loaded into memory. Example: host 10.155.2.3 and tcp See http://wiki.wireshark.org/CaptureFilters for a description of the capture filter syntax. Default: <blank> All packets are captured
- **Display filter**：Optional. Specify a filter that determines which captured packets are loaded into memory for display in the responses to show packets and show details. Example: arp or icmp The Display filter can be more selective than the Capture filter. Refer to http://wiki.wireshark.org/DisplayFilters for a description of Display filter syntax. Default: <blank> All captured or loaded packets are loaded into memory.
- **Advanced options, capture**：Optional. Specify additional tshark options for use during capture. See http://www.wireshark.org/docs/man-pages/tshark.html for a description of the options. Alternatively, enter “tshark help” from a command prompt or shell. Default: <blank>
- **Advanced options, display**：Optional. Specify additional tshark options for use while loading captured packets into memory. See http://www.wireshark.org/docs/man-pages/tshark.html for a description of the options. Alternatively, enter “tshark help” from a command prompt or shell. Wireshark already uses the tshark –c, –r, –T and –R options to load captured packets. Default: <blank>
- **Path to tshark**：Wireshark sessions use tshark to support network capture and file loading. tshark is installed by the iTest installer. Specify a path here if you did not install tshark in the default location or used a non-standard name for the application. Default: <blank>
