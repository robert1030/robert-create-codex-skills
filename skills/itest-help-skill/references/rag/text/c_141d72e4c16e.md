# Response Maps: Returning Data from Responses > Response Map editor Block page: Creating a block map

On the Block page, you identify tokes in an unstructured response.

Let us map the response to the show interfaces command. The response includes multiple blocks of data — one block supplies VLAN data and another block supplies FastEthernet data. Because there are two distinct block formats in a typical response, we will create two block mappers — one for VLAN blocks and one for FastEthernet blocks.

> **Tip：** Tip You can set block mapping preferences. See Setting preferences for response mapping.

> **Important：** Important When you add, delete, or make any change to a custom parser for a block map, follow the procedure for reparsing the blocks as described in Response Map editor: Parsers page.
