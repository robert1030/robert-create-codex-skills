# Analysis Rules: Validating Responses > Global Analysis Rules page

On the Global Analysis Rules page, you define analysis rules that apply to all steps in a test case. Analysis rules are described in Analysis rules: Validating responses and setting Pass / Fail.

The Global Analysis Rules page appears in several editors. Click the Global Rules tab on the editor to open the page.
