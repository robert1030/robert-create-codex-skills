1. 4 It is mandatory to provide a valid URI. Click change and when the Destination Git Repository dialog displays, browse to the location and provide the correct destination URI and Repository path as illustrated.

![](images/Git_in_iTest.8.jpg) <!-- image_ref -->

![](images/07-git_remote_repo_created.png) <!-- image_ref -->
