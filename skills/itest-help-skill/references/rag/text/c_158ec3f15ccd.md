# Parameters > Using Parameters in Properties or Steps > Inserting a parameter into a property or test case step > About the ‘param’ and ‘profile’ commands

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- The param command returns the value of a parameter defined in a test case or parameter file.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- The profile command returns the value of a parameter defined in a session profile.

For example, the parameter you inserted is replaced at runtime by the value of the parameter

In this example, as the Type of the parameter [param AUTOSERVER/password] is Secret, iTest prompts for the value to be entered at runtime. See also About the Parameter Type ‘Secret’.
