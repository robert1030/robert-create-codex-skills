# Response Maps: Returning Data from Responses > Why create a response map? > A response map can store sample responses for emulation.

One of the options for the emulation feature is that you can specify an external source for the emulated response to a step. You specify the source response as a particular sample that is stored in a response map or response map library.

For a full discussion of implementing emulating responses, see “Testing with Emulated Sessions”. For instructions on creating a response map for this purpose, see Creating a response map: Instructions.
