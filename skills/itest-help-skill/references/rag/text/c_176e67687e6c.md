# iTest Runtime: iTestRT > iTestRT command reference > Test Report options > 第2段

| 欄位1 | 欄位2 |
| --- | --- |
| --report URI | Generate test report at the specified URI. The following substitutions are supported in the text of the URI: {tcfilename}, {datetime}, {date}, {time}, {tcpath} (test case path) {jobfilename}, {jobstart} The report format will be determined by the specified file extension and iTest supports 5 types of format: HTML, Text, XML, XML_Raw and PDF. The file extension supported is predefined in file extension.txt with appropriate text (html, xml, xml_raw, or txt) and located in test_report_templates/format_name/. If the extension appended does not match any predefined format, HTML format will be used, the file name with extension are kept as provided, and any existing XSLT stylesheet is applied. In addition, the test report may be compressed when publishing to the Quality Center server. Example --report project://my_project/stressTests/{tcfilename}{datetime}.html file:/C:/Workspace/my_project/<folder>/<filename>.<extension> |
| --quiet | Suppress output from test report generation. |
| --format URI | Specifies the templates to use to format HTML, PDF, TEXT, XML, or XML_RAW reports. If you use this option, then you do not need to export the resources project to an itar file. To use the option: Example You may copy the custom templates and specifiy the URI during execution. file:/C:/Workspace/my_project/<folder>/<filename>.<extension> |
| --report URI ?format | Generate test report at the specified URI in the specified format. Example: --report file://C:/?XML_Raw The format output will be xml and the report name will be testcasename+time stamp.xml. --report file://C:/abc?XML_Raw The format output will be xml and the report name will be abc.testnumber.xml. The report format will be determined by the specified file extension and iTest supports 5 types of format: HTML, Text, XML, XML_Raw and PDF. The file extension supported is predefined in file extension.txt with appropriate text (html, xml, xml_raw, or txt) and located in test_report_templates/format_name/. If the extension appended does not match any predefined format, HTML format will be used, the file name with extension are kept as provided, and any existing XSLT stylesheet is applied. In addition, the test report may be compressed when publishing to the Quality Center server. iTestRT auto-detects JSON response data, and if the response is valid JSON, iTest formats the response as JSON prettiy print. The above applies to both test case and test suite. |
| --chartcolor <ChartColor> | Specify the color palette to be used to generate charts. if no chart color is specified, the color palette iTest is used by defaul. You can use the itestrt --help to list the available color pallette: Chart Color Options: --chartcolor <chartColor> Specify color for chart's series <iTest, Beach,Bermuda, Fall, gentleman, marine, Party, Playground, Vacation, Velocity> Example usage: --itar file://D://workspace/ChartColor/ --test project://my_project/test_cases/new_chart_testCase.fftc --licenseServer 100.100.10.1 --report file://D:/workspace/ChartColor/result --chartcolor iTest |
