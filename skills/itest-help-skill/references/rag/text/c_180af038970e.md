# Analysis Rules: Validating Responses > Analysis Rule Wizard: Extract page > Regular expression applied to the text of the response

This selection has the effect of setting What to extract (the Extractor property) to regex for the resulting analysis rule.

1. 1 When you select this option, the sample response appears.

1. 2 Select the text in the response. The wizard applies the appropriate regular expression and displays it in the Regex text box.

1. 3 Optional. Modify the regular expression if needed and then click Next
