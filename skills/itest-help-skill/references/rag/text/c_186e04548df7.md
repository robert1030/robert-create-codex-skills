# Response Maps: Returning Data from Responses > Making use of existing response map libraries: Chaining response maps > Chaining response map libraries

![*](bullet_blue.jpg) <!-- image_ref -->

1. In the Project Explorer, right-click the response map library that is specified for the session (the primary library) and select Properties. In the example, we right-clicked my_project.

1. 2 Select Project References in the list.

1. 3 On the Project References section, check the response map libraries that should be chained.

![](images/response_mapping_5.1.jpg) <!-- image_ref -->

1. 4 Click OK. Both R5000_router_response_maps and S100_switch_response_maps will now be chained to my_project.
