yamlDelete allows you to Delete a YAML node from the document. Select option on Select YAML Action dialog to Delete a node from a YAML document. The Delete a node option allows you to select a node from an existing YAML document to be deleted.

For details, see the online help: YAML Editor Wizard, section Delete a node from YAML document.
