# Spirent Avalanche sessions > Spirent Avalanche session window > Information on Cluster Units and Provision List

The tables display the Client and Server clusters from the test.tcl script, as well as the provision list from the configuration script (config.tcl). The information appears if you configure the session to use the Avalanche-generated Tcl test scripts. This option ignores the iTest session profile settings and executes the Avalanche scripts directly. This enables you, for example, to make use of the latest Spirent cards or appliance models. See Executing Avalanche-generated ‘Tcl test’ scripts directly (Pass‑Through Mode).
