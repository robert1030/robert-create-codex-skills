# Controlling execution flow: Loops, If/Then, and Switch > Overview: Loops and flow‑control logic > Overview: Loops and flow‑control logic > The foreach loop

A foreach loop performs the steps within the loop for each value in a specified set of values.

Example: foreach A {1 3 5}
