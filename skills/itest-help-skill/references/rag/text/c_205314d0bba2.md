# Using iTest Help > Searching help > To search help:

![*](bullet_blue.jpg) <!-- image_ref -->

1. From the main menu, select Help > Search

1. 2 Type in the word or phrase for which you want to search

1. 3 Click Go or press Enter. The list of results will be displayed below

1. 4 To view the content of a topic in the list of results, click it

Alternatively, you can search from the Help window using the Search field at the top of the window.
