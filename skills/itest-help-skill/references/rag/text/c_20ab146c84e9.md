# About the iTest Window > About workspaces > Making a copy of a workspace for Source Code Management

To make a copy of a workspace to send to Spirent or to check into Source Code Management do the following:

1. 1 Click File > Export.

1. 2 Select General > File System. Click Next.

1. 3 On the File System page, click Select All.

1. 4 Browse to a destination for the workspace copy.

1. 5 Click Finish.

A copy of the essential files of your test case, without history information, will be copied to the new destination. You can then check it in.
