# Using iTest Help > Quick Tips

This topic presents quick overviews of several iTest tasks.

![*](bullet_blue.jpg) <!-- image_ref -->

![](images/using_help.1.jpg) <!-- image_ref -->

1. Start direct-to-test capture by clicking

1. 2 Open an existing session profile and start a session with a device (this opens a new Session window).

1. 3 In the Session window, issue commands to the device.

1. 4 Close the Session window.

![](images/using_help.2.jpg) <!-- image_ref -->

1. 5 Stop the capture process by clicking .

1. 6 iTest opens a quick Add To Test Case wizard to let you save the steps immediately. You have the option of inserting steps into an existing test case or of saving whole sessions as steps in a new or existing test case.

1. 7 The captured steps appear in the test case editor (creating the basic test case).

![](images/using_help.3.jpg) <!-- image_ref -->

1. 8 You can now replay the test case by clicking (A new Execution window appears)

1. 9 When execution ends, the Session window closes and a test report is displayed,

1. 10 Now you can edit the test case as needed to add analysis for pass/fail, logic functions such as for loops, if statements, procedure calls, and so on.
