# Test Suites > Configuring a test group: The Test Group page > Editing a test group > Global Setup / Cleanup properties

- **Global setup test**：Specify the test case to execute before executing the test cases in the test group. The test case typically brings all devices and applications in the test group to a known state before testing starts.
- **Global cleanup test**：Specify the test case to execute after executing the test cases in the test group. The test case typically brings all devices and applications in the test group to a known state after testing finishes.
