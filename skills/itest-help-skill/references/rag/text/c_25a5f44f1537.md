# About the iTest Window > Creating a project > Sharing a project with another iTest user or with Customer support

Step 1

First, Export the project to an archive:

1. 1 Right-click the project and select Export. The Export wizard starts.

1. 2 On the Select page, the General > Archive File option is selected. Click Next.

![](images/ui_concepts_2.1.jpg) <!-- image_ref -->

1. 3 Click Select All.

1. 4 In the To archive file text box, type and/or browse to the archive file name.

> **Note：** Note Do not name the project “my_project” or “project”.

![](images/ui_concepts_3.2.jpg) <!-- image_ref -->

1. 5 Click Finish.

![*](bullet_blue.jpg) <!-- image_ref -->

Now, your coworker can import the archive

To import the archive as a project:

![*](bullet_blue.jpg) <!-- image_ref -->

1. Start iTest and create a new workspace: Click File > Switch Workspace.

When creating a new workspace in the iTest GUI, the interpreter language will be as set in Preferences: Spirent > General > General preference settings. For example, iTest defaults the interpreter language to Python.

1. 2 In the Workspace Launcher, click Browse. Create a new directory and return to iTest.

![](images/ui_concepts_3.3.jpg) <!-- image_ref -->

![](images/ui_concepts_3.4.jpg) <!-- image_ref -->

1. 3 In the Project Explorer, click} to collapse all projects.

1. 4 Delete the default projects to avoid duplicate names: Select (Ctrl-click) both the my_project and resources projects. Right-click and select Delete. On the Confirm dialog box, select Also delete contents in the file system.

The Project Explorer will now be empty.

1. 5 Click File > Import.

1. 6 On the Select page, select General > Existing Projects into Workspace. Click Next.

1. 7 On the Import Projects page, select Select archive file and then browse to the archive file.

1. 8 Click Finish. The project is imported.
