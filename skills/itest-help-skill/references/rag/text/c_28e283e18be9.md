# Scheduling Execution > Overview: Scheduling execution using Jobs > Velocity iTest > Exiting Velocity iTest while jobs are running or scheduled to run

If you try to exit Velocity iTest while a job is running, a dialog box prompts whether to cancel execution and quit Velocity iTest or to continue running Velocity iTest so that execution can continue.

If you exit Velocity iTest while jobs are scheduled to run, then Velocity iTest exits. When you restart Velocity iTest, the process of running scheduled jobs resumes. Velocity iTest does not run jobs whose start time was missed while Velocity iTest was not running.
