# Response Maps: Returning Data from Responses > Adding a new response map library

![*](bullet_blue.jpg) <!-- image_ref -->

1. In the Project Explorer, use one of the following methods to add a new library:

![*](bullet_blue.jpg) <!-- image_ref -->

- Right-click anywhere in the explorer and then select New > Response Map Library.

![*](bullet_blue.jpg) <!-- image_ref -->

- Click File > New > Other, and then select Response Map Library.

![*](bullet_blue.jpg) <!-- image_ref -->

- Click New, select Other, and then select Response Map Library

1. 2 On the New Response Map Library Project dialog box, type the name of the library.

1. 3 Click Finish.
