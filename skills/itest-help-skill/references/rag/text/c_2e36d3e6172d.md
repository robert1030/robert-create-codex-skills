# iTest Commands > Commands that are commonly used in field replacements > query command: Inserting the results of a query > Syntax > Examples Tcl > [query . versionMinor]

Uses the response for the current step and performs the query versionMinor.

> **Note：** Special case When certain events are fired during execution of a step (for example, OnConnectionFailed), actions may occur as a result. Some events fire during the execution process before mapping of the step has occurred. In those cases, [query . myQuery] will not work because the response has not yet been mapped.
