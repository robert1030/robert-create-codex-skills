# YAML Step Editor > YAML Steps in Test Case > Example Step properties and Response of yamlGet

The YAML Wizard inserts the yamlGet step as you selected in Query a YAML document. The Step Properties populate the name of the YAML document, and location of your selection (see Query a YAML document: Select node location)

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Go to Step Properties > EXEC yamlGet Properties > YAMLGet Step Properties to view the document name.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Go to Step Properties > EXEC yamlGet Properties > YAMLGet Step Properties > Location to view the document index, node path and Key/index content value.

![](images/yaml_tc_yamlGet.png) <!-- image_ref -->

After test execute, the Response View displays the value as selected in the Query a YAML document: Select node location.

![](images/yaml_query_response_view.png) <!-- image_ref -->
