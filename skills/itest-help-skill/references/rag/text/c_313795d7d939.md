# Capturing Manual (Interactive) Sessions > Capture reports > Viewing captured items in the Capture Report editor

At any time, you can view the details of selected captured items in the Capture Report editor.

![*](bullet_blue.jpg) <!-- image_ref -->

1. In the Capture view, select one or more captured items (use Ctrl-click and Shift-click to select multiple items).

![](images/capture_tasks_16.1.jpg) <!-- image_ref -->

1. 2 Click View As Capture Report in the Capture view toolbar. The Capture Report editor opens and displays all selected items.

![](images/capture_tasks_9.2.jpg) <!-- image_ref -->

1. 3 To save the Capture report, click Save As in the main toolbar.
