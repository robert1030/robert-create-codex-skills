If a port is specified for the SNMP port property in the session associated with the step, then listTraps lists all traps that have been received on the port since executing the first SNMP step (or previous listTraps calls, depending on the Clear Traps After List property setting as described in a moment). Traps on the ports specified in preferences are not included in the response. If no port is specified for the SNMP port property, then traps on the ports specified in preferences are included in the response. If no port is specified for the SNMP port property and no port is specified in preferences, then all traps are included in the response.
