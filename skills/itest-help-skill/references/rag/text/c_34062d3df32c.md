# Form Maps > Creating form maps for use with GUI testing test applications > Step 1: Obtaining the structure of the web page (the XML map)

To build a form map for a web page, you first obtain the XML map of the page. You capture the map of a page with a single click. For example, let's map Google's home page.

![*](bullet_blue.jpg) <!-- image_ref -->

1. In a Web Selenium session, go to http://www.google.com.

1. 2 Right-click Web Page and select Selenium > Snapshot.

![](images/forms_selenium_snapshot.png) <!-- image_ref -->

As a result of taking snapshot the map of HTML code of a web page appears in a Response view.

![](images/forms_mapHTMLCode_inResponseMap.png) <!-- image_ref -->

We now have the XML map of the page. (We mapped the only window on the web page — the window named MainWindow.)
