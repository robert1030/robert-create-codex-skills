# Analysis Rules: Validating Responses > Analysis Rule Wizard: Extract page > Query on the response

This selection has the effect of setting What to extract (the Extractor property) to query for the resulting analysis rule.

1. 1 When you select this option, the wizard lists the mapper XPath queries (XPath queries that are auto-generated by the response map) and their results as they normally appear in the Queries view.

1. 2 Select the query. The wizard displays it in the Regex text box.

1. 3 Optional. Customize the Regex if needed and then click Next.
