# Bash sessions > Setting preferences for Bash sessions > Spirent > Session Types > Bash

Specify the Bash interpreter used for Bash Session.

Note This is the path used when no path is provided in the Session profile.

- **System**：Default. When System is selected, iTest automatically detects from system's path .
- **Use specified Bash Installation**：Indicates that iTest will select the Bash interpreter from the path specified.

Note This is the path used by all sessions, when no path is specified in the Session profile.
