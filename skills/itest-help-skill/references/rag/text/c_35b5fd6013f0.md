- **Session Start Mode**：Default: Start in a compatible session window Start in current window: Start each new session in the iTest window, and not in a new session window. You can use the window management buttons to layer or tile the sessions. Start in a compatible session window: Start each new session in a session window of the same general type. For example, any CLI session type can open in the session window of any other CLI session type (they are all terminal-based sessions that typically appear in simple text windows). You can use the window management buttons to layer or tile the sessions. Create a new window for each session: Start each new session in a new session window. As a result, one session window will open for each new session
- **Display a warning ... and Always open the ‘Execute a QuickCall’ wizard ...**：These property settings are associated with iTest QuickCalls. See QuickCall preference settings for details.
