# iTest Views > Cached Secrets View

The Cached view displays the Secret type parameter values cached in memory for the duration of the iTest session (while the iTest GUI is running in a given workspace).

The Cached Secrets contains the secrets value entered for a parameter (in the parameter file and test case) and enables you to run multiple tests in the same iTest session and maintain independent secrets per-file. See also

The unique secret value are stored per parameter file and test case and show their URI.

> **Note：** Note iTest uses the Cached Secrets and does not prompt you to enter the Secret type value upon subsequent test execution within the same iTest session.

You may remove any and all cached secrets while in an iTest session.
