# About the iTest Window > Project Explorer > Performing Actions from Project Explorer

The iTest Project Explorer Right-click action can apply to the entire project or the selected test cases/resources. This action is particularly useful if you have a large workspace with several projects and testcases within each project. For example, select the project, test case folder, or multiple test cases, select Agent Requirements and add a common requirement, update an existing requirement, or delete a previously applied requirement.
