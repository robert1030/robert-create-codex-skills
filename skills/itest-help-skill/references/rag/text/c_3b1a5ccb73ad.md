Shifts a column in a grid (table) from the specified old index to the new index.

Target Required. Controls Data grids (tables). Command Old index and new index (separated by a space character). Step Properties Step Properties Trigger: Use the Mouse or Keyboard to perform the action. Default: Mouse Step Properties > Target Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15

For details, see the online help: Flex action reference.
