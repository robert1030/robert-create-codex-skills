# Form Maps > Associating a form map library with a session

Once you have created form maps and a form map library to hold all associated form maps, you must associate the form maps with a session profile or device to cause iTest to display the available targets in the drop-down lists in Context and Target fields.

1. 1 Edit the session profile or device for the session.

1. 2 Specify the Form Map Library:

![*](bullet_blue.jpg) <!-- image_ref -->

- On the Misc page of the Session Profile editor

or

![*](bullet_blue.jpg) <!-- image_ref -->

- On the Map Libraries page of the Testbed editor.

1. 3 Save the updated session profile or device.
