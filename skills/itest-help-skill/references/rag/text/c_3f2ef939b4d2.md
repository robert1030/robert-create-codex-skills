# Using iTest Help > Navigating help topics > Using the Help window

The Help window is a window separate from the workbench used exclusively for browsing, searching, and printing help. To open the window, select Help > Help Contents from the menu. This opens the help window with the Contents view visible, which shows the table of contents.

![](images/using_help_2.01.jpg) <!-- image_ref -->

To navigate the Help window:

![*](bullet_blue.jpg) <!-- image_ref -->

1. Find the topic you want to read in the table of contents by clicking to expand the subtopics.

1. 2 Most topics provide a list of links to related topics at the bottom. Follow these links to learn more.

![](images/using_help_2.02.jpg) <!-- image_ref -->

![](images/using_help_2.03.jpg) <!-- image_ref -->

1. 3 Use Go Back and Go Forwards to navigate back and forth. These behave the same way as in Web browsers.

![](images/using_help_2.04.jpg) <!-- image_ref -->

![](images/using_help_2.05.jpg) <!-- image_ref -->

The different parts (views) of the Help window can be maximized to take up the entire window. To maximize a frame, click Maximize in the toolbar, or double click the view's title header. To return the view to its original size, click Restore or double click the title header again.

To print a topic from the Help window:

![*](bullet_blue.jpg) <!-- image_ref -->

1. Select the topic in the navigation frame.

![](images/using_help_2.06.jpg) <!-- image_ref -->

Click Print in the Help toolbar.

![*](bullet_blue.jpg) <!-- image_ref -->

1. Select the desired printer settings, and click Print.
