To select content that includes the equal, colon, or comma characters (= : ,), use the backslash character \ to escape the character.

For example, to select "23:18", use "23\:18".

? marks a single character in the content as wild.

* marks the remainder of the string as wild.

For details, see the online help: Creating Web test case steps.
