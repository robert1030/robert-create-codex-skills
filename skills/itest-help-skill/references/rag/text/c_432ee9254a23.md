# Test Reports > Sharing Test Reports > Configuring Velocity iTest to save test reports to an external database

By default, Velocity iTest saves test reports to a database within your workspace. Velocity iTest users that use other workspaces might find it cumbersome to access test reports in your workspace. To make it easier for everyone on your team to share report data, you can configure Velocity iTest to save test reports to an external centralized database that is accessible to all Velocity iTest and iTestRT users rather than to the default ‘standalone’ database within your workspace.

> **Note：** Note To use an eternal database, your system administrator must first set up a database server. For instructions, see the chapter on “Setting up an external database for storing Velocity iTest Test Reports” in the Velocity iTest Installation Guide. In addition, when upgrading Velocity iTest, the administrator must also update the database schema (also described in the Velocity iTest Installation Guide).
