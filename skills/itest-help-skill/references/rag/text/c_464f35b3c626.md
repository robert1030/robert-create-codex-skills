# Test Reports > Sharing Test Reports > Setting preferences for Test Reports > Spirent > General > Test Reports > Auto-Export Test Reports > 第2段

- **Export test reports after execution**：Select option to ensure that iTest generates a test report document after each test execution. If not selected, iTest does not automatically generate report documents. In either case, you can manually save any test report as a file as described in Uses for test reports.
- **Export test reports for test cases executed in 'run' steps**：Check the box to include test report data for any test case that is executed as the result of a run step in the parent test case.
- **Formats to generate**：If you checked Export test reports after execution, then specify each document format to generate. You can specify any or all formats (HTML, PDF, Text, XML, XML_RAW). For format information, see Test report file formats.
- **Folder for test reports**：Specify a directory/path to automatically save the test reports for each testcase. The default folder for test report documents is: project://{project} You may use the following path variables in different combination to define relative or absolute path for automatically exporting and saving the execution reports.
