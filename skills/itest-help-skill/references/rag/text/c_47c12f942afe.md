# Configuring iTest Preferences > Preferences: Spirent > Editors

These are the general settings that control behavior of iTest editors.

- **Show warnings encountered when loading a file.**：While loading iTest documents, display warnings. Default: checked
- **Do not show dialog encouraging to use secret parameters when typing into password fields**：When selected, iTest does not prompt you to use secret parameters when entering a password. Default: not selected
- **Do not request confirmation to clear unmasked fields**：When selected, iTest does not display a dialog requesting you to confirm whether you wish to unmask field and clear content. Default: not selected
- **Content-assist delay (milliseconds): Default 0**：Enter a value to automatically display content-assist. For example, content assist will be displayed when you type or a Step Action when you press Ctrl+Space or automatically, depending on your setting here.
