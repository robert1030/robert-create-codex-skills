Action Name Target Command property value Description selectAdditional Required Required selectAdditional is similar to select, and is used for multi-selection lists. selectAdditional adds to the current selection, but does not unselect the existing selection (select steps do unselect the existing selection). The Command property specifies the set of labels to select in addition to the current selection. Use whitespace to separate labels.

For details, see the online help: Creating Web test case steps.
