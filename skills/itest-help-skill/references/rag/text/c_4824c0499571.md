# Capturing Manual (Interactive) Sessions > Capture reports > Viewing a Capture report

You can open a Capture report in any of the following ways:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- In the Project Explorer, double-click a report.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Right click a report in the Project Explorer and then select Open.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Select a report in the Project Explorer and drop it into the Editor area (the area in which the Start a New Session page normally appears).

The Capture Report Editor opens to the Details page.
