# Python Session Level Control Library > Password Encrypt Tool

You may use iTest > Tools > Encrypt to generate encrypted passwords, copy and paste the encrypted value into the SLC script.

Go to iTest > Tools > Encrypt .

![](images/EncryptMenu.png) <!-- image_ref -->

The Encryptor Dialog displays. Enter the value to be encrypted.

Original value: Enter the value to be encrypted. The value is generated as you begin to type the value.

Encrypted value: The Encrypt tool generates a value which you may copy and paste in your script.
