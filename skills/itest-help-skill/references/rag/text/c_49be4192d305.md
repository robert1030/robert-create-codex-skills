| --velocityPassword password | The password for the specified user |

| Certificate Validation: Use velocityDisableSslValidation or velocitySslKeyStore parameter to disable or enable certificate validation. iTestRT opens WebSocket for connection and validates certificate located in Velocity. To connect to Velocity, download ssl.crt file from Velocity Configure page. Then it should be imported to KeyStore used for validation. Default java keystore is used. You may use your custom keystore by using it in the parameter '--velocitySslKeyStore'. You may also disable certificate validation (--velocityDisableSslValidation) If both parameters are absent in the command line, the certificate will be validated by using the default Java trust store or key store. |  |
| --velocitySslKeyStore | The keystore file with an imported certificate. You may use keytool to import a certificate into keystore: For example: keytool -import -alias <unique_value> -file <path_to_certificate_file> -storepass <keystore_password> -keystore <path_to_keystore_file>. //keytool -storepass argument For example: --velocitySslKeyStore client.jks;changeit;jks |
| --velocityDisableSslValidation | Use the --velocityDisableSslValidation parameter in the command line, iTestRT will trust any SSL server certificate (No Validation). |
