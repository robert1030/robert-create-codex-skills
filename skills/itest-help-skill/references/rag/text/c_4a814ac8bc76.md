# iTest Topology Editor > General Local Topology Operations > Topology editor: Properties view, Device tab

![](images/topologies_7.1.jpg) <!-- image_ref -->

Select any device to cause the Device tab to appear. Use the Device tab to add cards or sub-devices to the device and to add ports to the device, to a sub-device, or to a card. In addition, you can specify property and attribute values for devices, cards, and ports..

> **Note：** Note Generic Devices (the kind of sub-device that you can add to a device) have no default @Type attribute value. You can set the attribute value as needed (for example, workstation),
