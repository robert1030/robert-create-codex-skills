# 未分類（無 TOC 對應） > Add your iTest Project Folders to Git > 第1段

This section provides instruction to add your iTest project folders to Git. This involves adding the project to the local repository and then uploading (push) to the remote repository.

Step 1

Add your project folder to Git (local repository)

![*](bullet_blue.jpg) <!-- image_ref -->

1. Go to iTest Development Perspective (select from the icons at the top right-hand side of iTest window).

1. 2 From the Project Explorer, select project to be added to Git. Right-click select Team > Share Project.

![](images/08-Add_project_to_git_local.png) <!-- image_ref -->

1. 3 Select Git when the Share Project dialog opens. The Configure Git Repository dialog opens populated with the project folder you selected.

![](images/Git_in_iTest.02.jpg) <!-- image_ref -->

Select the appropriate Repository from the list and Path within the repository (if required)

1. 4 Click Finish. The selected project is added to Git and the Project Explorer tree view displays as follows.

![](images/10-Project_added_toGit_itest_Explorer.png) <!-- image_ref -->

![*](bullet_blue.jpg) <!-- image_ref -->

Add your project folder to Git (remote repository)

After your project is in the Git local repository follow these steps to push it to the remote repository.

![*](bullet_blue.jpg) <!-- image_ref -->

1. Select project added to Git. Right-click select Team > Commit.

![](images/Git_in_iTest.04.jpg) <!-- image_ref -->

1. 2 The Git Staging tab displays with local project ready to be staged, committed, and pushed to the remote repository.

![](images/Git_in_iTest.05.jpg) <!-- image_ref -->

1. 3 Expand the Git Staging tab, select and right-click the files in the Unstaged Changes section of the Git Staging page.

![](images/Git_in_iTest.06.jpg) <!-- image_ref -->

The project/files are staged as illustrated below. Add a commit message for clarify and verification purposes. Click Commit. .

![](images/14-Project_staged.png) <!-- image_ref -->

After you click Commit, go to the Git Repositories page and notice that the project/files are ready to be added/pushed to the remote repository as illustrated below. You may view the commit history to verify the commit...

![](images/16_view_commit_history.png) <!-- image_ref -->

![](images/17-View_commit_history.png) <!-- image_ref -->

1. 4 Right-click the local commit and then click Push Branch. Make sure that the project is pushed to the required repository.

![](images/git_merge_rightClick_menu.png) <!-- image_ref -->
