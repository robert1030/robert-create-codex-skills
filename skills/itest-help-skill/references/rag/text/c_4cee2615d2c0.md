# Analysis Rules: Validating Responses > Analysis Rule Wizard: Comparison page > Step 2. Specify the expected value or values

Specify the value that you want to compare the value from the response to.

- **Using**：This value tells the wizard how to interpret the value that you specify in the Value field. A specified value: The value in the Value field is a particular string value or numerical value The name of a local variable: The value in the Value field is a local variable to have a particular string value or numerical value. The value of a Global variable: The value in the Value field is a Global variable to have a particular string value or numerical value. The name of an argument to this procedure: The value in the Value field is the name of an argument to the procedure. (The selected step is in the procedure.) The value of a parameter: The value in the Value field is the name of the parameter to evaluate. The name of a parameter: The value in the Value field is the name of a parameter.
- **Value**：Specify the value to compare the response data to. If you selected data in the sample response before starting the wizard, then it appears here.
