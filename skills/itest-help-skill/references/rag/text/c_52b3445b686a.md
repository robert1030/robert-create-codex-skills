# Test Case Editor > Requirements page on the Test Case Editor > Test case editor: Requirements page

Define the Agent capability requirement to be used with the Test Case exported to Velocity Core. Use the Requirements page to add agent capabilities requirements. (You can also delete and update the list.)

> **Important：** Important Requirements are associated with the test when exported as iTAR and imported in Velocity Core. The requirements will be available as options in the Agent requirements selection list.
