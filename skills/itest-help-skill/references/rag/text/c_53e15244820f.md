To add a a step that executes a QuickCall

Adding a QuickCall step to a test case is exactly like adding any other step:

1. 1 The open step for the session must refer to a topology device or session profile that is associated with a QuickCall library. See First, specify the QuickCall library to associate with a device or session profile for details.

![](images/quickcalls_2.1.jpg) <!-- image_ref -->

1. 2 Add a step. Click in the Action cell and then select the QuickCall from the list of actions. The QuickCall group appears after the open/close actions and before the EXEC actions.

1. 3 The Description cell is populated with any arguments and argument values that are defined for the QuickCall. For details, see About arguments in QuickCall steps.
