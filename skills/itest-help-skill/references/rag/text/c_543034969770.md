# Session Profiles > Defining a reference session profile

To specify that a session profile is a reference session profile, you configure the session profile in the normal way (as described in Defining a session profile (configuring the session settings)) and then specify one additional property setting:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- On the Start page, check the This is a reference session profile check box.

From now on, when you are defining other session profiles, the reference session profile will appear in the drop-down Inherit from list on the Session Profile editor’s Start page.
