# Working with NTAF sessions in Velocity iTest (Obsolete and Deprecated) > To work with NTAF-enabled sessions on Velocity iTest > Login settings

IMPORTANT

Note You can set the authentication information in the NTAF preferences page in iTest. The values are not used when an application login page asks for credentials.

- **NTAF server**：Specify the IP address or hostname of the NTAF server (provided by your IT administrator).
- **User / Password**：Specify the XMPP credentials to use to enable the NTAF Proxy service to access the NTAF server as a client. The credentials represent the Proxy service as a client on the NTAF server. Remember that iTest is a different client on the NTAF server and therefore has a different username.
- **Automatically sign me in Prompt for login every time Do not auto-login**：Specify what should happen when you open a session with the NTAF server: Apply the specified credentials or open this dialog box and request credentials.
