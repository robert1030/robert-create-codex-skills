# Response Maps: Returning Data from Responses > Response Map editor: Samples page > Adding additional samples to a response map document

You might choose to add more than one sample response to a response map in the following situations:

![*](bullet_blue.jpg) <!-- image_ref -->

- The response for a command can appear in more than one mode or format, depending on the state or configuration of the device

![*](bullet_blue.jpg) <!-- image_ref -->

- The response to a particular command differs slightly for different versions of the device’s software. By designing a single response map that can map the responses from multiple software versions, you do not have to prepare several response maps.

![*](bullet_blue.jpg) <!-- image_ref -->

- The sample will provide the emulated response to a step or session. For an overview of emulation, see “Testing with Emulated Sessions”.



Recommended method: Click ‘Add This Sample to an Existing Response Map’

![](images/response_mapping.08.jpg) <!-- image_ref -->

1. 1 On the Response view, click Add This Sample to an Existing Response Map .

1. 2 Once you specify the response map in a dialog box, iTest adds the new sample and opens the response map document in the Samples page of the Response Map editor.

1. 3 In the Sample name field, type a name. We recommend that you use a name that reflects the particular software revision or other command category that results in the different response. If you’re adding a second or third format of a response, you might include text that identifies the format of the response.

![](images/response_mapping.09.jpg) <!-- image_ref -->

1. 4 Save the response map document by clicking Save in the main tool bar.



Not Typical: Add the sample manually

![*](bullet_blue.jpg) <!-- image_ref -->

![](images/response_mapping.10.jpg) <!-- image_ref -->

1. On the Samples page, click Add to add a new sample definition.

1. 2 In the Sample name field, type a name. We recommend that you use a name that reflects the particular software revision or other command category that results in the different response. If you’re adding a second or third format of a response, you might include text that identifies the format of the response.

1. 3 Drop or paste the appropriate text into the Command and Response text boxes.

![](images/response_mapping.11.jpg) <!-- image_ref -->

1. 4 Save the response map document by clicking Save in the main tool bar.
