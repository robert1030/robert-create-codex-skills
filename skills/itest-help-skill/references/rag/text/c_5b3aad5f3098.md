# iTest Topology Editor > General Local Topology Operations > Topology editor: Properties view, Topology tab > Topology properties that communicate design history

Use the Topology tab to document the topology’s design history for the benefit of coworkers. Most values are auto-generated. You can specify the following values:

- **author**：Default. Name of the user who created the topology. This may not display when the topology is imported.
- **creationTool**：Default: com.fnfr.itest.topology.tbml.diagram. The tool used to create the topology.
- **creationToolVersion**：Version of iTest. Example: 7.3.0.201812050825
- **dateCreated**：Topology creation date. Example: 2018-12-05T14:50:52.144-08:00. (this field may not display for imported topologies).
- **dateModified**：Topology modified date. Example: 2018-12-05T14:54:39.808-08:00
- **isAbstract**：Default: Y. Identifies an abstract topology.
- **notes**：Optional. Additional text that describes the topology to make its usage clear to coworkers. Default: Blank.
- **rmGuid**：Indicates the velocity topology ID. Example: 9eadd88-ff5a-41a0-8693-152fd7f7f1fd
- **@Description**：Optional. Type text that describes the topology to make its usage clear to coworkers. The @ symbol denotes that this value is a TBML attribute.
- **@Name**：Optional. Type a one-line “friendly” name for the topology. For example, LabA_Switch_environment or Routers,TrafficGen, and Linux box This text appears in the Favorites view for the topology. The @ symbol denotes that this value is a TBML attribute.
