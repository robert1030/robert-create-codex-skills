# Popups（來源文件無 TOC 對應，依資料夾結構歸類） > popups/stretchColumn.html > stretchColumn

Stretches the specified column to the specified width.

Target Required. Controls Grid (table). Command The index of the column and the value of the new width of the column (separated by a space character). Step Properties Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15

For details, see the online help: Flex action reference.
