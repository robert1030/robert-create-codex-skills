Simulates a mouse scroll wheel.

Target Required. Controls All controls. Command Numeric value (+/-) to scroll. Step Properties Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15
