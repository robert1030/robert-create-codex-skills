# About the iTest Window > Switching between perspectives > Adding a new option to the Open Perspective menu

> **Note：** Note Follow these steps to add an iTest Expert Perspective to the short list only when working with old workspaces.

You may add a new menu option to the Perspective menu. For example, to add iTest Expert to the Open Perspective menu, do the following when in each of these perspectives:

![](images/open_perspective.png) <!-- image_ref -->

![*](bullet_blue.jpg) <!-- image_ref -->

1. Go to iTest Development perspectives (see Switching between perspectives).

1. 2 Click Reset Perspective: Window > Perspective > Reset Perspective

1. 3 Repeat Step 1 and Step 2 from these perspective: iTest Expert and iTest Development.
