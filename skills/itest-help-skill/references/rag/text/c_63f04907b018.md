# iTest Runtime: iTestRT > iTestRT command reference > File Utilities options

The ‘file utilities’ options enable you to list files in projects.

The long forms of option names begin with: com.fnfr.open.runtime.fileutils.optionModule

Note Use a single slash character after “file:” in the URI. For example:

Note Use a single slash character after “file:” in the URI. For example:

| 欄位1 | 欄位2 |
| --- | --- |
| --cat URI | Prints the contents of the specified URI file:/C:/Workspace/my_project/<folder>/<filename>.<extension> |
| --fileutils.list URI | Prints a list of the files for the specified URI file:/C:/Workspace/my_project/<folder>/<filename>.<extension> |
| --recursive | Causes the list of files to be recursive |
