# iTest Topology Editor > Velocity command > Commands that return information from Velocity

The Velocity group of commands returns information about resources and ports on the topology that is active during the current reservation.

See About Tcl commands and About Python commands in “iTest Commands”.

Important:

Using square brackets ([]) in Python syntax:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Required in session steps and session profiles fields.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Not required in non-session steps (eg: eval).

> **Note：** Note Square brackets are required if using Python and Velocity subcommands, when editing a session profile of a device in a topology imported from Velocity.
