# Field Replacements > Field replacements: Substituting values into properties and commands > Example: Using an iTest Python interpreter command in a field replacement

1. The text strings [param(‘PortType’)] and [param(‘SubIndex’)] appear in the following step:

![](images/field_replacements.2.jpg) <!-- image_ref -->

The [param(‘PortType’)] syntax means “Before running this step, replace all of the text in this field with the value of the PortType parameter”

1. 2 At runtime, step preprocessing replaces the fields. As a result, iTest issues the following command displaying the type of values, ins:

```
PortType = FASTETHERNET
```

SubIndex = 0

1. 3 At runtime, step preprocessing replaces the fields. As a result, iTest issues the following command:

show interfaces FASTETHERNET 1/0indicator
