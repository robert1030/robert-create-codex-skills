# Parameters > Pages on the Parameter editor > Parameter editor Include page: Including additional parameter files

On the Include page, you specify parameter files whose parameter definitions should be included in this parameter file.

So, at run time, the test case uses both the parameters that you define on the Parameters page and the parameters that are defined in the included parameter files (the files in the list). The files are merged in the listed order. For additional details, see Adding a parameter definition while inserting parameters.
