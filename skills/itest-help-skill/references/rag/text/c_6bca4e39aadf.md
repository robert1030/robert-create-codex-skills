# Test Reports > Sharing Test Reports > Sharing test reports as files

To ensure high performance, Velocity iTest does not, by default, automatically save test reports as files. So, to share a test report, you must first export it as a file. There are two options:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Export or auto-export the report as an HTML, PDF, Text, XML, or XML_RAW. This is useful for sharing with someone who does not use Velocity iTest.

![*](bullet_blue.jpg) <!-- image_ref -->

- See Manually saving a test report as an HTML, PDF, Text, XML, and/or XML_RAW file.

![*](bullet_blue.jpg) <!-- image_ref -->

- You can set a preference to auto-export a test report whenever a test case executes. See Setting preferences for Test Reports for details on configuring auto-save.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Export the report as a compressed Velocity iTest Test Report file. When you export a report as a compressed file, other Velocity iTest users can open it in the Test Report editor. You can email the resulting file to a coworker or tell the coworker the path of the file (typically, in a shared workspace under revision control). The coworker then uses Velocity iTest to import the file into their workspace. See Exporting a test report as a compressed file (fftz format).

The person importing the compressed file will follow the instructions in Importing Velocity iTest test reports that are in compressed file format (fftz).

> **Tip：** Tip You have the option to save only selected sections of any report when you export it. See Customizing the content of a test report.

For descriptions of the various formats, see Test report file formats.
