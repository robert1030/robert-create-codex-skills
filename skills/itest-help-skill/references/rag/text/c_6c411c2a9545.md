- **Ignore patterns**：Select the listed patterns and click Apply or Apply and Close for the changes to take affect or click Restore Defaults or Cancel to discard your changes. To ensure that iTest files in a project are not classified as derived, the following ignore pattern are selected by default: When pushing iTest content to a Git repository, none of the iTest project files of the pattern selected are added to .gitignore file.
- **Add Pattern...**：Click Add Pattern... and on the Add Ignore Pattern dialog enter the file name or path pattern that should not be in version control. Enter a name or path pattern (* = any string, ? = any character). Click OK to save pattern or Cancel to discard any changes.
- **Remove**：Select an Ignore Pattern and click Remove to delete the pattern from the list.
