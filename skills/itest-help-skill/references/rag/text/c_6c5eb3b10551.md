# SNMP Sessions > Configuring trap settings

iTest receives traps in two ways:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- At any time, whether a iTest SNMP session is running or not, iTest receive traps on the ports specified in the iTest preferences (Window > Preferences.Spirent > Session Types > SNMP). See Setting preferences for monitoring SNMP traps.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- When a iTest SNMP session is running, it receives traps only on the port specified for the Trap Port properties in the session profile. See SNMP MIB Browser > Traps and SNMP MIB Browser > Step Defaults > Traps.
