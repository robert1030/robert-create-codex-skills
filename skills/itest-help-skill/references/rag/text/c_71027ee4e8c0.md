# Reserving devices for execution > Making a reservation (Reserving a resource or topology for execution)

Making a reservation means:

![*](bullet_blue.jpg) <!-- image_ref -->

1. You (the requester) request a reservation: You specify (to the reservation system) the requirements for resources and the timeframe that the resources are needed.

1. 2 Depending on availability of the resources at the specified time, the system either:

![*](bullet_blue.jpg) <!-- image_ref -->

- Accepts the request and adds it to the reservation queue as pending

or

![*](bullet_blue.jpg) <!-- image_ref -->

- Rejects the reservation request

> **Note：** Note The resources identified in a reservation request are not actually made available to the requester until the reservation is activated (as described in a moment).



To make a reservation

![*](bullet_blue.jpg) <!-- image_ref -->

1. Do one of the following:

![*](bullet_blue.jpg) <!-- image_ref -->

- With the topology open in the Topology editor, right-click on the canvas and select Reservations > Reserve

![*](bullet_blue.jpg) <!-- image_ref -->

- With the topology open in the Topology editor, click Topology > Reserve

1. 2 On the New Reservation dialog box, provide the following information and then click OK. All of the information will appear in the Reservations view for this reservation.

- **Name**：Specify a meaningful name for the reservation
- **Duration**：Specify the time period during which the topology should not be available for tests
- **Topology**：Select the topology to reserve.

1. 3 A confirmation message appears. If the reservation could not be made, the message provides information that should help you to change the request so that the reservation can be made.
