# Form Maps > Form map libraries > Creating a new form map library

Whenever you create a form map, you specify the form map wizard that it should reside in. iTest creates the form map library if it does not yet exist.

In the case that you want to create an entirely new form map library:

![*](bullet_blue.jpg) <!-- image_ref -->

1. Click New > Other > Form Map Library.

1. 2 In the New wizard, select Form Map Library and click Next.

1. 3 In the Project name box, type the name for the new library and click Finish.
