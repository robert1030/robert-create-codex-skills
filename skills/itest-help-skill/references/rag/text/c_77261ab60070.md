# Parameters > Merging parameter definitions from multiple sources > How parameter definitions from multiple sources are merged at run time > Merge order

Parameters can be defined in several places. iTest combines the parameter definitions from all sources before execution. Here's how it works with default settings:

![*](bullet_blue.jpg) <!-- image_ref -->

1. First, parameters defined in the Global parameter file are loaded onto the heap.

1. 2 Parameter files that are included with in the Global file are loaded (again, the parameters defined in each file are loaded first, followed by any referenced files, recursively). The files are loaded in the order in which they are listed in the parameter Global file.

1. 3 The parameters defined in the test case are loaded.

1. 4 The parameters defined in the session profiles to be used for execution are loaded.
