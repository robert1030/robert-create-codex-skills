# Popups（來源文件無 TOC 對應，依資料夾結構歸類） > popups/selectText.html > selectText

Selects the specified text in a text input. To unselect all selects, set the start index and end index to be 0.

Target Required. Controls Text input controls. Command Start index and end index of the selection (separated by a space character). Step Properties Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15

For details, see the online help: Flex action reference.
