# Wizards and Dialog boxes > iTest Import wizard > iTest

- **External iTest Session**：Import iTest sessions from another instance of iTest (perhaps sessions that were created by coworkers).
- **Test Report**：Import test reports (perhaps reports that were generated by coworkers). See Sharing test reports as files
- **Selenium IDE test case (HTML)**：Import Selenium test cases. These test cases are intended for simple record-and-playback of interactions with the browser. The following lists the Selenium IDE commands recognized in iTest.
- **open type(AndWait) answerOnNextPrompt addSelection(AndWait) removeSelection(AndWait) click(AndWait) chooseCancelOnNextConfirmation**：chooseOkOnNextConfirmation(AndWait) runScript(AndWait) select(AndWait) selectWindow submit(AndWait) goBack(AndWait) fireEventAndWait waitForPopUp mouseOver(AndWait)
