# iTest Views > Displaying a view > Working with perspectives

When performing certain tasks, iTest displays a dialog box asking whether you want to switch to a different perspective. Switching is recommended because the suggested perspective is optimized for the task you are initiating. For example, if you create a new PyDev project from the Expert perspective, a dialog appears prompting you to switch to the PyDev perspective, as shown below.

![](images/view_changePerspectivePyDev.png) <!-- image_ref -->

If you want to switch back to your original perspective, select it from the list in the upper-right corner of the iTest window, as described in Switching between perspectives).

When switching to another perspective, if you previously selected Remember my decision to avoid being prompted again, you can reverse that choice by configuring a preference to display the dialog whenever a perspective switch occurs. See See Setting preferences for perspectives for details. You can also configure additional perspective-related preferences on that page.
