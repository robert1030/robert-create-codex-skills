To add a summarize step

![*](bullet_blue.jpg) <!-- image_ref -->

1. Add a step and select an Action of summarize.

1. 2 Leave the Description cell (the value of the Command property) blank.

1. 3 In the Step Properties section, open the EXEC summarize Properties > Summarize properties group and specify the Response format for the summarize step (as described above).
