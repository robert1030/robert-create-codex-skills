# Sharing iTest Resources > Exporting test cases and other iTest documents > Export document as HTML, XML, or text

![*](bullet_blue.jpg) <!-- image_ref -->

1. In the Project Explorer, right-click the document and click Export. The Export wizard opens.

1. 2 On the Select page, select iTest > Documents as HTML or text. Click Next.

![](images/export_as_html_txt_01.png) <!-- image_ref -->

1. 3 The Export page confirms the file to export. Click Next.

1. 4 On the Report Style page, for Stylesheet folder, specify the output file format. Some file types offer additional options like summary and detail versions. Click Next.

1. 5 On the Report Output Location page, the File name field confirms the filename with the appropriate filename extension. You can modify the output folder (Location) and File name as needed.

Optional: Check View the generated report in editor to view the resulting file in an editor in iTest.

Click Next.

1. 6 Click Finish. The file is added to the specified folder and, if specified, the file opens in an editor, as shown in this example.

![](images/sharing.2.jpg) <!-- image_ref -->
