# Configuring iTest Preferences > Exporting and importing iTest preference settings

You can export the entire set of iTest preference settings or a specified group of settings so that a coworker can import the settings.

1. 1 Click File > Export.

1. 2 On the Export page, select General > Preferences. Click Next.

![](images/preferences.1.jpg) <!-- image_ref -->

1. 3 You have the option to export all preference settings or any particular settings that you specify. Browse to a location in the file system and provide a name for the output file that will hold the settings (it will have an .epf filename extension). You have the option to overwrite existing preferences files. Click Finish.

![](images/preferences.2.jpg) <!-- image_ref -->
