# Test Cases > Overview: Creating a test case > Inserting captured steps into an existing test case

Here's a fast way to add steps that iTest captured during an interactive session:

1. 1 In the test case, set a breakpoint where you want to start adding steps.

1. 2 Execute the test case.

1. 3 When execution stops at the breakpoint, select the current session window (if it is CLI, it will be stopped at a prompt).

1. 4 Enter any commands that you want to add at this point.

![](images/test_cases_3.1.jpg) <!-- image_ref -->

1. 5 In the Execution view, click to complete execution.

![](images/test_cases_2.2.jpg) <!-- image_ref -->

1. 6 In the Capture view, select the last session. Click to save it as a new procedure.

> **Note：** Note When you convert manual steps into test case steps, iTest uses the combination of Session name from the session profile and the unique session number for the day (for example, myDUT5) to create the Session ID that appears in the Session cell in the Test Case editor.
