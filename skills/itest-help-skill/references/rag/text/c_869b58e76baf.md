# Popups（來源文件無 TOC 對應，依資料夾結構歸類） > popups/test_step.html > teststep

For the EXEC teststep action, the system interprets the text in the associated Description field as a test step to the user. Nothing is performed when teststep action. However you have an option to export to a text file all steps those use teststep action as a single test step.
