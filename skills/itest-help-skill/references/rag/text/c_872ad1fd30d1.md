# About the iTest Window > About workspaces > Folders > 第1段

Within projects, you can organize your working files (session profiles, capture reports, test cases, test reports, topologies, and so on) into folders and subfolders. The default structure works for many users; you may want to move, add, delete, and rename folders and subfolders to suit your needs — you can organize the files into folders any way you want.

For example, you might further subdivide the session profiles in the Sessions folder into groups of sessions (for example, so you can start all sessions in a folder for particular tests or topologies).

- One of the default projects in the workspace is named my_project. The icon looks like a hanging folder to indicate that it's a project that contains the folders.
