A switch construct allows the value of an expression to determine the flow of execution.

A legal switch construct is made up of a contiguous sequence of:

One switch step One or more nested case steps Zero or one nested default step. The default step must be the last step in the construct. Comments are allowed at any point.

Any other sequence is illegal.

See the online help for examples and details.
