# iTest Runtime: iTestRT > iTestRT command reference > Checking out a runtime license

To execute a test case, test suite, or job, iTestRT must obtain a runtime license by providing the license server address and port number.

Tip Set up multiple license servers in the options file.

| 欄位1 | 欄位2 |
| --- | --- |
| --licenseServer hostAddress:portNumber | hostAddress is the hostname or IP address of the license server host (typically provided by your IT administrator). iTestRT uses port 27000 if you do not specify a port number. To use more than one license server, use the --licenseServer argument multiple times at the command line. Example >iTestRT --licenseServer lshost.acme.com:-1 --test project://my_project/test_cases/test1.fftc |
