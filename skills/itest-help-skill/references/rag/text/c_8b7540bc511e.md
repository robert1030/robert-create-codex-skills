# iTest Views > Response view > Response view operation while developing test cases

The easiest way to add an analysis rule to a test case step is to select the step in the Test Case editor, right-click in the appropriate blue box in the Response view, and then select Insert Analysis Rule Using Wizard.

> **Tip：** Tip You can add a rule only if the step is selected in the Test Case editor. You cannot add a rule if the step is selected in the Test report editor.
