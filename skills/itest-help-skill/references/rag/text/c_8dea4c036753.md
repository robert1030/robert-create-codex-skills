# Spirent TestCenter REST sessions > Spirent TestCenter REST session window > Converting Spirent TestCenter Test cases to STC REST Test cases > Providing STC REST Session Properties

1. 1 Enter details as described in the table below on the STC REST Session Properties Settings window.

![](images/02-Rest_tool_STC_REST_session_propertiesSettings.png) <!-- image_ref -->

- **REST Session Properties settings**：Description
- **Apply default value for new session properties**：Select to apply default values to the new REST session properties.
- **STC URL**：Enter a valid STC Lad URL. A tool tip shows the valid the URL and port syntax.
- **Session Name**：Enter the session name for the STC REST sessions.
- **Owner ID**：Indicate the owner of the new REST sessions.
- **Command Set**：Select the STC version command set to be used for the REST sessions.
- **Create or replace new session on connect**：Select to indicate that a new session should be created or an existing session should be replaced when connection to the STC Lab is established. Default: unselected.
- **Terminate session on disconnect**：Select to indicate that a session should be terminated when connection to the STC Lab is terminated. Default: selected.

1. 2 Click Finish to display list of files converted to STC REST session for your review (Completed page).

![](images/03_Rest_tool_complete_conversion.png) <!-- image_ref -->

1. 3 Click Close to exit the window.

Note You may also use the REST commands to convert STC Session test case to STC REST test case via the REST console.

![](images/04-Rest_tool_Console_log.png) <!-- image_ref -->
