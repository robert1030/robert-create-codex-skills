Opens the popup or drop-down list.

Target Required. Controls Controls with popup or drop-down menus, for example combo boxes, menus. Command None. Step Properties Step Properties Trigger: Mouse or Keyboard used to open the popup. Default: Mouse Step Properties > Target Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15
