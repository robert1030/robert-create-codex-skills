# Parameters > Defining and managing parameters > Creating structure for parameters (working with nodes) > To add a node

1. 1 Click the Parameters tab on the appropriate editor: Test Case editor, Session Profile editor, or Parameter editor.

1. 2 Select the node that the new node should be a child of. For a top-level node, select the appropriate location in the tree.

![](images/parameters_5.2.jpg) <!-- image_ref -->

1. 3 Click to add a node as a child of the selected node. (The node is first added as a parameter, but as soon as you complete the next step, it becomes a node.)

![](images/parameters_3.3.jpg) <!-- image_ref -->

1. 4 Select the newly-added item and then click . The parameter is converted into a node (the parent of the new node). The Value setting is dimmed because nodes do not have values.
