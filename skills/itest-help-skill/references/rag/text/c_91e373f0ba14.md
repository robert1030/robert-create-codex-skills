Action Name Target Command Command property value setFilePath Not Required Required While uploading a file, a dialog asks you to specify the file to upload. While downloading a file, a dialog asks you to specify the path/filename in which to place the file. Use the setFilePath command to specify the path/filename when uploading or downloading files. setFilePath sets the value of the input text field as though you typed it in or clicked a Browse button and navigated to the location. If there is currently text in the field, then setFilePath replaces it. The Command property (Description cell) specifies the text to set in the text box. If Command is empty, then an empty string is set. Note: While manually adding a setFilePath step to a test case: Place the setFilePath step before the step that causes the File dialog to appear. For example, add the setFilePath before the click step that clicks the link that launches the download. When you save captured steps into a test case, iTest creates the steps in the correct order.
