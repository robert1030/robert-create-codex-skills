# Field Replacements > Where you can use field replacements > 第2段

> **Important：** Important The Command property is special in that it can also perform variable and backslash substitution and a command might be multiline for some protocols. To allow you to specify the behavior exactly as you need it, iTest provides the For the Command field, perform command, variable, and backslash substitutions check box. See Step Properties section: General properties group for details.
