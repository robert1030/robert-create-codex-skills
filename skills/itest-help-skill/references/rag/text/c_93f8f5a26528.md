# Prompts (in CLI sessions) > About inheriting prompt definitions > To start with the inherited prompts, edit them, and add prompts as needed

![*](bullet_blue.jpg) <!-- image_ref -->

1. Starting from the default setting (checked), uncheck the Include inherited prompts check box.

The Prompts list displays all inherited prompts.

1. 2 To edit a prompt definition, select it in the list and then change settings as described in the Prompt properties table.

![](images/prompts_2.3.jpg) <!-- image_ref -->

1. 3 To add a new prompt definition, click Add . Set the prompt properties as described in the Prompt properties table. A more prompt property setting appears in Terminal > Replay > Step Defaults > More. Another prompt property setting appears in Terminal > Replay > Step Defaults > Completion.

> **Note：** Note Because the formerly inherited prompts are now a part of the new profile, they are not updated when the prompts in the reference session profile change.
