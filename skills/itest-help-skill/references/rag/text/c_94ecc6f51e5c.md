# Test Reports > Test reports overview > Test Reports view > Working in the Test Reports view > Filter

![](images/test_reports_2.22.jpg) <!-- image_ref -->

The button allows you to populate the view with the results of a database search (that is, only reports that meet the search criteria are listed). You can further limit the reports that appear in the view by applying a filter to the results of the search.

When you type text into the Filter text box at the top, Velocity iTest applies the filter to the current list and then displays only reports that “pass the filter” (the associated test case name includes the specified text). To reset so that no filter is applied, delete the text. See also Controlling which reports appear in the Test Reports view: Database search and filter.
