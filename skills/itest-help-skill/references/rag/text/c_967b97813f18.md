# Sharing iTest Resources > Exporting iTest projects as iTar files, Network DevOps Agent, or Velocity > Click Finish to create iTar files

Click Finish to create the iTar files. Each iTar file is named with the name of the associated project.

iTest ensures that your system is licensed to Encrypt exported iTar and checks out a license.

> **Note：** Note Go to iTest > Help > Configure Licensing. When the iTest Licensing window opens, verify that the iTar Encryption module is checked on the iTest Licensing > Configuration tab.

Publish the iTar into a Velocity Server or Network DevOps Agent

The iTar file are created, and automatically published in the Velocity server or the Network DevOps Agent as selected in Step 4 c page 1092.

A progress bar shows the task progression and displays the name of the file being published to iTar before publishing to specified server.

Export to directory

If you are exporting to a directory (Export to Directory), and If there are existing iTar files with the same filenames as the files you are creating, you may choose to Overwrite existing files to replace the old files with the new ones.

A progress bar shows the task progression and displays a message saying the projects are being exported to iTar and the name of the iTar file.

In this example, we created the R5000_router_response_maps.itar file in the C:\R5000Regression\ folder. (The iTar files for all checked projects will also reside in the C:\R5000Regression\ folder.)

Note If there is any error during publishing, iTest does the following:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Indicates the files that caused the problem, and displays the associated error message from Velocity server or Network DevOps Agent for each of the files.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Displays a message asking whether you want to continue and complete the publishing process and skip the problem files, or cancel the process and remove the processed files (on Velocity server or Network DevOps Agent).

iTest processes files according to your response.
