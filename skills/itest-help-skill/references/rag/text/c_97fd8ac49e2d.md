# Mail (POP3) Sessions > Session profile property settings for Mail sessions

This topic describes the property settings that you can configure for session profiles. For basic information on configuring a session, see Session profiles: Session configuration settings. For a detailed description of how iTest uses the settings, see About property settings.

> **Note：** Note If you have already saved a device or session profile document with the appropriate settings, then you do not need to configure the settings again. See About property settings.

![](images/popmail_2.1.jpg) <!-- image_ref -->

For Mail (POP3) session profiles, there are no additional properties that appear when you click on the New Session page (the Start tab of the Session Profile editor).
