# iTest licensing > Borrowing a license > To return a borrowed license

![*](bullet_blue.jpg) <!-- image_ref -->

1. Re-connect the computer that is borrowing licenses to the license server.

1. 2 Start iTest and open the iTest Licensing Settings dialog box by clicking Help > Configure iTest Licensing.

1. 3 In the Checkout Mode section, click Return Borrowed Licenses. iTest returns all selected licenses to the license server and then immediately checks them out.

> **Note：** Note If iTest has no connection to the license server when you click Return Borrowed Licenses, iTest will not disable licenses locally. Instead, displays a message saying that the license server does not respond, check the connection and try again.

You now have the following options:

![*](bullet_blue.jpg) <!-- image_ref -->

- Leave the computer connected to continue to use iTest with licenses that are checked out from the license server (the “normal” mode)

![*](bullet_blue.jpg) <!-- image_ref -->

- Exit iTest to release all of the iTest licenses to the license server for use by other computers and users.
