# Spirent TestCenter REST sessions > Spirent TestCenter REST session window > Spirent TestCenter Command reference

This topic describes all TestCenter commands in a session with iTest. The actions are captured during interactive STC sessions and you can add actions as described in To add a TestCenter REST step to a test case.

iTest TestCenter REST sessions support all commands that are generated by UI elements, eval and source commands, and all TestCenter sequencer commands. See the sections listed below in “Spirent TestCenter sessions”.

iTest supports all basic STC API in STC REST Session. The following shows an example usage:

| 欄位1 | 欄位2 |
| --- | --- |
| STC API Session Command | STC REST Session Command |
| stc::get handle [-attributeName [...]] | performGet -handle <handle> ?attributes? |
| stc::create objectType -under handle [[-attrvalue] ...] | performCreate -objectType <objectType> -under <handle> ?attribute:name/value? |
| stc::config handle -attrvalue [[-attrvalue] ...] | performConfig -handle <handle> ?attribute:name/value? |
| stc::delete handle | performDelete -handle <handle> |
| stc::apply | performApply |

Example: Create port/ create:

TestCenterREST>performCreate -objectType Port -under project1 -attributes.name name -attributes.value Ethernet_1

Result

handle : port1

TestCenterREST>performGet -handle port1
