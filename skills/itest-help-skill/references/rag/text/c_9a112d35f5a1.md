# Prompts (in CLI sessions) > Teaching iTest the prompts to expect during execution > Teaching prompts during manual testing

During interactive testing, iTest might identify text that “acts like” a prompt (that is, it is the last text in a response and there is no additional response for a significant period of time). If iTest notices possible prompts, it starts the Update Session Profile wizard when the session ends. See Using the ‘Update Session Profile’ wizard.
