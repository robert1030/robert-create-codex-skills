# Field Replacements > Inserting field replacements using the Insert Field tool > Using the Insert Field tool

Place the cursor where you want to place the field replacement text (in the example, after the word ethernet in the command). Right-click and, from the menu, select the type of command field replacement to add. The tool displays appropriate choices until you reach a final choice.

![](images/field_replacements_2.1.jpg) <!-- image_ref -->

Select the value to paste the field replacement text into the cell at the cursor position. In the example, we insert a parameter. The correct field replacement text is inserted. It remains only for us to replace the <parameter_name> placeholder text with the name of a parameter defined for the test case (port in this example). As a result, the [param port] field replacement is appended to the command text.
