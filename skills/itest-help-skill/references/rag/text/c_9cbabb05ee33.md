Adds a new set value action to set an attribute value (e.g. 'Text' for a UI element of type text). Use action for setting the values of repository items. Depending on the assigned repository item, the available attributes might be different.

For details, see the online help: "Ranorex action commands" section under the "Ranorex Sessions" topic.
