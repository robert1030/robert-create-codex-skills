# About the iTest Window > Project Explorer > Executing a test case from the Project Explorer

You can execute a test case from the Project Explorer in any of the following ways:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

![](images/ui_concepts_2.7.jpg) <!-- image_ref -->

- Select the test case. Click Start Execution in New Window

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Right-click it and select Start Execution in New Window

By default, when you start a session using a session profile from the Favorites view, the Project Explorer, or the Session Profile editor, the session starts in a new session window.
