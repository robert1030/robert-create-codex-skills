# iTest Commands > info commands > Commands for returning information: info > ‘info’ subcommands for the computer and user

| 欄位1 | 欄位2 |
| --- | --- |
| Command | Description |
| info env varName info('env', 'varName') | Returns the contents of the environment variable specified by varName |
| info hostIP info('hostIP') | Returns the IP address of the computer that is currently running iTest. |
| info hostName info('hostName') | Return the hostname of the computer that is currently running iTest. |
| info platform info('platform') | Returns the current operating system (windows or linux) |
| info user info('user') | Returns the user name of the current user. |
