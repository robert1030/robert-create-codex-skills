# iTest Views > Response view > Response view tool bar > 第2段

- ****：View Unfiltered/Filtered response: Toggle between viewing the filtered response and the unfiltered response. By default, the view displays the filtered response.
- ****：Toggle Sidebar: While working on a response map in the Response Map editor, display or hide the sidebar that acts as a shortcut for response mapping tasks.
- ****：Add This Sample (as an Additional Sample) to an Existing Response Map: Once you specify the response map in a dialog box, iTest adds the new sample and selects it on the Samples page of the Response Map editor.
- ****：New Response Map: Using the data for the current response as the sample, create a new response map.
- ****：New Form Map: For Swing and Web snapshot steps, click New Form Map to start the Form map wizard. See Overview: Form Maps.
- ****：Add a new analysis rule by starting the Analysis Rule wizard. (You must first select the step to apply the rule to.) See About the Analysis Rule wizard.
- ****：View the Action, Target, and Command for the step. Useful for Swing and Web snapshot steps.
- ****：On the Response tab/section, the default display format is auto-detected as Text, JSON, or YAML form. If JSON format is not detected, the data will be displayed as TEXT and will interpret/present the data accordingly. Response view shows YAML response text (not formatted as pretty-print). Click Text/JSON/YAML options from the dropdown list on the Response Window to toggle the response view display as JSON Pretty-Print or Text or YAML. Note When iTest auto-detects JSON format, or select the JSON option to display the content, the pretty print format is assigned as per your settings (see Setting preferences for JSON Pretty Print in “JSON Editor”).
