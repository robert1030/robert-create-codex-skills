For a CLI command action, the Command might be show routes. For an open step, the Command might be the URI of the session profile or the name of the device to use to start the session For a comment step, the Command is the text of the comment. For a configure step (used by many traffic-generator device session types), the Command is the text of the multi-line configuration file

Note Field Replacement for a Call action step is disabled by default. The following warning message displays to caution you about the consequences: Do not enable substitution for this step. This results in incorrect double substitution.
