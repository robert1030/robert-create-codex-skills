# Test Reports > Test reports overview > Comparing (“diffing”) two test reports > Sharing comparison test reports as files

As with test reports, you can save comparison test reports as HTML, PDF, Text, XML, or XML_RAW files.



To save a comparison test report as a file

![](images/test_reports_3.10.jpg) <!-- image_ref -->

1. 1 While working in the Test Report Comparison editor, click Save Test Report Comparison As in the toolbar.

1. 2 Follow the instructions for saving test reports as files: Sharing test reports as files.
