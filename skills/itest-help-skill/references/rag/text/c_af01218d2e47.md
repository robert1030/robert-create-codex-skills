# Spirent TestCenter sessions > Spirent TestCenter session window > CLI integration commands > 第2段

| 欄位1 | 欄位2 |
| --- | --- |
| capture save port filename | Saves capture data from the specified port to the specified file. |
| capture start [portList] | Starts capturing on all or specified ports |
| capture stop [portList] | Stops capture on all or specified ports. |
| clear stats | Clears statistics for all ports |
| configuration load filePath | Configures the device with information from the specified file. The configuration load command supports XML configuration files generated by configuration save. If the filename extension is .xml, then iTest interprets the configuration file as XML format. iTest expects that a second file exists in the same directory. The second file must have the same name postfixed with _logic. For example, config.cfg and config.cfg_logic During interactive TestCenter sessions, configuration load performs replacements on the file so that the specific information (like IP address) are translated into variables or command substitutions. Arguments Name Description Example filePath Configuration file to load project:///spirent.xml |
| configuration save filePath | Save the current configuration information returned by the device into a specified file. The file is used to configure the device exactly as if you had configured it using TestCenter: In test cases, you use configuration load to load the configuration settings to the device. You can specify the resulting file in the Configuration file setting in a session profile. The configuration is performed when the session starts. The configuration file format depends on the filename extension of the specified file. If the extension is .xml, then the configuration is saved in XML format. If the target format is XML, you can provide the list of ports to include in the configuration file. Arguments Name Description Example filePath Configuration file to save the config to project:///spirent.xml |
| eval Tcl_statement | Evaluate a Tcl statement for direct access to Spirent TestCenter’s TCL API |
| sequencer start | Gets the sequencer and issues the commands to chassis to start the sequencer. Immediately returns control to the user. |
| sequencer stop | Stops the current sequence execution. |
| sequencer step [-async] | Executes the next step in the sequence. If the -async option is provided, the step is started and the control is returned to the user immediately. In this case, use sequencer wait to wait for the step to finish. |
| sequencer wait | Waits for the current step in the named sequence to finish. Blocks the call until step is completed. |
| sequencer state | Returns the current state of the named sequence. Possible values: IDLE, WAIT, and PAUSE |
| sequencer run | Issues command to run all the steps to end. This command blocks until the sequence run is finished. It prints out a message for each step in the sequencer as the steps execute. If you press Ctrl-C, the sequencer run is aborted. |
| show info host | Shows information about the 'host' parent object |
| show info router | Shows information about the 'router' parent object. (Replaces get routerinfo) |
| show info stream-block [portList] | Shows streams from all or specified ports |
| show info trafficGroup | Shows information about traffic group |
| show packet port packetIndex [-raw] | Displays the specified captured packet on the specified port |
| show results [objects] | Shows results of specified type for all or specified objects |
| show stats [portList] | Displays a table of statistics for all ports or by port Shows subscribed stats for the 'port' parent object for the specified port list |
| source | Sources TCL script from workspace |
| stream enable port streamIndex | Enables transmission on a specified stream |
| stream disable port streamIndex | Disables transmission on a specified stream |
| subscribe | Subscribes for specific result type or lists all the result-types available |
| transmit start [portList] | Starts transmitting on all or specified ports |
| transmit stop [portList] | Stops transmitting on all or specified ports |
| unsubscribe | Unsubscribes for specific result type or lists all the result-types available |
| unsubscribe all | Unsubscribes for all available result types |
