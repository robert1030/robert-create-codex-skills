# iTest Commands > Commands that are commonly used in field replacements > param command: Returning parameter values > Accessing parameters defined in a session profile

Parameters can be defined in session profiles, response maps, for test case steps and overall test cases, and in a child test case executed by a run command. To access a parameter defined in the session profile associated with a step, use the profile command. See profile command: Accessing parameters that are defined in session profile.

> **Tip：** Tip In any field that supports field replacements (including test case commands), the fastest way to insert a param command is to right-click where the command should appear and then select Insert Parameter. See Inserting a parameter into a property or test case step
