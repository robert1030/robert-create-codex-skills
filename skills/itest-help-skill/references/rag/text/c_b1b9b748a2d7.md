# Spirent TestCenter sessions > Spirent TestCenter session window > Sequencer action commands > Responses to sequencer action commands

Most sequencer action commands return a list of attributes. The attributes map to a iTest response in the following form:

```
property1 : value1
```

```
property2 : value2
```

```
property3 : value3
```
