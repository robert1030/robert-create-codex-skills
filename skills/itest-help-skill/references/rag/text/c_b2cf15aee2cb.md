# Filtering Unwanted Text from Responses > Comparing the filtered and unfiltered version of a response

![](images/filtering_responses_3.1.jpg) <!-- image_ref -->

The Response view includes the Filtered/Unfiltered response toolbar button that allows you to toggle between viewing the filtered response and the unfiltered response. By default, the view displays the filtered response.

> **Note：** Note You cannot add an analysis rule while viewing an unfiltered response.
