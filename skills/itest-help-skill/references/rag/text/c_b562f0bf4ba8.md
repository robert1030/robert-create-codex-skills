The sleep action pauses the test for the number of seconds s pecified in the Command field (default: 5 seconds). The Execution view displays real-time sleep status.

Upon completion of the sleep period, iTest executes the next step in step number order.

This example step implements a sleep interval of 60 seconds to allow enough time for restarting the device.
