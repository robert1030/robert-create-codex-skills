# Capturing Manual (Interactive) Sessions > Capture reports > Capture Report editor, Details page > Captured Items

Each item in the Captured Items list (default sorting by timestamp) represents a single captured item and the information associated with its execution.

- **Session ID**：For devices with more than one session attached or for multiple captures that use the same session profile: To create the Session IDs that appear in the Session cells in the Test Case editor and in test reports, Spirent iTest uses the combination of Session name from the session profile (for example, myDUT) and a unique session number for the day. (for example, myDUT.1 and myDUT.2). If the session profile does not specify a Session name, then Spirent iTest uses the filename of the session profile in its place. The unique identifier for a captured item is the combination of its Session ID and the action number. The first action in each session to start is assigned 1, the second action is 2, and so on. Example For the third and fourth captured items on session myDUT.1, the identifiers are myDUT.1.3 and myDUT.1.4
- **Action**：You perform actions on a session — send a CLI command action to a Telnet session, click a link to perform a get action in an HTTP session, send get or set actions regarding a MIB variable in an SNMP session, send a command to a Tcl session, and so on. For example, the type of Action that you take in a Telnet session with a device is called command. When a session starts, iTest sends the first action for the session, an open action. When a session ends (for example, when you send an exit command in a Telnet session), iTest sends the last action for the session, a close action. The actions that you perform occur between the open and close actions.
- **Timestamp**：The date and time that the items were captured in yyyy/mm/dd hh:mm format.
- **Duration**：The time that it took the action to run to completion during capture. For CLI commands, this is the return of the prompt. For actions on a form, this is the return of the full response (HTML page or form).
