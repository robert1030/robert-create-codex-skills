# Executing Tests > Loading a test case for execution > Loading for execution

![*](bullet_blue.jpg) <!-- image_ref -->

1. Load the test case using one of the following methods:

![*](bullet_blue.jpg) <!-- image_ref -->

![](images/executing_tests.2.jpg) <!-- image_ref -->

- Before starting execution, in either the Execution perspective or the Test Case Debugging perspective, click Load for execution .

![*](bullet_blue.jpg) <!-- image_ref -->

![](images/executing_tests.3.jpg) <!-- image_ref -->

- While working in the Test Case editor, save the test case and then click Load for execution .

![*](bullet_blue.jpg) <!-- image_ref -->

- In the Project Explorer, right-click the test case and select Load for execution or Load for execution – New Window.

1. 2 The Test Case editor opens to the first step in the test case. Execution is paused.

1. 3 You can now change runtime parameter values in the Data view.

![](images/executing_tests.4.jpg) <!-- image_ref -->

![](images/executing_tests.5.jpg) <!-- image_ref -->

1. 4 Use Execute One Step or Execute Procedure and Pause as needed.
