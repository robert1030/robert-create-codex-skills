- **Compares two test cases**：Two-way merge comparison applies current test case revision with previous revision
- **compares test cases Three-way**：Three-way comparison applies in the following merge situations: When comparing target, source, and ancestor, merge conflicts may appear. Comparison algorithm considers two (or three) versions of the test case object and display the set of differences as a result.
