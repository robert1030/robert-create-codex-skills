# QuickCalls: Defining and using a library of custom actions > Adding a test case step that executes a QuickCall > Viewing a QuickCall definition while working on a QuickCall step

While working in a test case, you might want to review the details of a QuickCall. For any step that executes a QuickCall that is defined in another test case (a QuickCall library), right-click the QuickCall name and select Open. The QuickCall library opens in the Test Case editor to the referenced QuickCall definition.

> **Tip：** Tip After iTest executes a QuickCall, the Query view lists the QuickCall library where the QuickCall is defined.
