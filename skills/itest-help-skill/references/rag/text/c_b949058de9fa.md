# iTest Topology Editor > Overview: iTest Topologies > TBML Command Wizard

The TBML Command wizard takes you through the creation of all of the tbml commands, for example:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Find a resource property value: The wizard will show a table of resources and their properties for you to select.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Find endpoints of a link: The wizard will display a list links to select.

After making your selection, the wizards builds the command automatically. You are not required to know or understand the TBML command syntax.
