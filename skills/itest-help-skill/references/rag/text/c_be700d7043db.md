# About the iTest Window > How iTest perspectives are organized > The iTest Development perspective

Use the iTest Development perspective to perform manual tests on devices to capture steps for use in test cases. The following parts appear on the perspective:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- The Favorites view gives you ready access to session profiles, test cases, and other files that you use often. You can place any sort of file in your Favorites view for easy access. You can even add non-Spirent files (such as spreadsheets or word-processor documents) to Favorites.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- The Project Explorer displays all projects, libraries, folders, and files in your workspace.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- The New Session page is the first page of the Session Profile editor that you will use to configure and review session profile documents.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- The Response view displays the command and response for the currently selected captured item or test case step. The view makes it easy to review responses and to copy part or all of a response for pasting into other documents. (You can select captured items in the Capture view or Capture Report editor. You can select test case steps in the Test Case editor and in the Test Report editor.)

See also Overviews of the default iTest perspectives and Overviews of the default iTest perspectives.
