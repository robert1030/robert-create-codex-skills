# Charting Test Case Data > Exporting chart data

You can export chart data into a standard format file (XML or CSV) so you or others can view the data using other applications (for example, Microsoft Excel or another data visualization application).

> **Note：** Note iTestRT cannot export chart data directly. There are, however methods for saving chart data. See Exporting chart data from iTestRT.

1. 1 Execute the test case that generates chart data.

1. 2 Click File > Export.

1. 3 On the Export page, select iTest > Export Chart Data. Click Next.

![](images/chart_export-01.png) <!-- image_ref -->

1. 4 You have the option to export the data in XML format or as a CSV (comma-separated value) file. (Many applications can import CSV files.) Click Next.

![](images/charting_2.2.jpg) <!-- image_ref -->

1. 5 Now specify where to save the data and provide a filename. Click Finish.

![](images/charting_2.3.jpg) <!-- image_ref -->
