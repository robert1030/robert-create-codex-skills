One report is generated for each execution. Report files are named with the test case name and a timestamp. You specify the format of the report documents (HTML, PDF, Text, XML, and/or XML_RAW) using the Formats to generate property. You specify the location to save reports using the Folder for test reports property

Note All other options on this window are grayed and not available for selection
