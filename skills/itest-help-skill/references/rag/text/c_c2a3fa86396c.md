| Include command timestamps | The Include command timestamps supports logging commands and responses into file. Default: Include command Timestamps logging is disabled. When enabled, the timestamps will be logged before each executed session command. The Timestamp format is: YYYY/MM/DD hh:mm:ss, where: |

YYYY is a four-digit year MM indicates a two-digit month of the year DD indicates a two-digit day of that month hh refers to a zero-padded hour between 00 and 23 mm refers to a zero-padded minute between 00 and 59 ss refers to a zero-padded second between 00 and 59 Note The command timestamps is supported only in Replay mode.
