# Form Maps > Creating form maps for use with GUI testing test applications

Typically, you create a form map for each page that test case developers will access. Each form map identifies the targets (elements like buttons, links, and text boxes) on the page. Targets may also take arguments. You have the option to give the targets user-friendly names.

You'll use the Form Map wizard to create form maps. We use a Web session in this example.

> **Tip：** Tip The application developer might help you to identify the likely targets on a page.

Creating a form map involves the following steps (details follow):

![*](bullet_blue.jpg) <!-- image_ref -->

1. Obtain the HTML structure of the web page by starting web Selenium session and taking a snapshot.

1. 2 Create the form map. (Once you create the map, iTest identifies nearly every target on the page.)

1. 3 Build a target list for the form map. (That is, identify the targets that test developers will most likely use. iTest does this with a mouse click.)

1. 4 Identify the important targets and name them clearly.

1. 5 Save the form map.
