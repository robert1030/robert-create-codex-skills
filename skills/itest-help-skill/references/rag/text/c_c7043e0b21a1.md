Double-clicks an item in the list.

Target Required. Controls Lists, trees, grids. Command Item to double click. Step Properties Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15

For details, see the online help: Flex action reference.
