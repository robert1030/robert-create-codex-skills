Simulates a rollover action on a chart item.

Target Required. Controls Chart or chart series. Command The index of the item in the chart series. Step Properties Step Properties Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15
