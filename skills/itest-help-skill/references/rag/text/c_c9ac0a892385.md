# Procedures > Defining a procedure > Insert Return Value Dialog

Use the Insert Return Value dialog to get the XPath for sample JSON response. See Commands that return sample json xpath used in Store Processor Once the sample JSON response (Step Note , page 361) is defined for the procedure, the tree style of that JSON string displays in this dialog, which is the same as the JSON tree in the Response Structure.

To get the XPath for the node value, select the node in the tree, the corresponding field replacement will be generated in this dialog. After clicking the Insert button, the [return query_xpath] will be inserted automatically.
