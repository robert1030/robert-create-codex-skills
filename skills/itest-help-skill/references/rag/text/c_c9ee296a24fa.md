# Serial Sessions > Session profile property settings for Serial sessions > Terminal > Replay > Step Defaults > Completion > 第2段

A countdown timer in the status bar starts to count down the Time for user to respond time period. iTest displays a Keep waiting link in the status bar. If the user clicks the Keep waiting link, then iTest waits for an additional (Expected maximum Idle channel interval + Extra wait before alerting user) has elapsed period. If the waiting period expires, then iTest raises an execution issue that it failed to find a prompt and sets the test result to Fail. The test case then continues
