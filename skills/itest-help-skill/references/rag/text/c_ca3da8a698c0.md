# iTest Runtime: iTestRT > iTestRT command reference > XMPP

The xmpp options enable you to set XMPP connection advisor parameters at the command line.

The long forms of option names begin with: com.fnfr.itest.runtime.xmpp.advisor.optionModule

| 欄位1 | 欄位2 |
| --- | --- |
| --xmpplogin loginName | Login name |
| --xmppuser userName | User name |
| --xmppfeature feature | Feature |
| --xmppinband | Register if does not exist |
| --xmpppub ipAddr | IP address of the pubsub |
| --xmppserver server | Host |
| --xmpppassword password | Password |
| --xmppresource resource | Resource |
| --xmppservice serviceName | Name of the XMPP server to connect to |
| ---xmppport port | Port where the XMPP is listening |
