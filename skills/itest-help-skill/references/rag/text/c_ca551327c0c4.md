# Python Session Level Control Library > Working with Sessions > Opening a Session > Queries Session properties

You may query for Session Properties available after a session is opened.

```
# open session, specifying additional session properties
```

```
s1 = proj.rest_session_ffsp.open(properties={"authentication.authenticationType": "Basic", "authentication.user": "me", "authentication.password": "totes_secret!"})
```

```
# Query for session properties
```

```
s1.session_properties()
```
