# Events: Taking Action when a Particular Event Occurs During Execution > Configuring events for steps

To define the set of actions to perform when a particular event occurs while a step is executing:

![*](bullet_blue.jpg) <!-- image_ref -->

1. On the Steps page, select the step.

1. 2 On the Step Properties page, select Events.

1. 3 Now follow the instructions for configuring a Global event: Configuring Events: The Global Events page.
