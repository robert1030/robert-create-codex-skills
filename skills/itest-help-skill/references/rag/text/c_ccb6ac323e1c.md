# Test Case Editor > General page on the Test Case Editor > Test Case editor: General page > Library Settings

Note You have the option to include the name of this test case in the drop-down list of procedure libraries while creating a call step.

Note Click the link to open the Test Case Steps page so that you can edit steps and procedures. Procedures are described more full in “Procedures”.

- **Procedure libraries**：Check the box to include the name of this test case in the drop-down list of procedure libraries while creating a call step. When you check the box to identify this test case as a procedure library that should be made easily available when creating test cases. As a result, when you add a call step or a CallProcedure action to a test case, the URI for this test case appears in the drop-down list of procedure libraries and local and foreign procedures in the Description cell. When you uncheck the box, the URI does not appear in the drop-down list. Default: unchecked
- **QuickCall Library**：The settings in this section identify the test case as a QuickCall Library, make the library “public”, and associate the QuickCalls with a device or session profile For more information on QuickCalls, see “QuickCalls: Defining and using a library of custom actions”. Check box to make the library “public”, that is, to cause iTest to display the test case name whenever a user asks to see a list of available QuickCall libraries. This settings adds the QuickCall library to the drop-down list when you edit a session profile or device to associate the library.
- **Associated Session profile**：Available only when you select QuickCall Library. Specify the device or session profile to associate with the QuickCalls that are defined in the library. Once you have specified a device or profile, the link becomes active and opens the item in the appropriate editor.
