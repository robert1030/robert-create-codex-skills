# Using Git in iTest > Setting up Git repository in iTest > 第1段

Follow these instructions in iTest.

Step 1

Setup Local Repository

![*](bullet_blue.jpg) <!-- image_ref -->

![](images/open_perspective_icon.png) <!-- image_ref -->

1. Click Open Perspective () at top right-hand side. Then Click Git in the Open Perspective dialog.

The Git Repositories page opens.

> **Note：** Note You may use the menu options on the top of the Git Repositories page as required.

![](images/Git_in_iTest.2.jpg) <!-- image_ref -->

1. 2 Select Create a new local Git repository the repository to add to your current view.

Create a New Git Repository dialog opens.

1. 3 Click Browse, navigate and choose the directory for your new local repository. For example: (example: c:\itest\builds\itest-5.4\47\git\localRepo) Click Finish.

A Local Git Repository is created at the specified location.

![](images/02-Git_repositories.png) <!-- image_ref -->

![*](bullet_blue.jpg) <!-- image_ref -->

Setup Remote Repository (Locally)

![*](bullet_blue.jpg) <!-- image_ref -->

1. Select Create a new local Git repository from the menu (at the top of the Git Repository page) to be added to your current view.

Create a New Git Repository dialog opens.

1. 2 Enter the remote directory path (example: c:\itest\builds\itest-5.4\47\git\remoteRepo) or navigate to the location. Click Finish.

![](images/02-a-Git_loca_repo.png) <!-- image_ref -->

A Remote Git Repository is created at the specified location.

![*](bullet_blue.jpg) <!-- image_ref -->

Create Remote repository to push or fetch files

![*](bullet_blue.jpg) <!-- image_ref -->

1. Right-Click on Remote under the localRepo and the New Remote dialog opens.

![](images/Git_in_iTest.5.jpg) <!-- image_ref -->

1. 2 Select the type of remote location you wish to create on the New Remote dialog. Enter/select the following:

Remote name:

Default: Origin

Enter the remote repository name (this name appears on the remote configuration dialogs).

Configure push

Select to configure the new remote location for push operation

(selected by default).

Configure fetch

Select to configure the new remote location for fetch operation.

It is mandatory that you configure the new remote location for either fetch or push operations. You may add configuration for the other directory at a later time.

1. 3 Select push and click OK and Configure push for remote ‘Origin’ dialog displays.

![](images/Git_in_iTest.6.jpg) <!-- image_ref -->
