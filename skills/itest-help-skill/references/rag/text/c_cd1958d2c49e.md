# Test Reports > Sharing Test Reports > Using Velocity iTest's XSLT stylesheets to format reports > Velocity iTest 4.0 directory structure

In Velocity iTest 4.0, the XSD (test_report.xsd) is located in:

resources1/reports18/test_report_templates/XML

The directory structure for test report templates is the same as for Velocity iTest 3.2.
