# Debugging Test Cases > Adding a breakpoint > To add or remove a breakpoint

You can add or remove breakpoints at any time (even during execution or while execution is paused).

1. 1 On the Test Case editor Steps page, select the step.

![](images/debugging_tests_2.1.jpg) <!-- image_ref -->

1. 2 In the toolbar, click Toggle Breakpoints . A breakpoint is added or removed as appropriate.

![](images/debugging_tests_2.2.jpg) <!-- image_ref -->

For breakpointed steps, a marker appears in the first column.

> **Note：** Note iTest ignores breakpoints on skipped steps—the steps are skipped without pausing execution.

All current breakpoints are identified on the Breakpoints view.
