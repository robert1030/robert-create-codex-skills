# iTest Views > Structure view > Working with query definitions

While viewing the response structure in the table format, the text box enables you to edit query definitions. As you edit an XPath query, the view updates to highlight appropriate matches in the structured part of the response. iTest supports XPath 3.1 and 1.0 functions. The XPath version default to the version specified in the Test Case Editor > General page.

You can now edit the query as needed to help you to develop a custom query (remember that iTest supports all XPath 1.0 and 3.1 functions).
