# About the iTest Window > Monitoring iTest's memory usage

1. 1 Click Window > Preferences.

1. 2 On the Preferences dialog box, click General.

1. 3 Click the Show heap status check box.

![](images/preference_memory_status_annotated.png) <!-- image_ref -->

Heap utilization information will now appear in the bottom right of the iTest status bar.
