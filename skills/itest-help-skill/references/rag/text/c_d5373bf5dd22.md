# Test Suites > Reviewing the tests that are members of a test suite or of a test group > Viewing the test cases in a test suite or test group > Viewing the included and excluded test cases in a test suite

On the Test Suite editor General page, click Show All Tests in the toolbar. The All Tests in Test Suite dialog box displays the list of all tests that will execute when the test suite runs.

> **Note：** Note The tab title includes the count of tests that appear on the page.
