# Spirent TestCenter sessions > Spirent TestCenter session window > To create a test case that includes Spirent TestCenter sessions > Step properties for the configurePort step

In addition to the port number for the aconfigurePort step, iTest captured all of the settings that you configured in the TestCenter Port Editor when you submitted the step. You can view (and edit) all of the captured property settings in the Step Properties section for the step.

For example, the selected COnfigurePort Step Properties settings are identical to the settings that you make on the TestCenter Editor while configuring a Port.
