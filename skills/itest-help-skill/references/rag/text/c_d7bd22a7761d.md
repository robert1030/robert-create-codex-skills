If you select a single file or select an editor, then the single file appears at the top level in this column. In the example, only one file — the proclib test case — is at the top level. If you select multiple files in either the Project Explorer or Favorites view, then each of the files appears at the top level in this column, one file after the other.

If there were a change to a device in the web_testbed testbed, then the system would perform a build to ensure that proclib would execute properly.
