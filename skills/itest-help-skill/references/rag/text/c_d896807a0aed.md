# iTest licensing > Borrowing a license > To borrow a license

![*](bullet_blue.jpg) <!-- image_ref -->

1. Temporarily connect the portable computer that will use the borrowed licenses to the license server.

1. 2 Start iTest and open the iTest Licensing Settings dialog box by clicking Help > Configure iTest Licensing.

1. 3 In the iTest Modules section, check the licenses that you want to borrow (click Select All or Unselect All to speed the process).

1. 4 In the Checkout Mode section, check Borrow Licenses and specify the “borrow until” date — the last day that you expect to use the borrowed license. You can either type the date directly or select the month, day, or year and use the up/down controls.

![](images/licensing_2.1.jpg) <!-- image_ref -->

> **Note：** Note Some feature licenses may not be “borrowable” or may have limits on how long they can be borrowed. The default time limit is one week unless altered by the license terms.If a license is already being borrowed on the current computer, its “borrow until” date is recalculated.

1. 5 Click OK. The licenses are now borrowed onto the computer.

The icon in the Status column changes to reflect borrowing and the “borrow until” date is displayed. iTest will now operate on the portable computer (not connected to the license server) using the borrowed license until the expiration date.
