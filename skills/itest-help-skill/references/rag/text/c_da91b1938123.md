# Parameters > Parameter Files: Centralizing parameter definitions > Parameter files > Global parameter file

You can specify that a particular parameter file is the Global parameter file. The only parameter file that is automatically used by test cases is the Global parameter file. The Global parameter file applies to all test cases in a workspace. See Global parameter file.

> **Important：** Important There is no way to specify a particular parameter file for a test case. You can, however, use iTestRT to specify a particular parameter file (that is, not the Global parameter file) for use by a particular test case.
