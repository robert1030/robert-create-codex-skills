# Run iTest as Network DevOps agent > Start and Stop NDO server

iTest allows you to Start and Stop NDO REST server Spirent from Preferences > Spirent > NDO Agent page.

Important

iTest does not allow simultaneous start of iTest as NDO Agent and Velocity Agent.

| 欄位1 | 欄位2 |
| --- | --- |
| Start | Displays when all the properties modified have been applied. That is, you have clicked the Apply button after a property is changed. The Status on top of the dialog displays as NDO server is stopped and all field are enabled. You may make further changes to the properties on these pages: Spirent > NDO Agent, Spirent > NDO Agent > Authentication, and Spirent > NDO Agent > REST Server Certificate. The Start button is disabled if Velocity Agent mode is in use. |
| Stop | Displays when NDO server is started. The Status on top of the dialog displays as NDO server is started and all field are disabled on these pages: Spirent > NDO Agent, Spirent > NDO Agent > Authentication, and Spirent > NDO Agent > REST Server Certificate. |
