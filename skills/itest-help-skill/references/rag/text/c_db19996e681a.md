# About the iTest Window > Working with folders > Adding a folder

1. 1 In the Project Explorer, right-click the parent folder and select New > Folder. (Alternatively, click File > New > Folder or select Folder in the New toolbar drop-down menu.)

![](images/ui_concepts_3.1.jpg) <!-- image_ref -->

![](images/menu_new_folder.png) <!-- image_ref -->

1. 2 On the New Folder page, type the path to the parent folder or select it in the navigator.

1. 3 In the Folder Name field, specify the name that should appear for the folder in the view.

![](images/ui_concepts_4.3.jpg) <!-- image_ref -->

1. 4 For help on the Advanced options, click Help .

1. 5 Click Finish.
