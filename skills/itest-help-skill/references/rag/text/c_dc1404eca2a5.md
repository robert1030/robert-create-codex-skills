# Form Maps > Form Map editor: Samples page > Adding a new sample

![*](bullet_blue.jpg) <!-- image_ref -->

![](images/form_maps.2.jpg) <!-- image_ref -->

1. In the interactive Web session, while on the web page, take a snapshot (click ). This places the DOM for the page into the Response view.

1. 2 Copy the text in the Response view.

1. 3 Open Samples page of the Form Map editor.

1. 4 Click Add to add a sample and then paste the response text into the XML Data Viewer field.

1. 5 Move to the Targets page to add the targets.
