# Test Cases > Library Template > Creating a template from existing test cases

If you find that you use a particular procedures, and/or property settings (QuickCalls) whenever you create a new test case, iTest allows you to create such a test case and generate as library template. You may link/associate the library template with a test case to use as a template. Then, the new test case you create, will be based on the procedures and properties of the library template automatically linked in the new test case.

Any testcase with defined procedures may be a Library Template for another testcase, e.g., any testcase can be linked to another testcase as a template. The steps below shows you creation of a library template (Creating a Library template) and the validations (Validation of testcase against the associated template) performed when modifying a test case based on the template.
