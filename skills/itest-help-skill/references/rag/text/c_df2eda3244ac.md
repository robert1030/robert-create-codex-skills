# Prompts (in CLI sessions) > About inheriting prompt definitions > To start with the inherited prompts and add new prompts

> **Note：** Note The inherited prompts are updated when the definitions in the reference session profile change.

1. 1 Leave the Include inherited prompts check box checked (this is the default setting).

1. 2 Check the Include additional prompts from list check box. The inherited prompts disappear from the Prompts list, but they are a still a part of the current session profile.

![](images/prompts_3.2.jpg) <!-- image_ref -->

1. 3 To add a new prompt definition, click Add . Set the prompt properties as described in the Prompt properties table. A more prompt property setting appears in Terminal > Replay > Step Defaults > More. Another prompt property setting appears in Terminal > Replay > Step Defaults > Completion.
