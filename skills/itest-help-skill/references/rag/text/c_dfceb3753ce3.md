# Session Profiles > Session Profile editor: Settings page > General Information

- **Headline**：Supply a brief description to help co-workers understand how the session profile should be used. The text that you type here appears in the Headline column of the Favorites view to help you when selecting a session profile.
- **Description**：Optional. Type additional documentation to help coworkers to understand and maintain the session profile
- **Language**：Use the default language displayed (as set in Preferences: Spirent > General > General preference settings, Chapter , “Configuring iTest Preferences”) or select a different language from the list. When you select Language as Python, you may export the entire iTest test case (FFTC) to a Python script.
