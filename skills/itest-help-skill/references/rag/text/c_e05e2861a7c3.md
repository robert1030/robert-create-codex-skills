# Controlling execution flow: Loops, If/Then, and Switch > For and ForEach loops > The foreach action: Execute a group of steps in a loop > Using a parameter to supply values

You can use a parameter with multiple values to supply a set of values. In this example, the parameter is named A. Use the following syntax:

```
foreach A {1 3 5}
```

For information on defining a parameter that has multiple values, see Defining a parameter.
