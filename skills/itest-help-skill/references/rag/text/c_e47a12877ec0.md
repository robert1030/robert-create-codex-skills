# Scheduling Execution > Configuring a job: The Job wizard > Once

Select Once to run the job a single time at the specified time. Specify the following settings:

- **Immediate**：Run the job as soon as you click Finish. This setting ignores the time specified by the Start at property.
- **Start at**：Specify the hour, minute, and date for the run. Click any time value and change it using the up and down arrows.
- **Enforce time limit**：To ensure that the job does not exceed a particular run time, check the box and specify the maximum time allowed for the job to finish its run. If a test is executing when the limit is reached, then iTest aborts execution and stops running the job. The Test case result is set to Aborted. The default setting of unchecked box and a time of 00:00 mans that there is no time limit for the run.
