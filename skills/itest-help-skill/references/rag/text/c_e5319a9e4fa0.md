# SNMP Sessions > Loading your proprietary MIB files into iTest > Copying your MIBs into the default folder (Not Recommended)

![*](bullet_blue.jpg) <!-- image_ref -->

1. Copy your MIB definition files (uncompiled text format) into the Mibs directory in the workspace.

Important You must copy the individual files because subdirectories under the Mibs directory are not supported.

The default paths are:

Linux:

```
~/itest/ workspace/resources/SNMP/Mibs
```

Windows:

```
C:\Documents and Settings\<user_name>\My Documents\iTest_<version>\resources\SNMP\Mibs
```

1. 2 The following steps are optional, but strongly recommended.

To make it easier to select MIBs from lists during SNMP sessions, you can specify an alias for your proprietary set of MIB variables. For example, when you specify the alias name ACME to replace iso.org.dod.internet.private.enterprises.acme, the OIDs for the MIB variables in the session window's drop-down lists become much easier to read and select:

```
ACME::IMAGE-MIB
```

appears in the list instead of:

```
iso.org.dod.internet.private.enterprises.acme.IMAGE-MIB
```

Follow these steps:

![](images/snmp_3.3.jpg) <!-- image_ref -->

1. 3 Open the device's session profile and click to view the Session Properties section.

1. 4 In the tree, click SNMP MIB Browser > Aliases.

1. 5 Uncheck the Inherited values box (to enable you to specify non-default aliases for proprietary MIBs).

![](images/snmp_2.4.jpg) <!-- image_ref -->

1. 6 Click to add an alias.

1. 7 In the Name text box, specify a name for the alias. In the example, the Name is ACME.

1. 8 In the Content text box, type or paste the OID prefix that you want to alias. In the example, the Content is:

1. 9 iso.org.dod.internet.private.enterprises.acme

1. 10 Repeat for each group of MIBs that share an OID prefix

1. 11 Click Save.

1. 12 Exit and restart iTest.
