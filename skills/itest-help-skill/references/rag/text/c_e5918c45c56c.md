# About the iTest Window > Perspectives > Velocity Agent/NDO Execution Mode Toggle

When the iTest GUI is connected to a Velocity instance, the iTest toolbar provides a toggle to run iTest as either a Velocity Agent or an NDO Agent. The toggle button text reflects the current Agent availability state, that is Velocity Agent Mode On, NDO Agent Mode ON, or Velocity Agent Mode Off.

> **Note：** Note These toggle appear only when iTest is connected to Velocity, even when both Velocity Agent and NDO Agent are disabled.

The following examples show how the toggle appears depending on whether the Agent mode is enabled or disabled.

> **Note：** Note These toggle appear on both iTest Expert and Velocity Agent/NDO perspectives.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- When iTest is connected to Velocity and both Velocity Agent and NDO are disabled:

The toolbar displays a button labeled Velocity Agent Mode: OFF. Click this button to open Preferences > Spirent > Velocity > Agent. See Configure Velocity Agent Mode.

![](images/perspective_toggle_AgentModes_off.png) <!-- image_ref -->

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- When Velocity Agent is enabled:

The toolbar displays a Velocity Agent Mode: ON button. Click this button opens Preferences > Spirent > Velocity > Agent. See Configure Velocity Agent Mode.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- When NDO Agent Mode is enabled

The toolbar displays a NDO Mode: ON button. Click this button to open Preferences > Spirent > NDO Agent, where you can reconfigure or stop NDO Agent mode. See Configure NDO Agent Mode.

![](images/perspective_toggle_AgentModes_ON.png) <!-- image_ref -->
