# Test Case Editor > Steps page on the Test Case Editor > Step Properties section: Events properties group > Configuring the actions to take for events for a step

In this example, we have selected the show interfaces step. On the Events properties page for the step, in the Analysis Extractor: Regex group of events, we have selected the OnIllegalRegexPatternError event. When we select the event, the actions that are currently specified for the event are listed in the Event section’s table of Actions.

The settings that you make on this page are similar in nature to the settings on the Global Events page — the difference is that the settings that you make here apply only to the current step. To configure the actions to take for an event, follow the instructions in Configuring Events: The Global Events page.
