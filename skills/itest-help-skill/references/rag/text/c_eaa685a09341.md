# Parameters > Using Parameters in Properties or Steps > Inserting a parameter into a property or test case step > Defining a new test case parameter and inserting it

> **Note：** Note Using this method, you can add parameters to test cases only — not to session profiles.

1. 1 In the Insert Parameter dialog box, select Test Case.

1. 2 Type the name of the new parameter into the Parameter name text box.

1. 3 Click Add. Follow the directions for the Add Parameter to Test Case dialog box.
