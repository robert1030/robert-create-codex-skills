# Scheduling Execution > Defining a job (using the Schedule wizard)

Step 1

Specify the tests to run and the Topology and/or Parameter file

![*](bullet_blue.jpg) <!-- image_ref -->

1. On the Project Explorer, right-click and select Job. The New Job wizard opens to the Job (create a new job file) page.

1. 2 Select folder to create the new job and click Next.

1. 3 Specify the test case/rest suite, on the General (Specify items to execute) page.

![*](bullet_blue.jpg) <!-- image_ref -->

1. Navigate to the appropriate project or folder and select as many test cases/test suites as needed (Ctrl+click, Shift+click) and then click OK.

![*](bullet_blue.jpg) <!-- image_ref -->

- Test cases/suites are executed in the listed order. To move a test case/test suite, select it and use the up and down arrows.

![*](bullet_blue.jpg) <!-- image_ref -->

![](images/scheduling_execution.1.jpg) <!-- image_ref -->

- To remove a test case/suite from the list, select it and then click .

1. 4 You have the option to specify the Topology and/or Parameter file to use for all test executions. The files that you specify here override the settings in the test cases.

1. 5 Click Next.
