# About the iTest Window > Setting preferences for the workspace > Spirent > General > Workspace

- **Automatically import missing projects into workspace on startup**：We strongly recommend that you do not change this setting. If checked, then, when iTest starts, automatically import missing projects into the workspace. This setting is important when you share a workspace under revision control; new projects are automatically imported, avoiding confusion. Note: If you have specified the root of a file system as your workspace (strongly not recommended), then start iTest using the following command: itest --noImport iTest starts and deselects the Automatically import setting. You must then use File > Import to import the projects that you need. Default: checked
- **Hide JPG files in Project Explorer**：Applies to iTest 9.4 and older releases. This option has been moved in iTest 9.5. See In the Project Explorer > Filters and Customizations > Pre-set filters > tab JPG files option. Refer to Eclipse documentation.
