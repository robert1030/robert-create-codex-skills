# QuickCalls: Defining and using a library of custom actions > Setting QuickCall preferences > QuickCall preference settings

To view or edit preferences, click Window > Preferences. On the Preferences page, click Spirent > Sessions.

- **Display a warning when executing a QuickCall with missing required arguments**：During an interactive session, when you execute a QuickCall that requires a value for an argument, but you did not specify a value, iTest displays a warning dialog box. Uncheck the box to eliminate such warnings. Default: checked
- **Always open the ‘Execute a QuickCall’ wizard when executing a QuickCall manually**：During an interactive session, when you execute a QuickCall that requires values for named arguments, iTest opens the Execute a QuickCall wizard to help you to specify values. To cause iTest to open the wizard for all QuickCalls (whether the QuickCall uses named arguments or not), check the box. Default: unchecked
