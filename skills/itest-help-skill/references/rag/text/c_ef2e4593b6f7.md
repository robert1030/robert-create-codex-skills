# Analysis Rules: Validating Responses > Analysis Rule Wizard: Custom Extractor page

> **Note：** Note When a test case command step uses secret values, the value is not masked and allows adding a Query/XPath on the Analysis Rule Wizard: Extractor page (See About the Parameter Type ‘Secret’).

On this page, you specify how to extract the data, that is, the type of extractor (Extract using property in the analysis rule).

Specify how to extract the data in the Extract using box. The options that appear in the Extractor Properties section depend upon your selection.
