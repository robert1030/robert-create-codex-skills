# About the iTest Window > About workspaces > Projects

Workspaces contain projects. Projects are not folders, they contain folders. Workspaces may contain multiple projects.

The default project is named my_project. When you open iTest, the Project Explorer displays all working folders in my_project. You may add, rename, or remove projects.

Note iTest does not support the project move function. External modifications of project files while iTest is using them are not allowed.

To move project to another location:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Delete project within iTest (do not select the Delete contents checkbox).

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Move project using external tools (i.e., Windows Explorer).

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Import project in the workspace using Import > General > Existing projects.
