# Session Profiles > Session Profile editor: Settings page > QuickCalls

- **QuickCall Library**：When you specify a QuickCall library here, any test case step in the session searches the QuickCall library for the requested QuickCall. In addition, all QuickCalls in the library are listed when you request a QuickCall during a manual session. See “QuickCalls: Defining and using a library of custom actions”
- **Initialization QuickCall**：Specify a QuickCall that perform relevant initialization tasks.
- **Run from testcase**：Select to indicate that the initialization QuickCall should be run from the test case.
