# Test Case Editor > Quality Center page on the Test Case Editor > Setting preferences for the Test Case Editor > Properties in: Editors > Test Case Editor > Appearance

Settings that control the appearance of the Test Case Editor.

| 欄位1 | 欄位2 |
| --- | --- |
| Expand entry point procedure one level and collapse all others | Checked: The Test Case Editor displays only the main procedure expanded and all other procedures collapsed. This help you see the high levels and descriptions of the test case (each quick call, each procedure, etc). Not checked: iTest opens test cases fully expanded. You may right-click, Collapse all and Expand one level, as required. Default: checked |
