# Executing Tests > Handling test cases that lasts more than a minute > Setting timeout value on Test GUI

![*](bullet_blue.jpg) <!-- image_ref -->

1. Edit the file in the installation folder: <installation folder>/iTest.ini file.

1. 2 Insert option on a separate line after -vmargs line:

```
-vmargs
```

```
-Dlogging.long.execution.seconds=-1
```

```
..
```

1. 3 Save file and restart iTest.
