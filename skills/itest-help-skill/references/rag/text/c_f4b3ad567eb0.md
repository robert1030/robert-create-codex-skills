Note When you add a custom parser, you must then reparse all the blocks that include the field that you created the custom parser for: In the Block Map Elements list, select the blocks (Ctr+click to select multiple) and then click Reparse Blocks.

![](images/response_mapping.4.jpg) <!-- image_ref -->

![](images/response_mapping.5.jpg) <!-- image_ref -->

Note When you delete a custom parser, you must then reparse all the blocks that include the field that you created the custom parser for: In the Block Map Elements list, select the blocks (Ctr+click to select multiple) and then click Reparse Blocks.

- **Add**：Add a new custom parser.
- **Remove**：Delete the selected parser.
- **Move Up / Move Down**：Use these buttons to organize the parsers into the order in which they should be applied.
