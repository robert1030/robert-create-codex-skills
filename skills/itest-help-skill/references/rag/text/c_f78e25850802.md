# JSON Editor > Overview

iTest provides JSON Editor to easily formulate a JSON document and also manipulate the JSON response. That is:

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Formulate a JSON document from the TestCase Editor (See also “Test Case Editor”). A Wizard provides an easy point-and-click way to perform CRUD operations on nodes in a JSON document.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Manipulate the JSON response. iTest provides a programmatic way of performing CRUD operations on block response of a procedure (see also “Procedures”, section Defining a procedure).
