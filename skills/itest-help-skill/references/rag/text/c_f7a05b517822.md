# Test Case Editor > Reference Files page on the Test Case Editor > Test Case editor: Reference Files page > Specifying reference files

![*](bullet_blue.jpg) <!-- image_ref -->

1. On the Test Case editor, open the Reference Files page.

![](images/test_case_editor_7.1.jpg) <!-- image_ref -->

1. 2 Click to add a new file to the list.

1. 3 Specify the following properties for the file:

Note Use any name that serves your purposes in communicating the relevance of the file — the name does not have to be the filename.

- **Name**：The name that you use for the reference file must be unique.
- **Location**：Specify the URI of any file (inside or outside the workspace). Use Browse as needed. Click the Location link to open the file in an editor.
- **Description**：Optional. Type one or more lines of text to describe the file for coworkers.
