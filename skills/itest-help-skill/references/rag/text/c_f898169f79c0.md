# SSH Sessions > Session profile property settings for SSH sessions > Advanced Authentication > SSH authentication: PublicKey

- **Key file**：Specify the path to the client private key file. Specify a URI that starts with file:// or project:// (i.e., specify user (see User and Password) and provide the private key file). See example screen shot below.
- **Passphrase**：Optional. Specify the passphrase to use to access the private key in the key file. The text is masked here and in all locations in which it is used.
