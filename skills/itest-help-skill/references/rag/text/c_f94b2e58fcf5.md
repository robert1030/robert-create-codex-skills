# iTest Views > Favorites view > Adding files to the Favorites view

Files listed in the Favorites view are actually shortcuts to the files (the files remain in the original folder).

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- To add an item, drag it into the Favorites view.

![*](bullet_blue_rectangle.jpg) <!-- image_ref -->

- Alternatively, right-click it in Project Explorer, and then select Add to Favorites.

For devices, if you do not specify a Description when defining the device on the Devices page of the Tpology editor, then the Description field in the Favorites view displays the session type for the device.
