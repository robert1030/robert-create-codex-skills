# Procedures > Creating a procedure library

It is easy to create a library of procedures that can be shared by iTest users. (For suggestions on why you might create a procedure library, see Overview: Procedures in test cases.)

To create a procedure library, you create definitions of commonly used procedures in a single test case. The test case then acts as a procedure library.

Any iTest test case in the same workspace can then use a call step or CallProcedure action to call a procedure from the library.

> **Tip：** Tip On the Test Case editor Steps page, click Collapse All to view only the procedures and not the individual steps.
