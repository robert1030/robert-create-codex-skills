# Using iTest Help > Navigating help topics > Using the Help view

The Help view provides the same features as the Help window (with the exception of printing), but in the same window as the workbench instead of a separate one. To open the Help view, select Help > Dynamic Help from the main menu. This will open the Related topics page.

![](images/using_help_2.07.jpg) <!-- image_ref -->

To navigate the Help view:

![*](bullet_blue.jpg) <!-- image_ref -->

![](images/using_help_2.08.jpg) <!-- image_ref -->

1. Switch to the All topics page using the link at the bottom.

1. 2 Find the topic you want to read in the table of contents by clicking to expand the subtopics.

1. 3 Most topics provide a list of links to related topics at the bottom. Follow these links to learn more.

![](images/using_help_2.09.jpg) <!-- image_ref -->

![](images/using_help_2.10.jpg) <!-- image_ref -->

1. 4 Use Go Back and Go Forward to navigate back and forth. These behave the same way as in Web browsers.
