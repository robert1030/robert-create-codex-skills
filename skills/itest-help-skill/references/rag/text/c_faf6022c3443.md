# Actions > Session-control actions: open and close > Determining the device or session profile (dynamically) at runtime > Parameterizing the session profile in an open step

![*](bullet_blue.jpg) <!-- image_ref -->

1. Create a topology (File > New > Topology).

1. 2 On the Topology editor, add a Device, and then add a session profile. On the Test Case Editor Steps page, add an open step. Now that you have specified a Local topology, the device appears as a choice in the drop-down menu for the Description.

At this point, the test case has some flexibility. Whenever you specify a different topology, you can select the appropriate device in the open step.
