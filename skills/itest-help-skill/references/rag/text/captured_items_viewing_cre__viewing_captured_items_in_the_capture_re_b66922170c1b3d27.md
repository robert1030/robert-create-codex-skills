# Viewing captured items in the Capture Report editor > Viewing captured items in the Capture Report editor

At any time, you can view the details of selected captured items in the Capture Report editor.

1. In the Capture view, select one or more captured items (use Ctrl-click and Shift-click to select multiple items).

1. 2

1. Click View As Capture Report in the Capture view toolbar. The Capture Report editor opens and displays all selected items.

1. 3

1. To save the Capture report, click Save As in the main toolbar.
