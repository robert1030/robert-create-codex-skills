# CyberFlood Session Overview > CyberFlood Session Overview

The iTest CyberFlood session provides easy-to-use testing mechanism that generates realistic application traffic and attacks to test the performance, scalability and security of application-aware network infrastructures.

The steps below describes a quick start process to operate the iTest CyberFlood session. See Creating CyberFlood Session Profile in iTest and CyberFlood Session Command Set.

- Generate iTest test case from captured CyberFlood session
