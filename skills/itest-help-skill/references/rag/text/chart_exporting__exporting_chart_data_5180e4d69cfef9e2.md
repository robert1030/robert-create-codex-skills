# Exporting chart data > Exporting chart data

You can export chart data into a standard format file (XML or CSV) so you or others can view the data using other applications (for example, Microsoft Excel or another data visualization application).

> **Note:** Note iTestRT cannot export chart data directly. There are, however methods for saving chart data. See Exporting chart data from iTestRT.

1. 1

1. Execute the test case that generates chart data.

1. 2

1. Click File > Export.

1. 3

1. On the Export page, select iTest > Export Chart Data. Click Next.

1. 4

1. You have the option to export the data in XML format or as a CSV (comma-separated value) file. (Many applications can import CSV files.) Click Next.

1. 5

1. Now specify where to save the data and provide a filename. Click Finish.
