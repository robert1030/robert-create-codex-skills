# Specifying the appearance of charts: Chart properties > Specifying the appearance of charts: Chart properties

Once you have created an analysis rule that generates a chart (as described in Charting test case data), you specify the appearance of the chart as follows.

1. 1

1. In the Steps section, select the required action: chart_as_xy, chart_as_bar, or chart_as_pie

1. 2

1. Click Processor Properties to expand and view.

1. 3

1. Select the required chart type, for example, Chart Using XY and view the Chart Using XY window where you set the properties that control the appearance of the chart.

The following sections describe the details for each chart type:

- Processors > Chart Using XY

- Processors > Chart Using Bar

- Processors > Chart Using Pie
