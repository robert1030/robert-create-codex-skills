# call command: Call a procedure and get the return value from that procedure > call command: Call a procedure and get the return value from that procedure

> **Note:** Note Applies to Tcl test cases.

Use the command to call a procedure in the test case with optional arguments and values. The call command returns the result of executing the procedure, which is defined using 'return' or 'write'.

> **Note:** Note The procedure must return a value so that the substitution could be processed successfully, otherwise exceptions will occur.
