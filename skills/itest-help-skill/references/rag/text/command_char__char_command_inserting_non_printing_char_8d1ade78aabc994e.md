# char command: Inserting non-printing characters > char command: Inserting non-printing characters

Inserts a non-printing character (for example, tab, Ctrl-C, Esc, or Delete) into a command or property. You can find documentation on the ASCII character set on the Internet.

> **Tip:** Tip You can also type escape sequences for non-printing characters directly into any command or property text.
