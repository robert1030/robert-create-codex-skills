# Command dialog box > Command dialog box

Use the Command dialog box to enter multi-line commands.

Alternatively, you can use the following settings to specify that, during execution, the step should use the value of a parameter as the command text.

| Use the value of a parameter as the command for this step | When you check the box: The Command property on the Parameter properties page displays the following text: “Command extracted from parameter <param_name>” In the steps grid, the Description cell for the step displays the same text. You must specify the Parameter property. Note If the parameter is masked, then, for the executed step, the command, the text response, and the structured data of the response are all cleared and are not displayed in any view or report.
