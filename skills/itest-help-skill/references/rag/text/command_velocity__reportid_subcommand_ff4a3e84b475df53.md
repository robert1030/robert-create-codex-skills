# Commands that return information from Velocity > Commands that return information from Velocity > velocity command syntax > reportId subcommand

Tcl: velocity reportId

Python: velocity('reportId')

The subcommand returns the execution report ID that Velocity passes to the agent. If no reportID value is provided, then the command will return empty value("") and causes no error.
