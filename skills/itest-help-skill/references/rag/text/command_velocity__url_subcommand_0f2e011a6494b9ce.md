# Commands that return information from Velocity > Commands that return information from Velocity > velocity command syntax > url subcommand

Example Tcl: [velocity url] subcommand

Example Python: velocity('url') subcommand

> **Note:** Note You may use [velocity] subcommands/velocity(subcommands) when authoring Velocity drivers.
