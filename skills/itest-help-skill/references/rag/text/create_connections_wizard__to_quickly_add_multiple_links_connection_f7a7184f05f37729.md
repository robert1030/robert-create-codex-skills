# To quickly add multiple links (connections between ports) > To quickly add multiple links (connections between ports)

> **Note:** Note The devices that you work with must each have at least two ports.

1. 1

1. Right‑click a device and select Create Connections.

1. 2

1. In the list at the top, open a device and then drag‑and‑drop one or more ports onto the connection area at the bottom.

1. 3

1. When you have created all connections, click Finish.
