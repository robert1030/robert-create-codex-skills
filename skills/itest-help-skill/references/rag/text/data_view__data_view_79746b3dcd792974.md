# Data view > Data view

The Data view is used when developing and troubleshooting iTest test cases (Windows > Show View > Spirent > Data). When an execution is underway and paused in current workbench window, the Data view shows all or a portion of the data model being used by that execution. A toolbar button can be used to toggle through different subsets of the data.

All data in iTest is stored in a single hierarchy. This includes global variables, local variables, procedure arguments, parameters, and even copies of the topology and session properties.

When debugging a test case, you may view all of this data using the Data view and modify the value of data items while execution is paused. For example, if you want to temporarily modify the value of a parameter while execution is underway, you can do so in this view.

The Data view offers two modes, Parameters and Stack mode (click to switch between the Parameters mode and the Stack mode.)
