# Data view > Data view > Stack mode

In the Stack mode, you may view variables for a stack frame in each thread.

During execution, when a breakpoint is encountered, you may view the contents of currently executed step.

- Click icon > to expand the relevant stack to auto-expand the contents and view all frames expanded within the stack.

Manual expansion and collapse state of frames is preserved when a stack element is expanded again.

- Click icon > to expand any newly added frames to automatically expand the contents.

- Click the Collapse All button (on the “Data view toolbar”) to collapse all stacks and parameters. This resets the state of expansion or collapsed elements in the tree.
