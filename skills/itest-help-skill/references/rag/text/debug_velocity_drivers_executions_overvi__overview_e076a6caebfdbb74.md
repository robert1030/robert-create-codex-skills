# Overview > Overview

iTest provides a way to enable debugging of automation assets being run from Velocity. This allows you to fix any issues with drivers, automation tasks, and test cases being developed. In addition, iTest allows you to debug drivers that use SLC session (assigned to agent pool with restriction value real-time) and Python drivers (assigned capabilities with language value as python and agent pool with restriction value driver).

iTest opens the test cases being debugged in the iTest Debugging perspective. You may view multiple windows—Velocity Explorer with test artefact's, responses, structures, and breakpoints of Velocity test executions (in the iTest Debugging perspective).

Important Ensure that iTest GUI Agent is used only for debugging purposes (debugging Automation Assets and drivers).
