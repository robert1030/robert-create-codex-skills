# iTest EXEC actions, grouped by function > iTest EXEC actions, grouped by function > Actions for procedures

The ‘call’ action: Calling a procedure

The ‘return’ action: Returning execution from the current procedure

The ‘write’ action: Adding text into the response of a call step

> **Tip:** Tip You should know about a powerful alternative to procedures: The iTest QuickCall feature makes it easy to add custom actions to the built-in iTest actions (e.g., getTable in SNMP sessions). You can use QuickCalls both during interactive (manual) testing and as test case steps. QuickCall procedures are custom actions that you define for a session profile or device. See “QuickCalls: Defining and using a library of custom actions”.
