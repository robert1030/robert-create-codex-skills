# Adjusting execution speed > Adjusting execution speed > Activating the Speed control in the Execution view

The speed control does not appear in the Execution view by default. Follow these steps to display the tool.

1. Click Window > Preferences.

1. 2

1. On the Preferences page, click Spirent > Views > Execution View.

1. 3

1. Check Display the execution speed slider in the Execution view.
