# Execution: Quick instructions > Execution: Quick instructions

Whenever Start Execution in New Window is enabled, you can click it to execute the currently selected item.

To specify whether new sessions should start in the iTest window or in an existing session window, set the Execution preferences (see Setting preferences for execution). You can set other execution preferences as well.
