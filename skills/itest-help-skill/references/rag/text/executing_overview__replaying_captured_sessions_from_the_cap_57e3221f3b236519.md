# Execution: Quick instructions > Execution: Quick instructions > Replaying captured sessions from the Capture view

In the Capture view, select a session or a group of sessions. Click .

> **Tip:** Tip Because iTest captures commands and responses from captured items that you replay, it captures the commands and responses that are being replayed too. This means that you can create a new (more complex) Capture report or captured session by using the capture that results from executing multiple original Capture reports, captured sessions, and captured items.
