# Loading a test case for execution > Loading a test case for execution > Loading for execution

1. Load the test case using one of the following methods:

- Before starting execution, in either the Execution perspective or the Test Case Debugging perspective, click Load for execution .

- While working in the Test Case editor, save the test case and then click Load for execution .

- In the Project Explorer, right-click the test case and select Load for execution or Load for execution – New Window.

1. 2

1. The Test Case editor opens to the first step in the test case. Execution is paused.

1. 3

1. You can now change runtime parameter values in the Data view.

1. 4

1. Use Execute One Step or Execute Procedure and Pause as needed.
