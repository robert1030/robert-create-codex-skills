# Exporting a test report as a compressed file (fftz format) > Exporting a test report as a compressed file (fftz format)

> **Note:** Note This section describes how to share reports with Velocity iTest users that use different workspaces from yours. This operation is not necessary if:

- You have configured Velocity iTest to save test reports to an external database rather than to the default database within your workspace. See Configuring Velocity iTest to save test reports to an external database.

- You share a report in another format with persons who do not have access to Velocity iTest. See Manually saving a test report as an HTML, PDF, Text, XML, and/or XML_RAW file.

When you export a report as a compressed file, you can share it with Velocity iTest users (that use different workspaces) for opening in the Test Report editor.

1. 1

1. Select the report to export and start the Export wizard. Use any of the following methods:

- In the Test Reports view, select the report. On the main menu, click File > Export.

- While working on a test report in the Test Report editor, click File > Export on the main menu.

- For a report saved in any of the other formats (PDF, Text, XML, or XML_RAW): In the Project Explorer, right-click the report and select Export.

1. 2

1. On the Export wizard’s Select page, select iTest > Test Reports as Compressed File. Click Next.

1. 3

1. Specify the location in your workspace to export the file to. Click OK.

1. 4

1. On the next page, click Finish.
