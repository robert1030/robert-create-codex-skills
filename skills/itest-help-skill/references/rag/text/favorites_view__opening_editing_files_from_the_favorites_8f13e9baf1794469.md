# Favorites view > Favorites view > Opening (editing) files from the Favorites view

Double-click the filename in the Favorites view. The file opens as if you had launched it from Project Explorer.

> **Note:** Note Rather than opening, a session profile will start a session when you double-click it in the Favorites view.
