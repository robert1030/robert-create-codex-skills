# Commands that are often used in field replacements > Commands that are often used in field replacements

Use the Insert Field tool as described in Inserting field replacements using the Insert Field tool to view the full list of supported field replacement commands.

Here are some commands that are commonly used in field replacements:

char: See char command: Inserting non-printing characters

expr: See expr command: Evaluating expressions

param: See param command: Returning parameter values

profile: See profile command: Accessing parameters that are defined in session profile

query: See query command: Inserting the results of a query

response: See response command: Accessing response data that is stored in a variable

tcl: See tcl command: Evaluating Tcl statements in the execution kernel's Tcl interpreter

tclexpr: See tclexpr command: Evaluating Tcl expressions in the execution kernel's Tcl interpreter

call: See call command: Call a procedure and get the return value from that procedure

json_select: see jsonSelect command: Get the node value from json string based on the query xpath
