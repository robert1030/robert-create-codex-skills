# Searching for text in a test report > Searching for text in a test report > Buttons

| Find | Find the next instance of the text specified in the Find field. During the Find process, the button changes to Cancel to allow you to cancel the current search. |
| --- | --- |
| Replace/Find Replace Replace All | Because test reports are read-only, Replace operations are not supported. |
| Close | Stop the Find operation and close the dialog box. |
