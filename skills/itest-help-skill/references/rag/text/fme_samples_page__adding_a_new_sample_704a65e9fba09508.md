# Form Map editor: Samples page > Form Map editor: Samples page > Adding a new sample

1. In the interactive Web session, while on the web page, take a snapshot (click ). This places the DOM for the page into the Response view.

1. 2

1. Copy the text in the Response view.

1. 3

1. Open Samples page of the Form Map editor.

1. 4

1. Click Add to add a sample and then paste the response text into the XML Data Viewer field.

1. 5

1. Move to the Targets page to add the targets.
