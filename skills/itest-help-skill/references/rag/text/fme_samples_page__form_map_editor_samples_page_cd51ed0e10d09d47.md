# Form Map editor: Samples page > Form Map editor: Samples page

When you use the New Form Map wizard to create a form map, the wizard finishes on the Samples page of the Form Map editor.

The XML Data Viewer field and the Response view are populated with the DOM of the web page.

iTest opens the Form Map editor to the Samples page and creates a sample.

iTest populates the XML Data Viewer field with the XML description of the home page that we got with the snapshot. This is where we'll find the targets that appear on the page.

> **Tip:** Tip The sample name is unimportant unless you expect more than one format for this web page (for example, when the page displays one set of configuration options or another, depending on the device model).

If the web page has more than one form (for example, it has different contents, depending on device configuration) then you can use the Samples page to add a new page map to the form map definition.
