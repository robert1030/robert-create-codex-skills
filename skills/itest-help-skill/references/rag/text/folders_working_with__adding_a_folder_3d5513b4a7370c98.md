# Working with folders > Working with folders > Adding a folder

1. 1

1. In the Project Explorer, right-click the parent folder and select New > Folder. (Alternatively, click File > New > Folder or select Folder in the New toolbar drop-down menu.)

1. 2

1. On the New Folder page, type the path to the parent folder or select it in the navigator.

1. 3

1. In the Folder Name field, specify the name that should appear for the folder in the view.

1. 4

1. For help on the Advanced options, click Help .

1. 5

1. Click Finish.
