# Form map libraries > Form map libraries

When you create a new form map, add it to a form map library.

When you associate the form maps with a session profile or device, iTest displays the available targets for the page in the drop-down lists in Context and Target fields.

A form map library is a iTest project (not a folder). A library contains a simple collection of form maps.
