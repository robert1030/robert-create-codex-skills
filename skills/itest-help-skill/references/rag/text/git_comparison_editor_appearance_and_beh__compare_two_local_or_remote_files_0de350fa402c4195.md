# Comparison editor appearance and behavior > Comparison editor appearance and behavior > Compare two local or remote files

When you compare two test cases either in the local branch or remote branch, iTest allows you to copy /replace steps from either the source or the target, that is, allows a two-way replace button for you to copy/replace only the required steps.

The example below show comparing two local files. Select the files you would like to compare, right-click select Compare with > Each Other.

The two files display on the Test Case Editors with connection lines to indicate the difference between the steps. Select a connector and a two-way arrow button appears. Click the arrow button to copy the files on the left or the right, as required.
