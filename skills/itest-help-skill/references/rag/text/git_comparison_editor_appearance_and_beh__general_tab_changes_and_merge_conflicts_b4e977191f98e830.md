# Comparison editor appearance and behavior > Comparison editor appearance and behavior > Comparing two test cases > General tab: Changes and Merge Conflicts

The screenshot below an example of shows the changes and merge conflicts on the Testcase Editor > General tab and how you may either accept changes and resolve merge conflicts.

Conflict and changes display as per the colors selected in General > Appearance > Color and Fonts.

- Resolve Merge Conflicts: Select the property that has a merge conflict indicator, an arrow appears in the middle of the two comparison windows. Click the arrow to accept and merge the conflict or manually update the property.

- Changes: Click the arrow on the top right of the source window to copy all non-conflicting properties or change the properties manually.
