# View and Resolve Any Merge Conflicts > View and Resolve Any Merge Conflicts

iTest provides an intuitive and readable view to solve merge conflicts encountered in a collaborative Git environment. Editing iTest file's underlying raw XML with complex nested XML elements, may not be intuitive and cause error.

Select the branch to merge, right-click. In case of merge conflicts, a Merge Results window appears to display the conflicting merge result. .

Click OK. Select the file with merge conflicts, right-click and select Project Explorer Teams > Merge Tool to display the file compare window.

> **Note:** Note You may also right-click on the conflicting test case, select Project Explorer > Team > Merge Tool to open the merge tool.
