# Setting preferences for Git > Setting preferences for Git > General > Appearance > Color and Fonts

| itest Compare | Select the required label for which you wish to change the default color, click Edit (on the left) and select a different color. Click Apply and Close. For example, select Conflict background, click Edit, select a different color from the color palette or define a custom color, click OK to accept the new color. Then click Apply and close for the color to be applied and displayed on the test case merge compare editor. |
