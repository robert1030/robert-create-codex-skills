# Restore Deleted Files > Restore Deleted Files

This section describes how to recover a file that was deleted in iTest from Git.

1. Go to iTest Development View, and delete a file you previously Staged.

1. 2

1. Right-click on the test_cases folder and then click Recover from Local History.

1. 3

1. The Recover from Restore from Local History dialog opens. Select file to recover and click Restore.

1. 4

1. The restore file is populated in the Project Explorer in Development view as illustrated below

You may delete the restored file from the Git Staging section, modify the restored file as required and commit again, if required.

1. 5

1. Right-click file in the Staged Changes section of the Git Staging page to delete files that are not required.

You may also perform other tasks options available on the right-click menu in the Git Staging > Staged Changes section.
