# Configuring Events: The Global Events page > Configuring Events: The Global Events page > Actions for the selected Event

The default Actions for the selected Event appear in this list. (You can review the full list of events in Actions on events: Definitions.)

Actions are taken in the order in which they appear in the list (the first action in the list occurs first). Use Move Up / Move Down to reorder the list.
