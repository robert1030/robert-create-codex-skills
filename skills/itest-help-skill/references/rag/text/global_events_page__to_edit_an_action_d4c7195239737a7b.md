# Configuring Events: The Global Events page > Configuring Events: The Global Events page > To edit an Action:

1. Un-check Inherit to enable non-inherited (non-default) settings.

1. Click More to display the properties of the selected action in the Action Definition Properties section.

1. Edit the Action Definition Properties settings as needed.
