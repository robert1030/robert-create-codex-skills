# Global parameter file > Global parameter file > Finding a Global Parameter File

You may quickly find and open the file set as a Global parameter File by clicking the toolbar button Find Global Parameter File.

The button Find Global Parameter File will be disabled:

- If a global parameter file is not defined.

- If the project to which the parameter file belongs to is closed.

When you click the toolbar button Find Global Parameter File, iTest automatically navigates to the global parameter file in the Explorer window and opens the file.

See also Specifying a parameter file as the Global parameter file to undo the global parameter file setting and/or set another parameter file as global.
