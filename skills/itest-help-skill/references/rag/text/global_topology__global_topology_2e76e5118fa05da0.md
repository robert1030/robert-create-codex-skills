# Global topology > Global topology

If you identify a particular topology as the Global topology, then, when you execute any test case that does not specify a Local topology, iTest asks whether you would like to use the Global topology for execution. You can configure the behavior so that particular test cases ignore the Global topology while others use it. (For more information on Local topologies, see Test Case editor: General page.)

The topology that was used for execution is identified in the Execution view and in test reports.Import topology to iTest

Important It is recommended to use the integrated Topology Editor to create, edit and reserve topologies. In addition, you may import a Velocity topology and then select the local Velocity topology in the test case.

> **Note:** Note A test case execution that uses a local Velocity topology includes the screenshot of the topology as displayed on the integrated Topology Editor. For example, if not all topology resources are shown in the integrated Topology Editor, then the screenshot will reflect this and does not show all topology resources.
