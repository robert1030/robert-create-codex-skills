# Searching help > Searching help > To search help:

1. From the main menu, select Help > Search

1. 2

1. Type in the word or phrase for which you want to search

1. 3

1. Click Go or press Enter. The list of results will be displayed below

1. 4

1. To view the content of a topic in the list of results, click it

Alternatively, you can search from the Help window using the Search field at the top of the window.
