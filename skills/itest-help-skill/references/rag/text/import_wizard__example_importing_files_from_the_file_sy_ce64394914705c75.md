# iTest Import wizard > iTest Import wizard > Example: Importing files from the File system

1. Click File > Import and select the type of document to import (File system in this example).

1. 2

1. Populate the From directory box by browsing to the directory that holds the files to be imported

1. 3

1. Now we select the filter that selects the type of file that we are interested in. Click Filter Types.

1. 4

1. On the Select Types dialog box, we select *.fftb because that is the file extension for iTest testbed files. Click OK.

1. 5

1. Now, on the File system page, click the folder in the left box and all of the files in the folder that pass the filter appear in the right box.

1. 6

1. Select the files to import.

1. 7

1. Supply the destination folder in the Into folder box by typing or browsing. In this example, we select the Testbeds folder in the project named project. (Notice that you can import the documents only into the current workspace.)

1. 8

1. Click Finish. The files are imported and are now available to iTest.
