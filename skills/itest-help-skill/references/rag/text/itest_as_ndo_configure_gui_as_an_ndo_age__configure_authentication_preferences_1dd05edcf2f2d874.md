# Configuring iTest GUI as NDO Agent > Configuring iTest GUI as NDO Agent > Configure Authentication preferences

Click Spirent > NDO Agent> Authentication and configure the authentication preferences.

| Users | Displays the names of users who can use NDO Agent. New: Click New. On the New user dialog, enter user name and password, and then click OK to same. Remove: Select username and click Remove to delete user from the list. Import: Click Import and on the Import User/Password file dialog, click Browse, select the required file and click OK to same |
| --- | --- |
| Generated Password | iTest NDO Agent uses an empty User/Password mapping file. When you start iTest NDO Agent, a user named spirent with random password is generated, if user/password is empty. No password is generated when you create user name and password or upload a username and password file. |
