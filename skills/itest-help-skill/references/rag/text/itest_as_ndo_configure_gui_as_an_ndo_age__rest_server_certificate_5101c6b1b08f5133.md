# Configuring iTest GUI as NDO Agent > Configuring iTest GUI as NDO Agent > REST Server Certificate

Click Spirent > NDO Agent> REST Server Certificate to specify the following settings when connecting to REST server.

| Generate self-signed certificate | The NDO Agent generates certificate and displays on NDO Console. |
| --- | --- |
| PEM Certificate | Browse and select the PEM Certificate and Private key. Enter the relevant password and click the Apply button. |
| PKCS12 certificate | Browse and select the Certificate, enter the password to use. The Generated self-signed certificate displays. Click the Apply button. If Certificate file does not exist, iTest will create the file, generate self-signed certificate and store it. The generated certificate will display as read only on this page and display on NDO Console. |
