# Start and Stop NDO server > Start and Stop NDO server > Network DevOps Agent API Calls > Executions using iTest NDO Agent > Delete Execution

When execution is in progress, if you issue DELETE /executions/{id}, the iTest GUI terminates the current execution.

The report page displays with Result as Cancel when execution is terminated.

When execution is terminated, the debug window is not closed automatically. See also the note above (page 2259).
