# Start and Stop NDO server > Start and Stop NDO server > Network DevOps Agent API Calls > Executions using iTest NDO Agent > Example Execute Test

iTest GUI open in debug mode, launches the TestCase Editor with test running and pauses at the first step.

> **Note:** Note The test execution pauses at first step, only if you have indicated that execution should stop at the first line (see Breakpoint at first step).

Click Execute One Step and the test executes one step at a time and debug as required.
