# Start and Stop NDO server > Start and Stop NDO server > Start iTest as NDO Agent

Go to Preferences > Spirent > NDO Agent page, and click Start.

If applicable you will be asked to checkout NDO license and the iTest License dialog displays where you an configure and manage licensing. Configure the License server and the NDO Agent starts.

The NDO Agent generates certificate and password. The generated password will also be displayed on the NDO Agent > Authentication dialog (Configure Authentication preferences) and on NDO Console. The generated certificate will be displayed on the NDO Agent > REST Server Certificate dialog and on NDO Console. The itest NDO Agent does not create and store logs in a file.
