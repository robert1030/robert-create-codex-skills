# iTestRT command reference > iTestRT command reference > Launcher options

The launcher options enable you to control iTestRT startup.

| --help [optionName] | Prints help information |
| --- | --- |
| --options path | Load additional (non-built-in) options from the file specified by path. path is a directory or file. |
| --verbose | Prints verbose help that identifies the full name of each registered option. |
