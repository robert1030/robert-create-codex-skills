# iTestRT command reference > iTestRT command reference > Test Report Publishing Service (rps) options

The rps options enable you to publish reports to a service.

Long form of name begins with: com.fnfr.open.automation.rps.activator

| --rps.password password | Account password for logging in |
| --- | --- |
| --rps.user userName | Account user name for logging in |
| --server serverURL | URL of the server to publish to To use a literal IPv6 address in a URL: Disable field replacement (substitution) for the property. As described in RFC-2732 (http://www.ietf.org/rfc/rfc2732.txt), enclose the literal address in [ ] bracket characters. For example, represent 1080:0:0:0:8:800:200C:4171 as http://[1080:0:0:0:8:800:200C:4171]/index.html |
