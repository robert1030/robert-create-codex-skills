# Overview: Scheduling execution using Jobs > Overview: Scheduling execution using Jobs > Velocity iTest

Velocity iTest runs jobs in the background, so sessions do not appear in execution views. In contrast, browser-based sessions (for example, Web and Swing) display the browser activity in the session window during execution.
