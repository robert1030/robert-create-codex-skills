# Overview: Scheduling execution using Jobs > Overview: Scheduling execution using Jobs > Velocity iTest > When Velocity iTest starts up

- When Velocity iTest opens, it starts any enabled jobs at the scheduled time.

- Jobs whose start times had elapsed while Velocity iTest was not running (and therefore were not run) are started at the next scheduled time. The missed run is ignored.

- Disabled jobs are ignored.
