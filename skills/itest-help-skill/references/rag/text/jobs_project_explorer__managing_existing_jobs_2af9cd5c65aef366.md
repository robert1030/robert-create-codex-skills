# Viewing and managing jobs using Project Explorer > Viewing and managing jobs using Project Explorer > Managing existing jobs

In the Project Explorer, right-click a job and select one of the following options:

- Open in iTest Jobs View — Open the iTest Jobs view and select the job. See iTest Jobs view: Monitoring and managing job schedules and results.

- Open — Open the job in the Job editor, as described in Job editor. Alternatively, double-click the job.

- Modify Job — Start the Job wizard on the Job page, as described in Step 2 of Configuring a job: The Job wizard.
