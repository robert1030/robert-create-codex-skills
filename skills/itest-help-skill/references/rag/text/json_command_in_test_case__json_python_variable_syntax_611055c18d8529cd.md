# JSON Command in Test Case > JSON Command in Test Case > JSON Command Syntax in Test Cases > JSON Python Variable Syntax

> **Note:** Note iTest does not highlight JSON Tcl variable syntax.

For Python variable use syntax: [var]

{"/":{"ports":\[{"name":"[portName]","status":"[portStatus]"}]}}

iTest highlights Python syntax in Path-Value field in the JSON Step Properties window as shown in the examples below.Substitutions are displayed with a highlight of higher contrast and the escape symbols are displayed in a lower contrast.

Both Tcl and JSON syntax use [ character to indicate variable substitution. The JSON syntax is highlighted to assist with readability and editing of JSON step Path-Value field that includes complex iTest substitutions and XPath expressions. See the examples below.

Example 1 shows Path-Value with syntax highlighted when substitution is enabled and syntax with no highlight when substitution is disabled.

Example 2 shows Path-Value with syntax highlighted for use of parameter substitution for key and value.

Example 3 shows Path-Value with syntax highlighted for use of variable substitution for array name and values.

Example 3 shows Path-Value with syntax highlighted with nested parameters, substitution for path, keys and values and arrays. .
