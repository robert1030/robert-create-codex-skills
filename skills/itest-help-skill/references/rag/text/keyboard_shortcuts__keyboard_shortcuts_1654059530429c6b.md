# Keyboard shortcuts > Keyboard shortcuts

You can use the following shortcuts in all editors:

| Windows | MacOS | Descrription |
| --- | --- | --- |
| Ctrl+Shift+L | Command +Shift+L | Show all keyboard shortcuts in iTest |
| Ctrl+3 | Command +3 | Open any iTest UI element (perspective, view, or editor) by typing its name. |
| Ctrl+Shift+R | Command +Shift+R | Open a resource by name. In the dialog, specify the resource name. You can use wildcard characters * and ? |
| Ctrl+Shift+S | Command +Shift+S | Save changes in all editors |
| Ctrl+Shift+W | Command +Shift+W | Close all editors |
| Ctrl+Space | Command +Space | While working in the Test Case editor, display popup information to help you to enter appropriate contents for a cell. |
| Tab | Tab | Moves the cursor to the next field in the editor, if any. |
| Shift+Tab | Shift+Tab | Moves the cursor to the previous cell in the editor, if any. |
| Ctrl-Z | Command+Z | Undo |
| Enter | Enter | Confirms the changes to that cell and gets out of the edit mode. |
| F2 | F2 | If a single item is selected, puts the cursor in the first editable cell in that item. If multiple items are selected, puts the cursor in the first editable cell of the first selected item. |
| F8 | F8 | Sizes each column in the editor to fit the longest cell in that column. |
