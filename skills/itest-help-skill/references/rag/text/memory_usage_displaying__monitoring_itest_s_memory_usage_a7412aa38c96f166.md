# Monitoring iTest's memory usage > Monitoring iTest's memory usage

1. 1

1. Click Window > Preferences.

1. 2

1. On the Preferences dialog box, click General.

1. 3

1. Click the Show heap status check box.

Heap utilization information will now appear in the bottom right of the iTest status bar.
