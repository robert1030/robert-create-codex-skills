# Migrate STC REST Test cases > Migrate STC REST Test cases

iTest provides a migration wizard to easily convert your existing STC REST session test cases to the latest version of STC REST session test cases for your testing. You may convert existing STC REST session test cases in these two ways.

- Go to iTest > tools > STC to REST Test Cases...

OR

- Go to Project Explorer > Test Cases context menu (right-click on Test cases folder or on any test case within the folder) and select STC to STC REST Test Case.

> **Note:** Note The Project Explorer context menu option will be enabled only when you select one or more folders or test cases within a project.

Conversion is a two step process selecting STC REST session test cases to convert and completing as follows.

1. The Select STC REST test cases page opens with a list of STC REST session test cases and location.

1. 2

1. Click Finish to display list of files converted to STC REST session for your review (Completed page).

> **Note:** Note The new test case name will include the suffix REST.

1. 3

1. Click Close to exit the Migrate STC REST Test Cases window.

> **Note:** Note You may also use the STC REST Mirage Tool Console to see any errors.
