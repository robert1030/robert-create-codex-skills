# New File dialog box > New File dialog box

You can create simple text files using iTest. Use one of the following methods:

- In the Project Explorer, right-click the intended parent folder and select New >File.

- In the main menu, click File > New > Other > iTest> File.

- In the main toolbar, click New Document and select Other > iTest> File.
