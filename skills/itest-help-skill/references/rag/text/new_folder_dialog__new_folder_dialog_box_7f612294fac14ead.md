# New Folder dialog box > New Folder dialog box

To add a folder to the Project Explorer:

1. Open the New Folder dialog box using one of the following methods:

- In the Project Explorer, right-click the parent folder and select New > Folder.

- In the Project Explorer, select the parent folder. In the main menu, click File > New > Folder.

- In the Project Explorer, select the parent folder. In the main toolbar, click New Document and select Folder.

1. 2

1. On the New Folder dialog box, select the parent folder in the Container field.

1. 3

1. Type a name for the new folder in the Folder Name text box.

1. 4

1. Click Finish.
