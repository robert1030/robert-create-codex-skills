# NTAF Response Data in iTest > NTAF Response Data in iTest > Specifying the maximum number of queries to display

Sometimes NTAF tools can generate a lot of data, especially when tables of results are returned. iTest, by default, sets the maximum number of queries (“blue boxes”) that can be generated at 100. You have the option to set a preferences setting to map more (or fewer) queries. In iTest, click Windows > Preferences and navigate to Spirent > Response Mapping. Set the value for the Maximum number of queries to evaluate property.
