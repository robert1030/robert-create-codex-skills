# Session types > Session types > Built-in Session Types > Other integration

| Zephyr for JIRA | Zephyr for JIRA Test Management system with the add-on ZAPI, integrated with iTest makes it easier to share projects across the organization. The integration (Zephyr for JIRA and iTest) allows you to work with JIRA tests via RESTful APIs to perform these tasks. |
| --- | --- |
| EggPlant | EggPlant Test session provides ways of automating execution of image-based GUI testing. The seamless testing of these iTest functionalities is achieved by iTest integration with EggPlant application (https://eggplant.io/eggplant-integrations/). |
| EGit | iTest integrates Eclipse EGit plugin, which allows you to use Git source control from iTest. The instructions provided in this guide assumes the following: Groups within your organization want to work on a project using EGit to develop and maintain test cases in a single location (the master branch). Users will have their own local repository (a copy of the test cases code including all the source control relevant information). Each user will receive changes and send changes using a remote repository at GitHub. For details about EGit see http://wiki.eclipse.org/EGit/User_Guide. |
