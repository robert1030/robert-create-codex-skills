# Working with parameters: The Parameters page > Working with parameters: The Parameters page > Define Custom Types

In the Test Case editor or Session Profile editor, the Custom type tab allows you to define custom parameter type with a set of named value elements. The custom parameter type and elements you define displays as an option that you can select to indicate the parameter types and values. See Custom Types.
