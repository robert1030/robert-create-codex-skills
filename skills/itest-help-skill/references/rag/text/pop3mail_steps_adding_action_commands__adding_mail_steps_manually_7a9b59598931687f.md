# Adding Mail steps manually > Adding Mail steps manually

1. 1

1. Add a step and select the open action. In the Description cell, select application:com.spirent.itest.applications.popmail. Session IDs for Mail steps do not interact with Session IDs of other sessions in the test case.

> **Tip:** Tip Add new steps by pressing Ctrl+Space, and then selection the command you would like to add.

1. 2

1. In the Action cell, select a Mail action and, if needed, add information to the Description cell. Field replacements are supported for all commands. For example, Update description will update the step command (Step Properties/General/Command), which supports Field replacements. See “Field Replacements”.
