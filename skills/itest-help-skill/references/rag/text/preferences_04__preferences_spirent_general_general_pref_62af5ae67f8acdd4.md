# Preferences: Spirent > General > General preference settings > Preferences: Spirent > General > General preference settings

When creating a new workspace, the interpreter language will be as selected in the Test Case preferred language (below). For example, iTest defaults the interpreter language to Python.

| Test Case preferred language | Select the default language that will be used to create Test Cases, Session Profiles, and Topologies. Options: Tcl, Python Default: Python |
