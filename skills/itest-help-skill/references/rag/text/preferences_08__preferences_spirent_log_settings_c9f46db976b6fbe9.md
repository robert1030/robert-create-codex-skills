# Preferences: Spirent > Log Settings > Preferences: Spirent > Log Settings

Spirent iTest captures the real-time data and writes a log file according to the logging level selected to a specified location. You can view this log file during a test run and then analyze when the test concludes.

| Logging Level |
| --- |
| DEFAULT |
| ERROR (Errors only) |
| INFO (Warnings, errors and information messages) |
| DEBUG (Message useful for debug iTest) |
| OFF (Turn off logging) |
| Log file location Note You may view log by clicking menu: Windows > Show View > Error Log |
| Note |
| Auto-select |
| Use local file |

| --- |
