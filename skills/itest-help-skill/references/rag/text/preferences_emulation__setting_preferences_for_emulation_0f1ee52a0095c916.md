# Setting preferences for emulation > Setting preferences for emulation

To view or edit preferences, click Window > Preferences. On the Preferences page, click Spirent > General > Emulation.

General information on setting and sharing preference settings appears in “Configuring iTest Preferences”.

| Do not require reservation for test cases with topology | Check the box if you find that you want emulation enabled for all steps in a test case when you start working on an emulated step. Note This property is purely a convenience — you can achieve the same functionality by checking Enable emulation for the test case on the Test Case editor General page. See the Ask if emulation should be enabled property.
