# Setting iTest preferences > Setting iTest preferences

You can set a significant number of preferences that configure iTest editors and views and that change how iTest behaves.

> **Note:** Note The topics that describe most preference settings appear in the appropriate chapter. For example, the chapter on Process sessions includes a topic on setting Process session preferences. This chapter describes the more general settings.

You can share preference settings with other iTest users. See Exporting and importing iTest preference settings.
