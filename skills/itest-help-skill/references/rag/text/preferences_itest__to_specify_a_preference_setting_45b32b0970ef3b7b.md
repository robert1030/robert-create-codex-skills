# Setting iTest preferences > Setting iTest preferences > To specify a preference setting:

1. Click Window > Preferences.

1. 2

1. On the Preferences dialog box, in the Preferences tree, click Spirent and then navigate to the appropriate page.

> **Note:** Note On the Preferences dialog box, in the Preferences tree, click General to list the Eclipse default settings, navigate to the appropriate page and set up preferences as required.

> **Note:** For example: Click Editors and change the value of Number of opened editors before closing as required. The default value is 25 and maximum is 99.
