# Setting preferences for monitoring SNMP traps > Setting preferences for monitoring SNMP traps

At any time, whether a iTest SNMP session is running or not, iTest receives traps on the ports specified in the iTest preferences. To configure a port to listen for traps during a iTest SNMP session, see SNMP MIB Browser > Traps and SNMP MIB Browser > Step Defaults > Traps.

To view or edit SNMP preferences, click Window > Preferences. On the Preferences page, click Spirent > Session Types > SNMP. (General information on setting and sharing preference settings appears in “Configuring iTest Preferences”.)
