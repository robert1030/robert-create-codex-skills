# Setting preferences for Wireshark sessions > Setting preferences for Wireshark sessions

To view or edit preferences, click Window > Preferences. On the Preferences page, click Spirent > Session Types > Wireshark.

General information on setting and sharing preference settings appears in Configuring iTest Preferences.
