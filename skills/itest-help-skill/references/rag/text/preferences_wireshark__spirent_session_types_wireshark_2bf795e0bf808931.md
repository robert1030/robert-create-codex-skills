# Setting preferences for Wireshark sessions > Setting preferences for Wireshark sessions > Spirent > Session Types > Wireshark

| Maximum number of load packets | Default: 2500 Note This setting is ignored if you are using tethereal, because tethereal does not support this option. The setting only takes effect if you are using tshark. The load count needs be limited to prevent an Out Of Memory exception when many packets have been captured or loaded. If the number of packets loaded is limited to the maximum packet count then a warning is displayed. You can then change the Display filter setting in the session profile to change the number of packets that will be loaded into memory. | Note | This setting is ignored if you are using tethereal, because tethereal does not support this option. The setting only takes effect if you are using tshark. |
