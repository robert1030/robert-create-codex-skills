# Calling a procedure in a test case step or in a property setting > Calling a procedure in a test case step or in a property setting

> **Note:** Note Not applicable for Python test cases.

You can use a call step or CallProcedure action to execute a local or foreign procedure. You cannot use the run action to execute a procedure. The call action is defined in The ‘call’ action: Calling a procedure.

For call steps or CallProcedure actions, the Command cell contains the target procedure name and any arguments and argument values.

Procedures can call procedures in a nested fashion.
