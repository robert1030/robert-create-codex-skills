# Topology editor: Properties view, Session tab > Topology editor: Properties view, Session tab

Select any device to cause the Session tab to appear. Use the Session tab to add, delete, view, and edit device sessions. The properties are set when you add a session profile as described in Add, edit, or remove a session configuration for a iTest topology device.
