# Setting preferences for Python > Setting preferences for Python

To view or edit preferences, click Window > Preferences. On the Preferences page, click Spirent > Session Types > Python.

Configure iTest to auto-select the General information on setting and sharing preference settings appears in “Configuring iTest Preferences”.
