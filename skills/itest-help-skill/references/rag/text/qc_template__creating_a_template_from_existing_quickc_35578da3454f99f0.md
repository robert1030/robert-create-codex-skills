# Creating a template from existing QuickCalls > Creating a template from existing QuickCalls

If you find that you use a particular QuickCalls procedures, and/or property settings whenever you create a new test case, iTest allows you to create such a test case with QuickCall procedures and generate as library template. You may link/associate the library template with a test case. Then, the new test case you create, will be based on the procedures and properties of the library template automatically appear in the new test case.

Any testcase with defined procedures may be a Library Template for another testcase, e.g., any testcase can be linked to another testcase as a template. The steps below shows steps for creation of a library template (Creating a QuickCall Library template) and the validations (Validation of QuickCalls against the associated template) performed when modifying a test case based on the template.
