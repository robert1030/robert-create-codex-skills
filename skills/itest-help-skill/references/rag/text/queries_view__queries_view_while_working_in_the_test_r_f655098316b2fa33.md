# Queries view > Queries view > Queries view: While working in the Test Report Comparison editor

On the Comparison page of the Test Report Comparison editor, when you select a step in the Executed Steps Comparison section that has a response map associated with it, the Queries view identifies differences between query results using the diff icon . For details, see Examining queries for differences.
