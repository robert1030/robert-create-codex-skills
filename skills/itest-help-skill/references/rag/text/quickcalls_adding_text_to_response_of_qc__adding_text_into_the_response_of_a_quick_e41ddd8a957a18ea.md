# Adding text into the response of a QuickCall step: The write action > Adding text into the response of a QuickCall step: The write action

A write step adds text into the response of a QuickCall step. In a QuickCall, you can use one or multiple write steps to return a response that includes response data from one or more of the QuickCall’s steps.

> **Note:** Note A write step does not write to files or involve file I/O.

See The ‘write’ action: Adding text into the response of a call step.
