# Defining a QuickCall > Defining a QuickCall

Step 1

First, specify the QuickCall library to associate with a device or session profile

1. You start the process from the topology device or session profile that you want the QuickCall library to be associated with:

- In the Device Properties section on the Topology editor, open the Libraries page.

or

- On the Session Profile editor, open the Misc page.

1. 2

1. In the QuickCall section, click the Create QuickCall library link.

1. 3

1. The New QuickCall Library wizard starts. Specify a location and filename for the new library.

> **Tip:** Tip Best practice is to place the QuickCall library in the same folder as the session profile that it is associated with and with the same filename. For example, router3A.ffsp and router3A.fftc

1. 4

1. Click OK. The new QuickCall library opens in the Test Case editor

> **Note:** Note Once you have specified a QuickCall library, the link changes to View QuickCall library. Click the link to open the QuickCall library in the Test Case editor.

Next, set up the QuickCall library
