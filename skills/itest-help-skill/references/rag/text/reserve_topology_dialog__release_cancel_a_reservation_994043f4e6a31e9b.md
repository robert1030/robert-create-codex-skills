# Reserve a topology > Reserve a topology > Release (cancel) a reservation

To release (clear) all port mappings that are being used by a reservation (for example, if you no longer need to use the resources), right‑click in the Reservation View and select Release.

> **Note:** Note Port mappings that are currently being used by another active reservation are not cleared.
