# Reserve a topology > Reserve a topology

In iTest, you can create a reservation that starts immediately. To schedule a reservation for a time in the future, use Velocity. If Velocity Reservation Priority Queuing feature is enabled, Velocity iTest can create a queued reservation.

> **Note:** Note You cannot reserve a iTest Topology. See To reserve a topology, below.

Important It is recommended to use the integrated Topology Editor to create, edit and reserve topologies. In addition, you may import a Velocity topology and then select the local Velocity topology in the test case.
