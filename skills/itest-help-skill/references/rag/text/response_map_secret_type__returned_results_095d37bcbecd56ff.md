# Response Map editor: Queries page > Response Map editor: Queries page > Creating a custom query > XPath 3.1 syntax for custom queries format > Returned results

XPath 3.1 returns sequences which consist of nodes, scalars (booleans, integers, double values), and structural types (maps, arrays).

iTest converts nodes into strings using node string value definition; and map and array XPath results are converted into JSON strings.
