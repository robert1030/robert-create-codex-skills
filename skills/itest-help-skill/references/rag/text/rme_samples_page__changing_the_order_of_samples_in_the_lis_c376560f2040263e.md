# Response Map editor: Samples page > Response Map editor: Samples page > Changing the order of samples in the list

You can use the Up and Down to organize the samples.

> **Note:** Note This feature is purely for your convenience and has no bearing on mapping (all response maps are applied to each response regardless of the order of the samples in the list).
