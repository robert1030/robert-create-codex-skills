# Response Map editor: Table Map page > Response Map editor: Table Map page > Preventing column wrapping in responses

In a CLI terminal session, the output wraps at the terminal width. This may cause table output to wrap. To avoid the problem, increase the terminal width, as follows:

1. Edit the session profile.

1. 2

1. Click More to view the properties page.

1. 3

1. Click Terminal > Size.

1. 4

1. Increase the Terminal Width setting (to, for example, 120) and select either

same as window size with the specified minimum

or

fixed as specified
