# Response Map editor: Table Map page > Response Map editor: Table Map page > Table Location: Repeating Tables

Use this page to specify how to respond when multiple instances of the table appear within a single response.

| Required | Generate an error if the table is not found at least once. The error appears in the Execution Messages window and in test reports whenever the table does not appear in a response. |
| --- | --- |
| Multiple | Check this property if the table can repeat within a response. If the table appears more than once in a response, then use the data in all table instances. Note This setting is allowed only if the start of data in the table is found using a banner (as described in The first row of data appears after a banner and also later in this topic). |
| Note | This setting is allowed only if the start of data in the table is found using a banner (as described in The first row of data appears after a banner and also later in this topic). |
