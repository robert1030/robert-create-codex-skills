# QuickCall definitions validation criteria > QuickCall definitions validation criteria > Validation rules applied when exporting Quickcall library

Based on the definition in the Quickcall argument description, the export Quickcall wizards will apply validation rules for each Quickcall argument before it can be a custom session command properly. The following rules apply: See Validation rule for default value, Validation rules for allowedPattern, allowedLength, etc., with datatype and Validation rules for AllowedRange, AllowedLength, AllowedCount:.
