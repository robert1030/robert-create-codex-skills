# scroll.html

Scrolls the specified value.

| Target | Required. |
| --- | --- |
| Controls | scroll bars or scrollable controls. |
| Command | Numeric value (+/-) indicating how much to scroll |
| Step Properties | Step Properties Direction: Horizontal or Vertical scroll direction Default: Horizontal Detail: Specify any advanced scroll action used, for example, Page Up. Default: [blank] Step Properties > Target Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15 |

For details, see the online help: Flex action reference.
