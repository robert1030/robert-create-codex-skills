# scrollDate.html

Simulates the scrolling in a date control.

| Target | Required. |
| --- | --- |
| Controls | Date controls. |
| Command | None. |
| Step Properties | Step Properties Detail: Scroll to next or previous month or year Default: NextMonth Step Properties > Target Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15 |

For details, see the online help: Flex action reference.
