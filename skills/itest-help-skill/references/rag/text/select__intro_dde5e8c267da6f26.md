# select.html

| Action Name | Target | Command property value | Description |
| --- | --- | --- | --- |
| select | Required | Required | Use select to select items in a list or a combo box. The Target is the element being selected. The Command property specifies the labels to select in the box (for example, label=myLabel). Use whitespace to separate labels. select steps also unselect anything that had previously been selected. |

For details, see the online help: Creating Web test case steps.
