# selectTab.html

Selects the specified tab.

| Target | Required. |
| --- | --- |
| Controls | Tab controls. |
| Command | The tab item to select or the index to it. |
| Step Properties | Step Properties Use index to specify the item to select: Check the box if the item is specified by index Default: unchecked Step Properties > Target Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15 |

For details, see the online help: Flex action reference.
