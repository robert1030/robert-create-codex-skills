# selectwindow.html

| Action Name | Target | Command property value | Description |
| --- | --- | --- | --- |
| selectWindow | Not Required | Required | selectWindow changes the focus to the specified popup window. Steps can then perform additional actions on the window. The Command property specifies the name of the window to select. To go back to the main window, use selectWindow with a Command property value of MainWindow. |

For details, see the online help: Creating Web test case steps.
