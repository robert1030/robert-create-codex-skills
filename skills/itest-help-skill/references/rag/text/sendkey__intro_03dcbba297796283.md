# sendKey.html

Sends the specified key to the targeted control.

| Target | Required. |
| --- | --- |
| Controls | All controls. |
| Command | The key to send, for example ENTER. |
| Step Properties | Step Properties Ctrl: Indicates that the Control key is pressed when executing the action Shift: Indicates that the Shift key is pressed when executing the action Alt: Indicates that the Alt key is pressed when executing the action Default: [No key selected] Step Properties > Target Maximum time to wait for target: Specify the maximum number of seconds to wait for the target to appear before performing an action on it. If the time is exceeded, iTest declares an execution issue for the step and then continues executing. Default: 15 |

For details, see the online help: Flex action reference.
