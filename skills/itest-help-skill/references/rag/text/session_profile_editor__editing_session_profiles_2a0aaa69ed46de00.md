# Editing session profiles > Editing session profiles

Use the Session Profile editor to make changes to any session profile properties.

1. In the Project Explorer or Favorites view, right-click the profile and select Open.

1. 2

1. The profile opens in the Session Profile editor, as described in Defining a session profile (configuring the session settings).

> **Caution:** When the editor opens, it displays the session type for the session profile that you are editing. If you change the Session type property, then all property settings are replaced with the default settings for the newly selected session type.

1. 3

1. Move to the appropriate editor page and modify the property settings as needed.
