# Session profile property settings for Bash sessions (Ubuntu and RHEL) > Session profile property settings for Bash sessions (Ubuntu and RHEL)

This topic describes the property settings that you can configure for session profiles. For basic information on configuring a session, see Session profiles: Session configuration settings. For a detailed description of how iTest uses the settings, see About property settings.

> **Note:** Note If you have already saved a device or session profile document, then you do not need to configure the settings again. See About property settings.

The first group of properties appears on the Start a New Session page (the Start tab of the Session Profile editor). To access the other settings, click .

> **Note:** Note It is recommended to specify the prompts before starting a new session. If you start a session without prompts, it is required to write at least one command to ensure that the rest of the commands that follow will be captured correctly.

| Path to bash installation | Optional. If blank, iTest will use the path specified in iTest Preferences Page. If the bash installation path is other than the one set on the Preferences page, iTest will use the path specified in the session. |
| --- | --- |

Click More and complete the options as required.
