# Session profile property settings for Spirent TestCenter sessions > Session profile property settings for Spirent TestCenter sessions > LabServer

The following properties let yo u specify whether and how to use Spirent TestCenter Lab Server for iTest sessions.

| Use LabServer | Check the box to use the LabServer option and run Spirent TestCenter on a server, as specified by the following settings. |
| --- | --- |
| Server IP/hostname | Specify the IP address or hostname of the host that is running Lab Server |
| Create new session on connect | If checked, use the credentials specified by the following properties to start a new LabServer session. If unchecked, use the currently running LabServer session for the iTest session. Works in conjunction with the Terminate session on disconnect setting. |
| Session name | Name to use to identify the session when starting a new LabServer session. |
| Owner ID | Owner ID to use when starting a new LabServer session. |
| Terminate session on disconnect | If checked, then end the LabServer session when iTest disconnects from LabServer. If unchecked, then do not end the LabServer session. Works in conjunction with the Create new session on connect setting. |
