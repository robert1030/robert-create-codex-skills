# Session profile property settings for Spirent TestCenter sessions > Session profile property settings for Spirent TestCenter sessions > Tcl

We recommend that you use the default values for the following properties.

| Use global Tcl interpretor during execution | Select to indicate that the Tcl Interpreter used during execution is the one specified in Preferences > Spirent > Session Types > Spirent TestCenter > Use specified Tcl Interpreter |
| --- | --- |
| Path to Tcl interpretor | Enter the path of the Tcl interpreter to be used during execution, if you do not wish to use the Global Tcl Intepreter. Default: Blank |
| Spirent Test Center Tcl API directory | Optional. Specify the path to the folder that holds the Tcl API to use in place to the default system Tcl API. Default: blank |
