# Bash session (Ubuntu and RHEL) > Bash session (Ubuntu and RHEL)

iTest supports Bash session on RHEL and Ubuntu and invokes the bash shell found in the system path. iTest also allows you to configure a specific bash path to invoke an alternate installation of bash interpreter.

The iTest bash session includes two built-in prompts: $ and #

> **Note:** Note The bash session shares the common CLI session properties such as color, size, prompts, etc. as in sessions like COMMAND, SSH, Telnet, etc.
