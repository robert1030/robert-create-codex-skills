# setslave.html

The setslave action applies to SSH or Telent high availability sessions.

The setslave action specifies the node to which commands will be sent for steps where the Send to property is set to slave. Commands with a Send to property value of slave are sent to the first node that is slave.

For setslave steps, specify an index in the Description cell to indicate the node to set as slave.

For details, see the online help: The setslave action.

Also, see the HA command reference.
