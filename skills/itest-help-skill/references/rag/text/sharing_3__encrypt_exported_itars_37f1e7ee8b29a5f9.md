# Exporting iTest projects as iTar files, Network DevOps Agent, or Velocity > Exporting iTest projects as iTar files, Network DevOps Agent, or Velocity > Encrypt exported iTars

iTest allows you to encrypt the iTars and distribute them for execution without revealing the content.

Select Encrypt exported iTars if required..
