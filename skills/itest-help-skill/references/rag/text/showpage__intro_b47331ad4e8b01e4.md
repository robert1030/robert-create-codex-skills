# showpage.html

| Action Name | Target | Command property value | Description |
| --- | --- | --- | --- |
| showPage | Not Required | Not Required | Returns the HTML source of the current HTML page. This is the equivalent of clicking View > Source in the browser. If you specify a frame in the Target property, then showPage returns the source of the document in the frame. Examples Action Target Command showPage frame3 <None> showPage <None> <None> |
