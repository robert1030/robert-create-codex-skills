# Session profile property settings for Spirent Avalanche sessions > Session profile property settings for Spirent Avalanche sessions > Advanced > License

| Hardware is an appliance | If unchecked, iTest makes the av::connect [IP address] –type STC call If checked, iTest makes the av::connect [IP address] –type Appliance STC call and you must specify a value for the License file property. Default: unchecked |
| --- | --- |
| License file | Required only if Hardware is an appliance is checked, Location of the Avalanche license file (XML format). For example: ./files/license/License.xml Note If you specify Demo mode, then the license information is not required. See Demo Mode for details. |
| Note | If you specify Demo mode, then the license information is not required. See Demo Mode for details. |
