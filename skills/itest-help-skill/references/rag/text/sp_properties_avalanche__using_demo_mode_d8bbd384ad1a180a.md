# Session profile property settings for Spirent Avalanche sessions > Session profile property settings for Spirent Avalanche sessions > Using Demo mode

You have the option to run sessions in Demo mode, where iTest runs the session against prepared data, enabling you to view results as if it were being returned by a device. To use Demo mode, set the Demo mode properties and provide values for the required properties in the Session Properties group. See Demo Mode for details.
