# Session profile property settings for SSH sessions > Session profile property settings for SSH sessions > Session Properties > More > SSH > Remote Port Forwarding

| Enable remote port forwarding | Check the box to enable remote port forwarding. If you enable remote port forwarding, then you must specify port forwarding pair information in the Port forwarding list text box. |
| --- | --- |
| Port forwarding list | If you enable remote port forwarding, then for each port forwarding pair, provide host and port information in the following format (one pair per line): [remoteIPaddress:]remotePort:localIPaddress_or_hostName:localPort Notice that remoteIPaddress: is optional. Field substitutions are supported in any part of the text. Default: unchecked |
