# Session profile property settings for SSH sessions > Session profile property settings for SSH sessions > Session Properties > More > SSH > X11 Forwarding

| Enable X forwarding | Check the box to enable X forwarding. If you enable X forwarding, then you must identify the display in the X display location text box. Default: unchecked |
| --- | --- |
| X display location | If you enable X forwarding, then type the information that identifies the display in the following format: [hostName]:displayNumber Notice that hostName is optional. Field substitutions are supported in any part of the text. If you do not specify a value, then iTest uses 127.0.0.1:0 Default: [blank] |
