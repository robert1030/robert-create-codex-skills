# Session Profile editor: Global Events page > Session Profile editor: Global Events page

On the Events page, you specify the actions that should take place whenever particular events occur during execution. Events are described more fully in Events.

Actions that you define here apply to any step in a session that is based on the current session profile. See Configuring Events: The Global Events page
