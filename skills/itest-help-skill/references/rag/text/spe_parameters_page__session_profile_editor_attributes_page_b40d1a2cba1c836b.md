# Session Profile editor: Attributes page > Session Profile editor: Attributes page

Parameters that you define for a session profile can be accessed by any step in a test case that operates in a session that was started using the session profile. See also About the Parameter Type ‘Secret’

The Attributes page appears in several editors as Parameters page. For details on creating and managing session attributes, see Masking a parameter’s value.
