# Setting preferences for the Session Profile editor > Setting preferences for the Session Profile editor

To view or edit preferences, click Window > Preferences. On the Preferences page, click Spirent > Editors > Session Profile Editor.

General information on setting and sharing preference settings appears in “Configuring iTest Preferences”.
