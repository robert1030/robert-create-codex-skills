# Running a test using Demo mode > Running a test using Demo mode

You have the option to run sessions in Demo mode, where iTest runs the session against prepared data, enabling you to view results as if it were being returned by a device. The intent is that you can run a session to learn more about how Avalanche sessions operate on iTest without having to install or run any Avalanche software.

> **Note:** Note Demo mode is not supported if you run a test using the Tcl scripts generated by Avalanche.

1. While configuring a session profile in the Session Profile editor, click to view the property tree and select Demo Mode. Set the following property values:

| Run session in demo mode | Check the box to run the session against prepared data. Important If you specify demo mode, then you must specify a value for each of the required properties in the Session Properties group, as described in Session Properties. (Any settings will do — iTest does not use the values. The values are required only to satisfy the iTest validation checks.) Default: unchecked | Important |  |
| --- | --- | --- | --- |
| Important |  |  |  |
| Results folder | Optional. if Run session in demo mode is checked, you can specify the folder from which to obtain the files for display in the Data Files list on the session window. If the field is blank, then iTest uses the embedded results from the Avalanche plug-in. |  |  |

- Save the session profile and start the test.
