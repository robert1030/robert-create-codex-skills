# To create a test case that includes Spirent TestCenter sessions > To create a test case that includes Spirent TestCenter sessions > The configurePort step

iTest generated this configurePort step because it captured an configurePort action when you clicked . Notice that the Description field for the step specifies the port (1) to which the Port configuration was added.

> **Note:** Note Remember that the device’s response to this command is auto-mapped, so, you could add an analysis rule for the step to have the automated test verify the settings or extract a value from the response.
