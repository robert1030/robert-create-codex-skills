# Traffic commands > Traffic commands > Generator commands

| Action | Arguments / Command property values | Button that captures the Action | Description |
| --- | --- | --- | --- |
| configureGenerator | portIndex |  | Applies any changes that you made to configuration settings |
| showGenerators | [portList] | — None — | Gets the property settings of the selected generator |
| startGenerator | [portList] | Selected port All ports | Starts transmitting on all or selected ports |
| stopGenerator | [portList] | Selected port All ports | Stops transmitting on all or selected ports |
