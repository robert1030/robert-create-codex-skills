# Traffic commands > Traffic commands > iMIX commands

> **Note:** Note For details on using the iMIX editor in interactive sessions and to see the commands that are captured when you click editor buttons, see To edit iMIX settings.

| Action | Arguments / Command property values | Button that captures the Action | Description |
| --- | --- | --- | --- |
| showFrameLengthDistributions | distributionName |  | Shows iMIX frame length distribution. See Property settings |
| addFrameLengthDistribution | distributionName | See note above the table | Adds a new iMIX frame length distribution. See Property settings. |
| configureFrameLengthDistribution | distributionName | See note above the table | Changes the settings for the specified frame length distribution See Property settings. |
| deleteFrameLengthDistribution | distributionName | See note above the table | Deletes the specified frame length distribution. |
