# Spirent TestCenter Command reference > Spirent TestCenter Command reference > Configure VLAN on TestCenter Testcase step > Configure VLAN on TestCenter Console page

To add/edit VLAN configuration, load the session file, and change or add VLAN configuration as required. At the TestCenterREST console, enter Help to display the list of parameters/groups available for setting or modifying values, as required.

You may change VLAN properties as required and apply the new values to the device.
