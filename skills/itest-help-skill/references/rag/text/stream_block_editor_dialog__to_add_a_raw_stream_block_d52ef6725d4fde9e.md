# To add a raw stream block > To add a raw stream block > To add a raw stream block

1. Select a generator and click . iTest opens a Stream Block editor that is very similar to the editor that you are used to using in TestCenter.

The iTest Frame tab differs from the TestCenter Frame tab. You specify the hex contents of the entire frame in a text box. You construct the text using other tools.

1. 2

1. When you have finished configuring the stream block, click OK. iTest captures an addStreamBlock action and captures all of the settings that you configured in the editor. In the iTest Test Case editor, you can view (and edit) all of the captured property settings in the Step Properties section for the step.
