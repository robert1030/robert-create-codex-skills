# summarize.html

The response to a summarize step summarizes test case pass/fail status and lists all execution messages that have been declared. For a summarize step, the response appears in the Response view and as a test report entry.

The Description cell (the value of the Command property) for a summarize step is blank.

Tip: Use a mail session and a response field replacement. to write the response to the summarize step into the body of an email message.

For details and restrictions, see the online help: The summarize action.
