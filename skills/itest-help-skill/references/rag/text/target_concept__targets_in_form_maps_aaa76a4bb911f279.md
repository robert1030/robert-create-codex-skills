# Targets > Targets > Targets in form maps

Once you associate a form map library with the session profile or device for the session, test case developers can create steps by selecting the targets from a drop-down list. The step in the example click (Action) the link named link=Advertising (Target) on the google_home page (the Context is the page where the target lives, as defined by the google_home form map).

> **Note:** Note To associate a form map library with the session profile or device for the session, you specify the form map library on the Misc page of the Session Profile editor or the Map Libraries page of the Testbed editor. Details appear in Associating a form map library with a session

.
