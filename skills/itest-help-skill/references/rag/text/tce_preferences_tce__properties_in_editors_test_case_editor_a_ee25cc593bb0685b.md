# Setting preferences for the Test Case Editor > Setting preferences for the Test Case Editor > Properties in: Editors > Test Case Editor > Appearance > Colors

On this page, you specify the various colors displayed in the Test Case editor.

| Setting colors for Test Case Editor rows | Different row types may be set to have different color. Note The row background set applies to the type of row. For example: The Test Step Row Background is for 'teststep' command background only. Paused row is selected when test case is suspended and hence, you cannot see the set background color. If you select a different row (not necessarily a Procedure row), the background color of the Paused row will be shown (e.g., yellow). | Note | The row background set applies to the type of row. If you select a different row (not necessarily a Procedure row), the background color of the Paused row will be shown (e.g., yellow). |
