# Test case editor: Requirements page > Test case editor: Requirements page > Specifying Agent requirements

1. On the Test Case editor, open the Requirements page.

1. 2

1. Click to add a new attribute to the list.

1. 3

1. Specify the following properties for an Agent:

| Key | The name that you use for the Agent must be unique. Note Use any name that allows you to identify the Agent capability. For example, os_type, agent_id, browser_type, etc. The following validation rules apply: A Key name should not start with these special characters: ';', '#' or '[' Value should not end with: ']' Both Key and Value should not contain: '=' Duplicate key and value pair is not supported, a warning displays saying that the value pair already exists. | Note | Use any name that allows you to identify the Agent capability.
