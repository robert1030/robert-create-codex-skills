# Step Properties section: Documentation properties group > Step Properties section: Documentation properties group > Documentation properties

| Label | Specify text for the label, which will display in the execution reports. |
| --- | --- |
| Tag | A tag is user-defined text string that provides Tag property for documentation only. |
| Comment | Type a comment string. You might provide more information about the step to make it easier to understand what is happening. For example, “Enter Interface Configuration mode” or “Reset Ethernet settings”. In addition, you could use the Comment to remind other automation engineers about the required context for the step. This Comment differs from the Comment action, which outputs a user-defined string into the capture report. |
