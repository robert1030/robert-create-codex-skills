# tcl.html

tcl {statement}

The iTest interpreter tcl command calls on the execution kernel's Tcl interpreter, evaluates the argument in the Description cell as a statement, and then returns the result of that evaluation.

STDOUT and STDERR are not used.

For details on using this and other iTest interpreter commands, see iTest interpreter command syntax.

Also, see: Field replacements: Substituting values into properties and commands.
