# Drag and drop (move/duplicate) procedure and steps > Drag and drop (move/duplicate) procedure and steps

iTest provides a quick way to move and duplicate steps by selecting the procedure/steps, that is, drag and drop them to the required location.

You may select one or more code lines, drag and drop them where required. See also Context (right-click) menu for the copy/cut and paste functions to copy or move one or multiple lines of code.

> **Note:** Note You may drag and drop only procedures and steps. You cannot drag and drop items such as Analysis rules.

See the examples below for selecting, dragging and dropping procedures/steps to the required location.

Example 1 move steps/procedures by dragging and dropping: Select one or more steps or procedures in a testcase, drag and drop them to a different location within the test case (move the lines to a new location) or a different test case. For example, drag and drop the selected steps or procedures in TestCase1 to TestCase2. The procedure is moved along with steps.

Example 2 copy steps/procedures by dragging and dropping: Select one or more steps or procedures in a test case, click or pressed the CTRL key (OPTION key on macOS), then drag and drop them to a different location within the test case (copy the lines to a new location). For example, click CTRL key (OPTION key on macOS), drag and drop the selected steps or procedures in TestCase1 to TestCase2. The procedure is copied along with steps.

These rules apply when dragging and dropping procedures and steps in iTest TestCase Editor.

- You may drag/drop procedure and steps within the same test case or into another open test case in the same iTest instance or into a test case open in a different iTest instance.

- You may select only consecutive steps from a procedure or select multiple consecutive procedures from a test case, then drag and drop them to the required location.

- You may also move/copy consecutive steps from one procedure to another within the same test case or another test case.

- You cannot drop a procedure into another procedure.

- You cannot select non-consecutive steps or procedures from a testcase to drag and drop them to the required location.

> **Note:** Note You may undo the Drag and drop action by pressing CTRL+Z (OPTION+Z on macOS) twice or clicking the menu option Edit > Undo twice.
