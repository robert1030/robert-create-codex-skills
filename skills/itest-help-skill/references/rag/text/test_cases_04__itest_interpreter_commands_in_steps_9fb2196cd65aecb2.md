# iTest interpreter commands in steps > iTest interpreter commands in steps

You can use iTest interpreter commands to perform a variety of tasks; some commands set variable values, perform mathematical operations, return information about a device, or parse a portion of a response, others are replaced at runtime by the value of a variable, a parameter value, query results, the full response to an earlier step, a special character, or any of a variety of other values.
