# Auto-saving every test report to an HTML, PDF, Text, XML, and/or XML_RAW file > Auto-saving every test report to an HTML, PDF, Text, XML, and/or XML_RAW file

You can configure a preference setting to cause Velocity iTest to auto-export each test report in any or all of HTML, PDF, Text, XML, and/or XML_RAW formats. See Setting preferences for Test Reports for details on configuring auto-save.

Format descriptions appear in Test report file formats.
