# Test Report editor > Test Report editor > Viewing test reports > Summary information on the executed test case

This section (collapsible by clicking the arrow ) displays the URI of the test case, the URI of the topology used for execution (if any), list of test case tags (if any), date, time and duration of execution, counts of execution issues, final test result, and a Report ID that uniquely identifies the report. In addition, the Summary section also displays the Parameters table with parameter names and their values.
