# Test Report editor > Test Report editor > Viewing test reports > Test result

An icon represents the overall test result: Pass, Fail, Abort, or Indeterminate. The Indeterminate result means that, because no pass/fail rule was executed, Velocity iTest cannot set the result as either Pass or Fail.
