# Test Report editor > Test Report editor > Viewing test reports > Toolbar

The menu options are always displayed on the toolbar.

When the Test Report page is resized horizontally, the toolbar automatically adjusts, and the menu options reposition accordingly.

| Go To Next Issue Go To Previous Issue | For very long test reports, it might take time to locate an execution issues. The Go To Next Issue and Go To Previous Issue buttons make it easier to quickly locate and view issues and their associated execution messages. |
| --- | --- |
|  | Export the test report as described in Uses for test reports. |
|  | Select a step in the report and then click the button to view the associated step in the Test Case editor. If no step is selected, then the Test Case editor opens the test case. Alternatively, right-click a step in the report and select Open Test Case. |
