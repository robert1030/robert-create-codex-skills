# Test reports overview > Test reports overview

Whenever you execute a test case, Velocity iTest saves all of the steps and responses in a test report. Each test report records a single execution of a particular test case, so test reports are identified by the test case name and the time of execution. In addition, during debug mode (see Debugging Test Cases), all manual steps executed in the open sessions and their associated responses are captured and included in the test report.

Velocity iTest lists all available test reports in the Test Reports view and displays the details of a test report in the Test Report editor. There are many options for accessing test reports:

- From the Test Report editor or Test Reports view, you can save test reports into Custom HTML, HTML, PDF, Text, XML, or XML_RAW formats.

- You can export test reports into a file suitable for import into other Velocity iTest workspaces.

- You can configure auto-export so that test reports are saved into a specified format and/or location whenever execution ends.

> **Tip:** Tip Test reports are displayed after test cases finish execution. To view status for each step during execution, use the Console view ( Console view).
