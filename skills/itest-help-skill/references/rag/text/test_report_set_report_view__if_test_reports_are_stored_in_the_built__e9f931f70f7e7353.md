# Controlling which reports appear in the Test Reports view: Database search and filter > Controlling which reports appear in the Test Reports view: Database search and filter > If test reports are stored in the built-in Velocity iTest database

1. In the Test Reports view toolbar, click Database Search .

1. 2

1. On the Search Reports, Search settings dialog, specify any or all of the search criteria:

| Result | The search returns reports with the specified execution result: Pass, Fail, Abort, Indeterminate, or All (all of the result types). |
| --- | --- |
| Time period | Specify the time period during which the test case was executed.: today,last 2 days, last month, last 6 months, last year, or all. |
| Test Case | Enter the test case name results you want to view. In addition you may view the Full test case URL and/or only the latest test case result. Select Full test case URL to view the test case location. Select Show only latest to view the latest results report. |
|  | Select Full test case URL to view the test case location. |
|  | Select Show only latest to view the latest results report. |
| Reset to default Cancel | Click Reset to default to discard your changes and set new search criteria. Click Cancel to discard the changes and close the dialog. |
|  | Click Reset to default to discard your changes and set new search criteria. |
|  | Click Cancel to discard the changes and close the dialog. |

1. 3

1. Click OK to save and apply the search settings, and close the dialog. The view gets populated with the reports that meet the search criteria.

1. 4

1. At this time, you have the option to apply a further filter to the results. See Applying a filter to the reports listed on the Test Reports view.
