# Setting preferences for Test Reports > Setting preferences for Test Reports > Spirent > General > Test Reports > Test Report Tags

These properties determine the database tags that are associated with test reports.

| Host | Optional. Default: iTest tags each test report with the hostname where the test case executes. If you specify text here, then each report is tagged with the text instead of the actual hostname. You can use the value to search for test reports in the database.
