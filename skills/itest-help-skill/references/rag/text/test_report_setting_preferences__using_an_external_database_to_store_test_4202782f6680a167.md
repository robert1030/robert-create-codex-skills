# Setting preferences for Test Reports > Setting preferences for Test Reports > Editors > Test Reports > Database > Using an external database to store test reports

To make it easier for everyone on your team to share test report data, you can configure Velocity iTest to save test reports to an external centralized database that is accessible to all Velocity iTest and iTestRT users rather than to the default “standalone” database within your workspace. See Configuring Velocity iTest to save test reports to an external database.
