# Running a test suite > Running a test suite

To execute a test suite, you can do either of the following:

- Execute a test suite using iTestRT, as described in “iTest Runtime: iTestRT”.

- Define an iTest job that references the test suite. When the job runs, the test suite executes. For information on defining, scheduling, and running jobs, see “Scheduling Execution”.
