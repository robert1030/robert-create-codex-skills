# NetConf commands > NetConf commands

The supported NetConf commands are based on RFC 6242:

https://tools.ietf.org/html/rfc6242

If you use an implementation that does not follow RFC6242, use the iTest command action and provide the NetConf command details as an RPC (remote procedure call) argument. The examples below show console display and termination characters displayed for NetConf 1.0 and 1.1.
