# to.html

Specifies the recipients of the email message. Required for each mail session in a test case.

In the Description cell, specify an email alias or a semicolon-separated list of email addresses of the recipients of the email message.

Field replacements are supported.

For details, see the online help: Sending email messages during test execution.
