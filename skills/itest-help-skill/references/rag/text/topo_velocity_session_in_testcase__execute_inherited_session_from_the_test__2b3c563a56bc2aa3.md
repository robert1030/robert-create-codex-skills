# Execute inherited session from the Test Case > Execute inherited session from the Test Case

Insert the inherited device session URI in the Open step on the Test Case Editor from imported Local Velocity topology. iTest inserts the inherited session URI and the properties as shown below.

Ensure to include the imported topology as Local Topology on the Test Case Editor > General tab. Then click ... on the Description column to display the Select Session Profile or Device dialog, and select the session profile associated with the Device in Topology.

See Test Case editor: Steps page, in “Test Case Editor” and Selecting a session profile or device in “Wizards and Dialog boxes”.

> **Note:** Note A test case execution that uses a local Velocity topology includes the screenshot of the topology as displayed on the integrated Topology Editor. For example, if not all topology resources are shown in the integrated Topology Editor, then the screenshot will reflect this and does not show all topology resources.

- Execute tbml command with the inherited sessions and iTest displays the inherited session in the Response tab.
