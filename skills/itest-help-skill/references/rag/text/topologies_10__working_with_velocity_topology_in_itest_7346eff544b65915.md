# Working with Velocity Topology in iTest > Working with Velocity Topology in iTest

You may work with topologies defined in Velocity in the following ways:

- Import it into the iTest workspace to use the topology in test cases. See Import a topology from Velocity into your iTest workspace.

- Create and edit Velocity topology in iTest Web Topology Editor. See Create and edit Velocity topology in the integrated Topology Editor.
