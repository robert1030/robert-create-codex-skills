# Comparing (“diffing”) two test reports > Comparing (“diffing”) two test reports > Working in the Test Report Comparison editor > Toolbar

- For very long reports, it might take some time to locate differences. Go To Next Diff and Go To Previous Diff in the toolbar make it easier to quickly locate and view differences and the associated execution messages.

- You can save comparison test reports as HTML, PDF, Text, XML, or XML_RAW files by clicking Save Test Report Comparison As . See Sharing comparison test reports as files
