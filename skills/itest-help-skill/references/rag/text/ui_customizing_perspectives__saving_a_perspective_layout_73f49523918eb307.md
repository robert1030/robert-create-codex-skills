# Customizing perspectives > Customizing perspectives > Saving a perspective layout

1. 1

1. Click Window > Save Perspective As.

1. 2

1. In the Save Perspective As dialog box, specify a name for the custom perspective and click OK. Now, when you open the new perspective, it is listed in the Other group.
