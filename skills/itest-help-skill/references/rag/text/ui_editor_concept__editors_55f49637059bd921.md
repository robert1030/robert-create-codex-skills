# Editors > Editors

Editors are typically displayed in a tabbed window in the editor area (highlighted in the example).

> **Tip:** Tip You can set preferences for editors. See Preferences: Spirent > Editors.Double-click the tab to maximize the editor. Double-click it again to minimize it.
