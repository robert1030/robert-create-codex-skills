# iTest menus > iTest menus > Window

| New Window | Open another instance of iTest in a new window |
| --- | --- |
| New Editor | For the current document in the current editor, open the document in another instance of the editor. |
| Open Perspective > [perspective_name] | Overviews of the default iTest perspectives |
| Show View | Display the selected view on the iTest window. Views. Tip: It's quicker to click Show View on the main toolbar. |
| Customize Perspective | See Customizing perspectives |
| Save Perspective As | See Customizing perspectives. |
| Reset Window Layout | Change the current layout of editors and views to the default iTest layout. Customizing perspectives |
| Close Perspective | Close the current perspective (the previously-used perspectives is then used). |
| Close All Perspectives | Close all perspectives. A blank Eclipse window remains. |
| Navigation > Show System Menu | Display the context menu for the current view or editor (same as right-click). |
| Navigation > [all others] | Display, resize, or move to the selected view or editor on the iTest window. |
| Preferences | See “Configuring iTest Preferences”. |
