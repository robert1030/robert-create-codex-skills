# Working with projects > Working with projects

iTest allows you to create and work with as many projects as you need and you can add, delete, and rename the folders within any project.

> **Note:** Note Response Map libraries and Form Map libraries are actually projects and you manage them as you would any other project.

> **Tip:** Tip You can set preferences for importing projects upon startup. See Setting preferences for the workspace.
