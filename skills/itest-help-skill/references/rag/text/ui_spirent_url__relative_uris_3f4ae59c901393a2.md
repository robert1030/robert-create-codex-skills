# URIs > URIs > Example URIs > Relative URIs

The general forms are:

fileName.extension

../fileName.extension

folderName/fileName.extension

URIs support relative references. For example, in an open step, the URI could be ../session_profiles/my_profile.ffsp

Using relative URIs is good practice because you can move and/or rename things with minimal impact. For example, if you have a response map for a particular step in a test case, you could place the response map file in the same directory as the test case. In the step properties, use my_local_respone_map.ffrm
