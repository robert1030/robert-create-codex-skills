# Viewing the XML source of iTest documents > Viewing the XML source of iTest documents > Advanced Users Only

To view iTest's XML representation of any iTest document (for example, Capture reports, test cases, and so on):

In the Project Explorer, right-click the document and select Open With Text Editor.
