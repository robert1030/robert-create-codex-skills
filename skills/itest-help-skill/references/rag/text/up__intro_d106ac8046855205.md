# Up.html

Adds a new mouse action item at the current position. This action is typically used for button clicks. Use the mouse action for 'Up', 'Down', 'Click', 'Double-Click' and 'Move' actions. Note:This action requires a repository item assignment.

For details, see the online help: "Ranorex action commands" section under the "Ranorex Sessions" topic.
