# Mapping a response using a Block Map > Mapping a response using a Block Map > Partially repeating, multiple-block

The general structure includes a header (optional), a middle section of text with a fixed structure, and (optionally) another header element (you might think of it as a footer).

1. Block: header

1. 2

1. Block: protocol_status

1. 3

1. In this example, this data is ignored. If we needed the data, we could create a block for it.

1. 4

1. Block: footer

Because there are multiple blocks, you will use a container to hold the blocks.
