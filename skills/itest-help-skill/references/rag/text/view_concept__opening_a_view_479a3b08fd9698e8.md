# Views > Views > Opening a view

Use one of the following methods to open a view:

- In the main tool bar, click the arrow on and select the view from the drop-down list. If the view is not listed, then select Spirent and then select the view.

- To select from a list of all available views, click the arrow on . select the required view.

- You may select available views from the Window > Show View menu. Clicking Window > Show View > Other, displays the Show View pop out menu.
