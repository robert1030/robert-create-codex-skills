# Outline View > Outline View

The Outline View displays the testcase outline. In an active TestCase Editor, the Outline view displays all procedure names and the associated procedure tags for the testcase and QuickCall library. You may filter items by tag or by procedure name separated by comma.

Filtering the list by Tag name, requires you to enter the exact Tag name and for procedure names, iTest supports auto-completion. That is, as you type text, iTest displays a list of matching procedure names.

For example, In the two procedures proc1 and proc2, proc1 has tag_01 and proc2 has tag-02, and if user inputs both tag1 and tag2 in the filter, both proc1 and proc2 will display in the Outline View.

When you select a procedure in the Outline View, TestCase Editor jumps to the corresponding procedure in the current testcase and expands to display the child steps.
