# Reservations View > Reservations View

The Reservations view displays the list of current active Velocity Core topology reservations.

In addition to refreshing, minimizing, and maximizing the Reservations view, you may perform the following tasks with the buttons on the top-right.

|  | Click icon to open the New Reservations window to create a new reservation. Enter these attributes to create a reservation: Name of the reservation Duration of the reservation (Days, hours, minutes). Default is 1 hour. You may filter the required topology and Select the topology you wish to reserve. Click Next to add relevant notes and click Finish. iTest displays activating and then activates the topology. |
| --- | --- |
|  | Click Filter to open the Configure Reservations Filter window, and enter the start and end time of the reservations. Click OK and the active reservations within the entered time frame displays. To view inactive reservations select the checkbox Show inactive reservation to view and click OK. See View reservations, “iTest Topology Editor”. |
|  | Click Link with Editor. If you have multiple reservation editors open and select a reservation in the Reservation view, and clicking this button activates the corresponding editor. This is not applicable in the iTest embedded Topology Editor. |
|  | Click to refresh the list displayed. |
