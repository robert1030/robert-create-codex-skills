# Setting Preferences for Views > Setting Preferences for Views > Setting preferences for error log view

To view or edit preferences, click Window > Preferences. On the Preferences page, click Spirent > View >Error Log View . The Error Log View window opens, set up the error log view as required.

| Open the Error Log View on any error, warnings, or exceptions | Default: Not selected. Select to indicate that iTest should open the Error Log view when any error, warning, or exception occurs. |
