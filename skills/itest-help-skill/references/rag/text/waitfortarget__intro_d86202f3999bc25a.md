# waitfortarget.html

| Action Name | Target | Command property value | Description |
| --- | --- | --- | --- |
| waitForTarget | Required | Not Required | This action is useful for Ajax applications with dynamically loaded controls. For example, a combo box appears only after you click a button, and you don't know how long it could take for the box to appear. In this case, create a Web waitForTarget step and specify the combo box in the Target property. Specify the time to wait using the Wait for target property. |

For details, see the online help: Creating Web test case steps.
