# while.html

A while loop repeats a group of steps until a specified condition is no longer true. The while loop consists of a group of steps and a condition. The condition is first evaluated. If the condition is true, then the steps are executed. This repeats until the condition becomes false.

For example, while $port < param portCount means: While the port number is less than the number of ports on the card (the value of the portCount parameter), repeat the loop. As soon as the port number is greater than or equal to portCount, leave the loop and continue executing at the first step after the while loop.

Nested loops (if, for, foreach, and while) are supported.

See the online help for details of how while loops work and tips on adding them.
