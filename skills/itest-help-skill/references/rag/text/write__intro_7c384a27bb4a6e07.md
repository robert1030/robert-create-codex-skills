# write.html

Sends the specified strings as the content of the data section of the UDP packet through the UDP socket to the destination port using default system encoding. Use quotation marks and a space to delimit strings. Returns confirmation of text sent. If the Flush receive buffer when data is sent session property is enabled, the write command also clears the read buffer.

For details, see the online help: UDP command reference section under the topic "UDP Session Editor Concept".
