# writefile_exec.html

You can use a writeFile step to write information to a file while executing a test case. For example, create a file that stores variable values, or data that is extracted from a response, or the entire text of the response to a step. Here are some options for writeFile steps:

- You can overwrite or append to an existing file
- You can add a blank line to the end file (after the end of the data)

For details, see the online help: The write action.
