# Supported XPath functions > Supported XPath functions

iTest supports the following XPath functions:

- XPath 1.0:

Language: http://www.w3.org/TR/1999/REC-xpath-19991116

XPath functions: https://www.edankert.com/xpathfunctions.html

- XPath 3.1:

Language: https://www.w3.org/TR/xpath-31/

Functions: https://www.w3.org/TR/xpath-functions-31/

iTest also includes the following additional XPath functions to spupport backward compatibility: min, max, avg.
