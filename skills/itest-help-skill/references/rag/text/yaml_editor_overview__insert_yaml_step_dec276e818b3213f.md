# YAML Step Editor Overview > YAML Step Editor Overview > Insert YAML Step

While adding a step in the Test Case editor, click in the Action cell to open the Insert YAML Step wizard by using one of the following methods:

- Click the Insert button on the Test Case Editor and select Insert YAML Step to open.

- Right-click context menu sub-menu items

- Use the quick access key Ctrl + Shift + Enter, Y and the Insert YAML Step wizard opens.
