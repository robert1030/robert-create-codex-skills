# YAML Steps in Test Case > YAML Steps in Test Case

Each Insert Step action in the wizard inserts only one YAML command into the test case step.

The arguments would appear both in the Description column of the test case and the Step Properties, and be synchronized.

> **Note:** Note iTest does not allow you to edit the description field or the command (Step Properties > General).

Substitutions are available in step properties for yaml actions. Substitutions are available for different fields like: document name, content, document index, value, File URI, sample, etc. See “Field Replacements”.

The Step Properties section includes unique properties label for each YAML action steps. See YAML Action Types and step properties. See also Example Step properties and Response of yamlGet.
