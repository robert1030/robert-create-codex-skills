# yamlAdd.html

yamlAdd allows you to insert a YAML node in an existing document. Select option on Select YAML Action dialog to Add a node to a YAML document. The Add a node option allows you to select a node from an existing YAML document and add a child or sibling node.

For details, see the online help: YAML Editor Wizard, section �Add a node to a YAML document�.
