# 版本政策

本地知識庫版本為 iTest Help 26.2.0。回答時把「使用者產品版本」「知識庫文件版本」「外部文件版本」分開記錄。

- 版本一致時，可依檢索內容回答。
- 只有相同 Major／Minor 時，明示可能存在 patch 差異。
- 版本不同且會影響操作或語法時，分開說明，不能混用。
- 使用者未提供版本且差異會影響正確性時，先給可確認的共同內容，再說明需要確認版本。
- 較新官方資料不可無標示地套用到 26.2.0。

衝突時使用下列格式：

```text
【版本或來源衝突】

知識庫資料：
- 版本：
- 說法：

外部官方資料：
- 版本：
- 說法：

本次採用：
- 來源：
- 版本：
- 原因：
```
