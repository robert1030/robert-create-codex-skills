# 正式回答格式

一般技術問題使用：

````markdown
## 結論

直接回答問題。

## 適用範圍

- iTest 版本：
- 作業系統：
- Test Step／Session 類型：
- 前置條件：

## 操作步驟

1. 
2. 
3. 

## 語法或範例

```language
<經過來源確認的範例>
```

## 參數說明

| 參數 | 用途 | 必填 | 注意事項 |
| --- | --- | ---: | --- |

## 注意事項

- 版本差異。
- 常見錯誤。
- 需要替換的值。
- 權限或環境需求。

## 資料來源

【知識庫來源】

【外部查證聲明】
只有實際使用外部資料時才顯示。
````

提供 Tcl、Python、PowerShell、Regex、Ixia 或其他語法時，必須使用程式碼區塊、保留大小寫與縮排、標明適用版本和前置條件、標示 placeholder、說明是否可直接執行。知識庫只能支持部分內容時，明寫「知識庫目前只能確認以下部分：」。
