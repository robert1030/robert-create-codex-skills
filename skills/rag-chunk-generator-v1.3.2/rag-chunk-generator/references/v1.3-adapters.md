# v1.3 Adapter Notes

HTML／XML 的完整工作紀律、策略、流程、工具矩陣與限制請讀
[`html-xml.md`](html-xml.md)。本文件保留 backend 決策摘要。

## Decision boundary

This release changes the extraction backend, not the chunk-size contract. The
existing `chunk_size=256`, `overlap=40`, `min_len=30`, Markdown delivery names,
and v1.0 metadata fields remain unchanged.

## PDF

Docling is the runtime primary candidate because its document model exposes
structured items and provenance. The adapter requires page provenance for all
non-empty items. If that condition is not met, it stops rather than emitting
unlocatable text. OCR is not enabled by this skill.

`pdfplumber` remains only as `--pdf_backend legacy`. Its tolerance tuning is
not a v1.3 quality strategy because the observed issue is a font mapping and
reading-order problem, not merely a configurable whitespace threshold.

Marker is an explicit optional comparison route. When selected, the adapter
passes `--disable_ocr` and uses only the PDF text layer. It is not the default
PDF route and does not add an OCR server dependency. PyMuPDF4LLM is
intentionally not part of this candidate.

## DOCX and HTML

MarkItDown is the default general text-analysis adapter. It is not promised to
be a high-fidelity layout converter. `Trafilatura` is isolated to HTML article
mode because boilerplate removal is useful for web pages but destructive for
technical or full-document HTML. HTML decoding is strict. BOM or `meta
charset` is honored, un-declared input must be UTF-8, and replacement
characters are not silently inserted.

## XML

The default XML route uses `lxml.etree.XMLParser` with
`resolve_entities=False`, `no_network=True`, `load_dtd=False`,
`recover=False`, and `huge_tree=False`. DOCTYPE and ENTITY declarations are
rejected before parsing. The output includes namespace-aware element paths,
attributes, sibling indexes, and mixed-content context so that hierarchy is
not discarded during chunking. `--xml_backend markitdown` is an explicit
general conversion fallback, not the security default. File size, element
count, and depth limits are enforced.

## Evidence limits

The adapter design is evidence-backed by the cited upstream documentation and
the local PDF reproduction, but this candidate does not claim a measured
accuracy percentage. A real quality claim requires a source-bound GOLDEN set,
including expected English phrases such as `brush one's teeth`, and retrieval
evaluation after embedding. Static tests do not substitute for that runtime
measurement.
